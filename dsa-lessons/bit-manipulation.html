Bit Manipulation in Python

Use binary representation and bitwise operations to solve compact low-level problems.

1What is it?

Bit manipulation works directly with the binary bits of integers using &, |, ^, ~, <<, and >>.

2Why do we need it?

It appears in masks, parity checks, subsets, permissions, XOR tricks, and performance-sensitive algorithms.

3How it works

Everyday idea

Instead of treating a number as a whole, inspect or change its individual 0/1 switches.

Technical view

Bitwise operators act on integer bit representations. Masks isolate positions; XOR toggles bits and cancels equal values.

  1. Write the number in binary.
  2. Choose a mask for the target bit(s).
  3. Apply the operator.
  4. Convert back or interpret the resulting bits.

4Python code, step by step

example.py
n = 10          # 1010
mask = 1 << 2    # 0100
print(n ^ mask)  # toggle bit 2
OUTPUT / RESULT
14
CodeWhat it means
1 << 2Creates a mask with bit 2 set.
n ^ maskXOR toggles the selected bit.

5Common mistakes

  • Confusing bit positions starting at 0 with positions starting at 1.
  • Using XOR tricks without checking the input constraints.

6When should I use it?

Use bit manipulation for masks, parity, powers of two, XOR uniqueness, and compact state representation.

7Interview questions

What does x ^ x equal?

0. XOR cancels equal bits.

What does x ^ 0 equal?

x.

8Try it yourself

Check whether n is a power of two.

Show hint
Hint: A positive power of two has exactly one set bit.
Show solution
solution.py
answer = n > 0 and (n & (n - 1)) == 0
