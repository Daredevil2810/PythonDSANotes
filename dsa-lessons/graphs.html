Graphs in Python

Learn graph types, representations, traversal, connectivity, cycles and the techniques that lead into shortest paths and MSTs.

1What is it?

A graph contains vertices connected by edges. You must distinguish directed vs undirected, weighted vs unweighted, connected vs disconnected, cyclic vs acyclic, and sparse vs dense graphs.

2Why do we need it?

Networks, maps, dependencies, social connections and real systems are graphs. The important skill is not just drawing a graph; it is choosing the representation and algorithm that match the constraints.

3How it works

Everyday idea

Cities are nodes and roads are edges. Roads may be one-way or two-way, free or costly, and there may be many routes or cycles.

Technical view

Common representations are adjacency lists and matrices. Core techniques include BFS, DFS, connected components, cycle detection, bipartite checking and topological sorting. Advanced algorithms include Dijkstra, Bellman-Ford, Floyd-Warshall, DSU, Kruskal, Prim and SCC algorithms.

  1. Identify graph type and edge meaning.
  2. Choose adjacency list or matrix.
  3. Master BFS and DFS with visited state.
  4. Learn components, cycle detection and bipartite checks.
  5. Then learn topological order, shortest paths, MST and strongly connected components.

4Python code, step by step

example.py
from collections import deque
graph = {
    "A": ["B", "C"],
    "B": ["D"],
    "C": ["D"],
    "D": []
}

q = deque(["A"])
seen = {"A"}
while q:
    node = q.popleft()
    print(node)
    for nxt in graph[node]:
        if nxt not in seen:
            seen.add(nxt)
            q.append(nxt)

5Common mistakes

  • Forgetting visited tracking in cyclic graphs.
  • Mixing up directed and undirected representations.

6When should I use it?

Use graphs whenever relationships are many-to-many or cycles are possible.

7Interview questions

BFS vs DFS?

BFS explores by distance/layers; DFS explores one branch deeply before backtracking.
