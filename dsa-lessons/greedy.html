Greedy Algorithms in Python

Make the best local choice when the problem guarantees that local choices can lead to a global optimum.

1What is it?

A greedy algorithm commits to the best-looking choice at each step without revisiting earlier decisions.

2Why do we need it?

When a greedy-choice property holds, it can be simpler and faster than dynamic programming.

3How it works

Everyday idea

Always take the best next step—but only when you can prove that doing so cannot hurt the final answer.

Technical view

Greedy correctness usually relies on an exchange argument or a structural property showing that an optimal solution can include the locally optimal choice.

  1. Define the local choice.
  2. Ask whether an optimal solution can always be transformed to include it.
  3. Make the choice and reduce the problem.
  4. Prove correctness before trusting the heuristic.

4Python code, step by step

example.py
coins = [25, 10, 5, 1]
amount = 63
used = []
for coin in coins:
    while amount >= coin:
        amount -= coin
        used.append(coin)
print(used)
OUTPUT / RESULT
[25, 25, 10, 1, 1, 1]
CodeWhat it means
for coin in coinsConsiders larger denominations first.
while amount >= coinTakes the coin whenever it is safe for this coin system.

5Common mistakes

  • Assuming every optimization problem is greedy.
  • Using coin-change greedy for arbitrary denominations where it may fail.

6When should I use it?

Use greedy only after proving the greedy-choice property for the problem.

7Interview questions

Why can greedy fail?

A locally best choice can block a globally optimal combination.

8Try it yourself

solution.py
intervals.sort(key=lambda x: x[1])
end = -float("inf")
count = 0
for start, finish in intervals:
    if start >= end:
        count += 1
        end = finish
