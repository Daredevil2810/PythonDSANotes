Trees in Python

Learn tree structure, major tree types, traversals, height, balance and the techniques built on them.

1What is it?

A tree is a connected acyclic hierarchy. In practice you will meet general trees, binary trees, full binary trees, complete binary trees, perfect trees, balanced trees, skewed trees and ordered trees such as BSTs.

2Why do we need it?

Trees model folders, DOM structures, syntax trees, organization charts, heaps and many interview problems. Knowing only the definition is not enough; you need to recognise the shape and choose the right traversal or invariant.

3How it works

Everyday idea

Start with a root. Every child begins another smaller tree. Binary trees limit each node to two children, BSTs add ordering, and balanced trees control height.

Technical view

Important distinctions: a full binary tree has 0 or 2 children per node; a complete tree fills levels left-to-right; a perfect tree has every internal node with two children and all leaves at the same depth; a balanced tree keeps height controlled; a skewed tree behaves like a chain. Traversals include preorder, inorder, postorder and level order.

  1. Learn the node/child representation.
  2. Recognise the tree type from its structural rule.
  3. Master preorder, inorder, postorder and level-order traversal.
  4. Learn height, leaf count, diameter and balance as recursive patterns.
  5. Move to BST operations, then balanced-tree rotations and serialization.

5Common mistakes

  • Assuming every tree is binary.
  • Forgetting that traversal order matters.

6When should I use it?

Use trees for hierarchical relationships and recursive divide-into-children problems.

7Interview questions

What is the difference between a tree and a graph?

A tree is connected and acyclic; a general graph may have cycles and disconnected components.

8Try it yourself

Compute the maximum depth of a binary tree.

Show hint
Hint: Depth is 1 + max(left depth, right depth).
Show solution
solution.py
def depth(node):
    if not node: return 0
    return 1 + max(depth(node.left), depth(node.right))
