Deque in Python

Use a double-ended queue when both ends matter.

1What is it?

A deque supports insertion and removal at both the front and back.

2Why do we need it?

Some sliding-window and queue problems need access to both ends efficiently.

3How it works

Everyday idea

Think of a hallway with doors at both ends: people can enter or leave from either side.

Technical view

collections.deque provides O(1) append, appendleft, pop, and popleft operations.

  1. Choose which end represents the newest or oldest item.
  2. Use append/appendleft to add.
  3. Use pop/popleft to remove.
  4. For indexed random access, use a list instead.

4Python code, step by step

example.py
from collections import deque
d = deque([2, 3])
d.appendleft(1)
d.append(4)
print(d)
print(d.popleft(), d.pop())
OUTPUT / RESULT
deque([1, 2, 3, 4])
1 4
CodeWhat it means
appendleft(1)Adds to the front.
pop()Removes from the back.

5Common mistakes

  • Treating deque like a random-access array.
  • Using list operations when both-end operations dominate.

6When should I use it?

Use deque for queues, sliding windows, and two-ended processing.

7Interview questions

What is the key difference between queue and deque?

A queue normally exposes one insertion end and one removal end; a deque supports both ends.
