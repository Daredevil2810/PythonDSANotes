Prefix Sum in Python

Precompute cumulative totals so range sums become constant-time queries.

1What is it?

A prefix sum stores the total from the beginning up to each position.

2Why do we need it?

It replaces repeated range summation with O(1) queries after O(n) preprocessing.

3How it works

Everyday idea

Write down the running total at every position. Any range total can then be found by subtracting two checkpoints.

Technical view

With prefix[i] representing the sum before index i, sum(l..r) = prefix[r+1] - prefix[l].

  1. Create prefix[0] = 0.
  2. Append each running total.
  3. For a range [l, r], subtract the prefix before l from the prefix after r.

4Python code, step by step

example.py
values = [2, 4, 1, 5, 3]
prefix = [0]
for x in values:
    prefix.append(prefix[-1] + x)

l, r = 1, 3
print(prefix[r + 1] - prefix[l])

5Common mistakes

  • Off-by-one errors in prefix indexes.
  • Forgetting that prefix arrays are often one element longer than the input.

6When should I use it?

Use prefix sums for many static range-sum queries and cumulative-balance problems.

7Interview questions

Why add a leading zero?

It makes a range beginning at index 0 use the same subtraction formula.
