Searching in Python

Find a target efficiently by choosing the right search strategy.

1What is it?

Searching means locating a value or deciding whether it exists.

2Why do we need it?

The search method can reduce work from O(n) to O(log n) when the data is sorted.

3How it works

Everyday idea

Linear search checks boxes one by one. Binary search keeps cutting the remaining range in half.

Technical view

Linear search is O(n). Binary search requires sorted data and is O(log n) by halving the candidate interval each step.

  1. Check whether the data is sorted.
  2. If not, use a linear scan or prepare the data.
  3. If sorted, compare the target with the middle value.
  4. Discard the half that cannot contain the target.

4Python code, step by step

example.py
def binary_search(values, target):
    left, right = 0, len(values) - 1
    while left <= right:
        mid = (left + right) // 2
        if values[mid] == target:
            return mid
        if values[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

print(binary_search([2, 4, 7, 9, 12], 9))

5Common mistakes

  • Using binary search on unsorted data.
  • Using the wrong boundary update and causing an infinite loop.

6When should I use it?

Use linear search for unsorted data or tiny inputs; use binary search when the search space is ordered and the monotonic condition is valid.

7Interview questions

Why is binary search O(log n)?

Each comparison removes roughly half of the remaining candidates.

left, right = 0, len(values) - 1
while left <= right:
    mid = (left + right) // 2
    if values[mid] >= target:
        if values[mid] == target:
            answer = mid
        right = mid - 1
    else:
        left = mid + 1
