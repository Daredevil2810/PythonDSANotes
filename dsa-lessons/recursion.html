Recursion in Python

Solve a problem by reducing it to smaller versions of itself.

1What is it?

A recursive function calls itself on a smaller subproblem until it reaches a base case.

2Why do we need it?

Trees, backtracking, divide-and-conquer, and many mathematical definitions naturally use recursion.

3How it works

Everyday idea

Ask a smaller version of the same question, and keep shrinking until the answer is obvious.

Technical view

A recursive algorithm requires a base case and a recursive case that makes progress toward the base case.

  1. Define the smallest input you can answer directly.
  2. Express the current answer using a smaller input.
  3. Ensure every call moves toward the base case.
  4. Trace the call stack when debugging.

4Python code, step by step

example.py
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))

5Common mistakes

  • Missing the base case.
  • Recursive calls that do not reduce the problem.
  • Ignoring recursion depth for large inputs.

6When should I use it?

Use recursion for trees, backtracking, divide-and-conquer, and naturally recursive definitions.

7Interview questions

What are the two essential parts?

A base case and a recursive case that progresses toward it.

8Try it yourself

Compute the sum of 1..n recursively.

Show hint
Hint: sum(n) = n + sum(n-1).
Show solution
solution.py
def total(n):
    if n == 0: return 0
    return n + total(n - 1)
