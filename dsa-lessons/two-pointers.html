Two Pointers in Python

Move two indexes strategically instead of checking every pair.

1What is it?

Two pointers maintain two positions in a sequence and move them according to the problem condition.

2Why do we need it?

It can reduce pairwise brute force from O(n²) to O(n) after sorting or when the input already has useful order.

3How it works

Everyday idea

Instead of comparing every person with everyone, place one finger at each end and move the fingers based on what you learn.

Technical view

Two-pointer algorithms maintain indices with an invariant that eliminates impossible states as pointers advance.

  1. Identify the order or invariant that makes pointer movement safe.
  2. Place pointers at the useful starting positions.
  3. Evaluate the current pair/window.
  4. Move one or both pointers according to the invariant.

4Python code, step by step

example.py
def has_pair(values, target):
    left, right = 0, len(values) - 1
    while left < right:
        total = values[left] + values[right]
        if total == target:
            return True
        if total < target:
            left += 1
        else:
            right -= 1
    return False

Boolean result
CodeWhat it means
left, right = 0, len(values) - 1Starts at both ends of a sorted list.
total = ...Measures the current pair.
left += 1 / right -= 1Moves toward a possible solution without revisiting eliminated pairs.

5Common mistakes

  • Applying the technique without the required ordering/invariant.
  • Moving the wrong pointer.

6When should I use it?

Use two pointers for sorted pair sums, partitioning, palindrome checks, and many in-place array transformations.

7Interview questions

Why does moving a pointer not miss the answer?

The ordering invariant proves that all states skipped by that movement cannot satisfy the target.
