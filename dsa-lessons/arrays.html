Arrays in Python

Store values in indexed order and learn the operations that make arrays useful.

1What is it?

In Python, lists provide dynamic array-like storage with indexed access.

2Why do we need it?

Arrays are the base structure behind many searching, sorting, prefix-sum, and two-pointer problems.

3How it works

Everyday idea

Think of numbered boxes placed next to each other. Indexing tells you which box to open.

Technical view

Python lists provide amortized O(1) append and O(1) indexed access, while inserting or deleting near the front requires shifting elements and is O(n).

  1. Choose the index or traversal you need.
  2. Use direct indexing when the position is known.
  3. Traverse when you need to inspect values.
  4. Remember that middle insertion/deletion can shift many elements.

4Python code, step by step

example.py
values = [10, 20, 30, 40]
print(values[2])
values.append(50)
print(values)
OUTPUT / RESULT
30
[10, 20, 30, 40, 50]
CodeWhat it means
values[2]Reads the third item in O(1) average time.
values.append(50)Adds a value to the end in amortized O(1).

5Common mistakes

  • Using an invalid index.
  • Assuming insert(0, x) is O(1).

6When should I use it?

Use arrays when you need ordered data, indexing, iteration, or compact storage.

7Interview questions

Why is list indexing O(1)?

The list stores references in an array-like contiguous table, so the index can be calculated directly.
