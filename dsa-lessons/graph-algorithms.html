Graph Algorithms in Python

Go from graph traversal to shortest paths, ordering, and connectivity.

1What is it?

Graph algorithms solve path, reachability, dependency, connectivity, and optimization problems on networks.

2Why do we need it?

Once graphs are understood, many real-world problems become recognizable as BFS, DFS, shortest-path, or topological-order tasks.

3How it works

Everyday idea

A map gives you roads; the algorithm decides whether you need to explore, find the cheapest route, or respect dependencies.

Technical view

Common families include BFS/DFS, Dijkstra for non-negative weighted shortest paths, Bellman-Ford for negative edges, and topological sorting for DAG dependencies.

  1. Identify the graph model and edge weights.
  2. Choose the algorithm based on constraints.
  3. Maintain visited, distance, or indegree state as required.
  4. Prove that the algorithm’s assumptions match the input.

4Python code, step by step

example.py
import heapq

def dijkstra(graph, start):
    dist = {node: float("inf") for node in graph}
    dist[start] = 0
    heap = [(0, start)]
    while heap:
        d, node = heapq.heappop(heap)
        if d != dist[node]:
            continue
        for nxt, weight in graph[node]:
            nd = d + weight
            if nd < dist[nxt]:
                dist[nxt] = nd
                heapq.heappush(heap, (nd, nxt))
    return dist

5Common mistakes

  • Using Dijkstra with negative edge weights.
  • Forgetting visited/stale-entry handling.

6When should I use it?

Use graph algorithms when the input is a network of relationships and the question asks about reachability, paths, costs, or dependencies.

7Interview questions

When should BFS find shortest paths?

In an unweighted graph, BFS finds shortest paths measured by number of edges.

When is Dijkstra appropriate?

For shortest paths with non-negative edge weights.

from collections import deque
q = deque([n for n in graph if indegree[n] == 0])
order = []
while q:
    node = q.popleft()
    order.append(node)
    for nxt in graph[node]:
        indegree[nxt] -= 1
        if indegree[nxt] == 0:
            q.append(nxt)
