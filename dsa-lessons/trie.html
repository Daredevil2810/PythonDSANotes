Trie in Python

Store strings by shared prefixes for fast prefix queries.

1What is it?

A trie is a tree where each edge represents a character and a path represents a prefix.

2Why do we need it?

It is useful for autocomplete, prefix search, dictionaries, and word lookup.

3How it works

Everyday idea

Words share the same starting hallway: cat and car both walk through c → a before splitting.

Technical view

Trie insertion and exact/prefix lookup take O(L), where L is the string length, independent of the number of stored words aside from branching/memory costs.

  1. Start at the root.
  2. For each character, follow or create its child.
  3. Mark the end of a complete word.
  4. For prefix queries, stop after the prefix characters.

4Python code, step by step

example.py
class TrieNode:
    def __init__(self):
        self.children = {}
        self.end = False

root = TrieNode()
word = "cat"
node = root
for ch in word:
    node = node.children.setdefault(ch, TrieNode())
node.end = True
OUTPUT / RESULT
Trie containing "cat"
CodeWhat it means
children.setdefault(ch, TrieNode())Gets an existing child or creates one.
node.end = TrueMarks that a complete word ends here.

5Common mistakes

  • Confusing a prefix with a complete word.
  • Using a trie when ordinary hashing is enough and memory is more important.

6When should I use it?

Use tries for prefix-heavy workloads such as autocomplete and dictionary prefix search.

7Interview questions

What is the lookup complexity?

O(L) for a word/prefix of length L.

8Try it yourself

Implement starts_with(prefix).

Show hint
Hint: Walk the trie for each prefix character and return whether every edge exists.
Show solution
solution.py
def starts_with(root, prefix):
    node = root
    for ch in prefix:
        if ch not in node.children: return False
        node = node.children[ch]
    return True
