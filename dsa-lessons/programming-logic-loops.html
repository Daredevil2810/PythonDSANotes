Loops & Conditions in Python

Build the control-flow habits that every DSA solution depends on.

1What is it?

Conditions choose a path; loops repeat a block of work. Together they let you describe most basic algorithms.

2Why do we need it?

Before learning data structures, you need to be comfortable turning a problem into repeated checks and updates.

3How it works

Everyday idea

Think of a traffic light. The condition decides what happens now, while a loop keeps checking the road until the journey is finished.

Technical view

A conditional branches execution based on a Boolean expression. An iteration construct repeatedly executes a block while its loop condition or iterable produces work.

  1. Read the input and identify the state you need to track.
  2. Write the condition that decides whether the current item matters.
  3. Choose a loop that visits every required item.
  4. Update your state inside the loop and stop when the work is complete.

4Python code, step by step

example.py
numbers = [4, 7, 2, 9, 6]

total = 0
for number in numbers:
    if number % 2 == 0:
        total += number

print(total)
OUTPUT / RESULT
12
CodeWhat it means
for number in numbers:Visits each value once.
if number % 2 == 0:Checks whether the current value is even.
total += numberAdds matching values to the running total.

5Common mistakes

  • Changing the loop variable when you only meant to update an accumulator.
  • Using a loop when a direct operation already solves the problem.

6When should I use it?

Use loops when work depends on every item, and conditions when the next action depends on the current state.

7Interview questions

What is the difference between if and while?

if makes one conditional decision; while can repeat a block while its condition remains true.

What is the usual complexity of one pass through n items?

O(n), because each item is processed once.

8Try it yourself

Count how many values in a list are greater than a target.

Show hint
Hint: Keep a counter and increment it only when the condition is true.
Show solution
solution.py
count = 0
for x in [3, 8, 2, 9]:
    if x > 5:
        count += 1
print(count)
