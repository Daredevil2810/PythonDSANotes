Functions in Python

Turn repeated logic into named, testable building blocks.

1What is it?

A function packages a piece of logic behind a name, accepts inputs through parameters, and can return a result.

2Why do we need it?

Algorithms become easier to reason about when each piece has one clear job.

3How it works

Everyday idea

A function is like a small machine: give it inputs, let it do one job, and collect the result.

Technical view

A Python function creates a callable object with a local scope. Parameters receive arguments and return transfers a value to the caller.

  1. Name the job clearly.
  2. Choose the inputs the job actually needs.
  3. Compute the result without relying on unnecessary global state.
  4. Return the result and test the function separately.

4Python code, step by step

example.py
def find_max(numbers):
    best = numbers[0]
    for x in numbers[1:]:
        if x > best:
            best = x
    return best

print(find_max([4, 9, 2, 7]))

5Common mistakes

  • Forgetting a return statement.
  • Making a function depend on unrelated global variables.

6When should I use it?

Use functions whenever a logical operation can be named and tested independently.

7Interview questions

Why are functions useful in DSA?

They isolate algorithmic steps, make recursion possible, and make testing easier.

8Try it yourself

Write a function that returns the sum of all values in a list.

Show hint
Hint: Start at zero and accumulate in a loop.
Show solution
solution.py
def total(values):
    answer = 0
    for x in values:
        answer += x
    return answer
