Sorting in Python

Rearrange data into order and understand the trade-offs between classic sorting algorithms.

1What is it?

Sorting rearranges values according to an ordering rule.

2Why do we need it?

Sorted data enables binary search, two pointers, merging, and many greedy strategies.

3How it works

Everyday idea

Sorting is like putting books on a shelf by title so later searches become easier.

Technical view

Comparison sorts repeatedly establish ordering relationships. Common complexities range from O(n²) for simple educational sorts to O(n log n) for merge sort and average-case quicksort.

  1. Decide the required order.
  2. Choose a sort based on constraints and stability needs.
  3. After sorting, exploit the new order with another technique.

4Python code, step by step

example.py
def insertion_sort(values):
    for i in range(1, len(values)):
        key = values[i]
        j = i - 1
        while j >= 0 and values[j] > key:
            values[j + 1] = values[j]
            j -= 1
        values[j + 1] = key

values = [5, 2, 4, 1]
insertion_sort(values)
print(values)
OUTPUT / RESULT
[1, 2, 4, 5]
CodeWhat it means
key = values[i]Stores the value being inserted.
values[j + 1] = values[j]Shifts larger values one position right.
values[j + 1] = keyPlaces the key in its sorted position.

5Common mistakes

  • Forgetting that Python sorted() is usually the practical choice.
  • Choosing O(n²) sorting for very large data without reason.

6When should I use it?

Use built-in sorting in real Python unless an interview asks you to implement a sorting algorithm or constraints require a specialized method.

7Interview questions

When is insertion sort useful?

For small or nearly sorted data, and for learning how insertion works.

8Try it yourself

Implement selection sort.

Show hint
Hint: For each position, find the smallest remaining value.
Show solution
solution.py
for i in range(len(values)):
    best = i
    for j in range(i + 1, len(values)):
        if values[j] < values[best]:
            best = j
    values[i], values[best] = values[best], values[i]
