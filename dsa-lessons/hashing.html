Hashing in Python

Use sets and dictionaries to turn repeated searches into fast lookups.

1What is it?

Hashing maps keys to locations so membership and key-based lookup are usually O(1) on average.

2Why do we need it?

Hash maps are one of the most important tools for turning brute-force O(n²) solutions into O(n).

3How it works

Everyday idea

Instead of checking every drawer, use a label that tells you which drawer to open.

Technical view

A hash table computes a hash for a key and stores it in a bucket. Collisions are handled internally; average lookup is O(1), with O(n) worst-case behavior.

  1. Ask what value must be remembered.
  2. Choose a key that identifies it.
  3. Store the information in a set or dictionary.
  4. Look it up instead of scanning the whole input.

4Python code, step by step

example.py
values = [2, 7, 11, 15]
target = 9
seen = set()
for x in values:
    if target - x in seen:
        print("pair found")
        break
    seen.add(x)
OUTPUT / RESULT
No pair found
CodeWhat it means
seen = set()Stores previously visited values.
target - x in seenChecks whether the matching partner already exists.

5Common mistakes

  • Using a list for repeated membership checks.
  • Forgetting what information the key must uniquely identify.

6When should I use it?

Use hashing for membership, frequency counting, grouping, duplicate detection, and pair-sum style problems.

7Interview questions

Set vs dict?

A set stores unique values; a dictionary stores key-value pairs.

8Try it yourself

Solve Two Sum using a dictionary.

Show hint

Show solution
solution.py
seen = {}
for i, x in enumerate(values):
    need = target - x
    if need in seen:
        answer = [seen[need], i]
        break
    seen[x] = i
