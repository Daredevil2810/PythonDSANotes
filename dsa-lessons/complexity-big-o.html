Complexity & Big O in Python

Measure how an algorithm grows as the input gets larger.

1What is it?

Big O describes an upper-bound growth rate such as O(1), O(log n), O(n), or O(n²).

2Why do we need it?

Two correct solutions can behave very differently on large inputs. Complexity helps you choose the scalable one.

3How it works

Everyday idea

If a list doubles, ask: does your work stay the same, double, or become four times larger?

Technical view

Time complexity models the number of basic operations as a function of input size; space complexity models additional memory usage.

  1. Identify the input size n.
  2. Count how many times the main work can execute.
  3. Drop constants and lower-order terms for Big O.
  4. Also check extra memory, not only time.

4Python code, step by step

example.py
def has_duplicate(values):
    seen = set()
    for x in values:
        if x in seen:
            return True
        seen.add(x)
    return False
OUTPUT / RESULT
No printed output; returns True/False.
CodeWhat it means
seen = set()Stores values already encountered.
if x in seen:Average O(1) membership check.
seen.add(x)Records the current value.

5Common mistakes

  • Calling every nested loop O(n²) without checking whether the inner range is actually constant.
  • Ignoring space complexity.
  • Confusing worst-case O(log n) binary search with linear search O(n).

6When should I use it?

Use complexity analysis whenever you compare solutions or need to judge whether a solution will scale.

7Interview questions

What is binary search complexity?

O(log n) time on a sorted sequence and O(1) extra space for an iterative implementation.

What does O(1) mean?

The amount of work does not grow with input size.
