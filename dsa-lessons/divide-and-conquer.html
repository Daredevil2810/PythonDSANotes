Divide & Conquer in Python

Split a problem into smaller independent pieces, solve them, and combine the results.

1What is it?

Divide-and-conquer repeatedly partitions a problem until the pieces are easy, then combines their answers.

2Why do we need it?

It produces efficient algorithms such as merge sort and supports parallel-style reasoning.

3How it works

Everyday idea

Cut a big job into smaller jobs, solve each, then assemble the result.

Technical view

If T(n)=aT(n/b)+f(n), recurrence analysis describes the resulting complexity. Merge sort gives O(n log n).

  1. Divide the input.
  2. Recursively solve each part.
  3. Combine the partial results.
  4. Check the recurrence or total work.

4Python code, step by step

example.py
def merge_sort(values):
    if len(values) <= 1:
        return values
    mid = len(values) // 2
    left = merge_sort(values[:mid])
    right = merge_sort(values[mid:])
    return merge(left, right)

def merge(a, b):
    out = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            out.append(a[i]); i += 1
        else:
            out.append(b[j]); j += 1
    return out + a[i:] + b[j:]

Sorted list

5Common mistakes

  • Forgetting a base case.
  • Ignoring the cost of the combine step.

6When should I use it?

Use divide-and-conquer when subproblems are independent and a clean combine step exists.

7Interview questions

Why is merge sort O(n log n)?

There are log n levels of splitting and O(n) merging work at each level.

8Try it yourself

Find the maximum value using divide and conquer.

Show hint
Hint: Split, find each half maximum, then take max.
Show solution
solution.py
def maximum(a):
    if len(a) == 1: return a[0]
    mid = len(a)//2
    return max(maximum(a[:mid]), maximum(a[mid:]))
