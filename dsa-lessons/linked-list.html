Linked List in Python

Store nodes connected by references instead of contiguous indexes.

1What is it?

A linked list consists of nodes where each node stores a value and a reference to another node.

2Why do we need it?

It teaches pointer/reference manipulation and supports efficient insertion when you already have the correct node.

3How it works

Everyday idea

Imagine a treasure hunt where every note tells you where the next note is.

Technical view

A singly linked list stores a value and next reference per node. Traversal is O(n), while insertion after a known node is O(1).

  1. Create a node containing data and a next reference.
  2. Start from the head.
  3. Follow next until you reach the desired position or None.
  4. Update references carefully when inserting or deleting.

4Python code, step by step

example.py
class Node:
    def __init__(self, value):
        self.value = value
        self.next = None

head = Node(10)
head.next = Node(20)
head.next.next = Node(30)

cur = head
while cur:
    print(cur.value)
    cur = cur.next
OUTPUT / RESULT
10
20
30
CodeWhat it means
self.next = NoneStarts the node without a successor.
head.next = Node(20)Connects the first node to the second.
cur = cur.nextMoves one node forward.

5Common mistakes

  • Losing the next reference before saving it.
  • Forgetting to update head when inserting at the beginning.

6When should I use it?

Use linked lists when pointer manipulation is the learning goal or when frequent insertion/deletion is needed at known positions.

7Interview questions

Why is random access slow?

You must follow links from the head, so accessing position k is O(k).

8Try it yourself

Reverse a singly linked list.

Show hint
Hint: Keep previous, current, and next references.
Show solution
solution.py
prev = None
cur = head
while cur:
    nxt = cur.next
    cur.next = prev
    prev = cur
    cur = nxt
head = prev
