Pattern Printing in Python

Use nested loops to understand rows, columns, and repeated structure.

1What is it?

Pattern problems print characters or numbers according to row and column rules.

2Why do we need it?

They force you to reason about nested loops, boundaries, spacing, and changing work per row.

3How it works

Everyday idea

Imagine drawing a shape one row at a time. The outer loop chooses the row; the inner loop decides what appears in that row.

Technical view

Nested iteration gives an O(r*c) structure for r rows and c columns unless each row uses a constant-time string operation.

  1. Decide how many rows exist.
  2. For each row, calculate how many symbols or spaces it needs.
  3. Print the row and move to the next line.

4Python code, step by step

example.py
rows = 4
for i in range(1, rows + 1):
    print("*" * i)
OUTPUT / RESULT
*
**
***
****
CodeWhat it means
range(1, rows + 1)Generates row numbers 1 through rows.
"*" * iCreates exactly i stars for the current row.

5Common mistakes

  • Mixing up row count and column count.
  • Forgetting to move to a new line after each row.

6When should I use it?

Use patterns to practise loop logic before moving to nested-loop algorithms.

7Interview questions

What does the outer loop usually represent?

The current row or major unit of work.

8Try it yourself

Print a right-aligned triangle of stars.

Show hint
Hint: Print spaces before the stars.
Show solution
solution.py
rows = 4
for i in range(1, rows + 1):
    print(" " * (rows - i) + "*" * i)
