Sliding Window in Python

Maintain a changing contiguous range instead of recomputing every subarray.

1What is it?

A sliding window keeps a left and right boundary and updates only what enters or leaves the range.

2Why do we need it?

It turns many O(n²) contiguous-subarray problems into O(n).

3How it works

Everyday idea

Imagine looking through a moving train window: when it moves right, one item leaves and another enters.

Technical view

The technique maintains an invariant over a contiguous interval, expanding or shrinking boundaries while updating aggregate state.

  1. Define what makes a window valid.
  2. Expand the right side to include new data.
  3. Shrink from the left whenever the window becomes invalid or too large.
  4. Record the best valid window.

4Python code, step by step

example.py
def longest_unique(text):
    seen = set()
    left = 0
    best = 0
    for right, ch in enumerate(text):
        while ch in seen:
            seen.remove(text[left])
            left += 1
        seen.add(ch)
        best = max(best, right - left + 1)
    return best

print(longest_unique("abcabcbb"))

5Common mistakes

  • Not removing outgoing state when moving left.
  • Using a fixed window when the problem needs a variable window.

6When should I use it?

Use for contiguous arrays/strings involving longest, shortest, count, sum, or frequency constraints.

7Interview questions

When is sliding window inappropriate?

When the problem is not about a contiguous range or when the state cannot be updated efficiently as the window moves.

8Try it yourself

Find the maximum sum of any window of size k.

Show hint
Hint: Add the new right value and subtract the outgoing left value.
Show solution
solution.py
window = sum(values[:k])
best = window
for right in range(k, len(values)):
    window += values[right] - values[right-k]
    best = max(best, window)
