Stack in Python

Learn LIFO: the last item added is the first item removed.

1What is it?

A stack supports push and pop at one end.

2Why do we need it?

Stacks model nested work, undo operations, parsing, recursion, and monotonic-stack problems.

3How it works

Everyday idea

A stack of plates: you take the top plate first.

Technical view

A stack is an abstract data type with push, pop, and peek operations, typically O(1) with a dynamic array or linked list.

  1. Push items onto the top.
  2. Peek when you need the top without removing it.
  3. Pop when the top item is complete.
  4. Never remove from the middle if you want stack semantics.

4Python code, step by step

example.py
stack = []
stack.append("A")
stack.append("B")
print(stack.pop())
print(stack[-1])
OUTPUT / RESULT
B
A
CodeWhat it means
append("B")Pushes B onto the top.
pop()Removes and returns the top item.
stack[-1]Peeks at the top without removing it.

5Common mistakes

  • Calling pop() on an empty stack.
  • Using the wrong end of a list and accidentally making operations O(n).

6When should I use it?

Use stacks for parentheses, undo, DFS, expression parsing, and monotonic-stack problems.

7Interview questions

What does LIFO mean?

Last In, First Out.
