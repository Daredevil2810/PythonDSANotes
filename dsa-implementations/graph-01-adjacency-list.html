Adjacency List in Python

Store each vertex with its neighbors.

1Why this matters

It is the standard sparse-graph representation for BFS and DFS.

Approach

Choose representation before choosing the algorithm.

2Python implementation

Python
graph={"A":["B","C"],"B":["A","D"],"C":["A"],"D":["B"]}
for u in graph: print(u,graph[u])

3Expected output

OUTPUT / RESULT
A ['B', 'C']
B ['A', 'D']
C ['A']
D ['B']

4Line by line

CodeMeaning
graph["A"]Returns A’s neighbors.

5Dry run

A has edges to B and C; B connects A and D.

6Complexity

O(V+E) space.

7Common mistakes

  • Forgetting reverse edges in undirected graphs.

8When to use it

Use for sparse graphs and traversals.

9Interview questions

List vs matrix?

List uses O(V+E) space; matrix uses O(V²).
