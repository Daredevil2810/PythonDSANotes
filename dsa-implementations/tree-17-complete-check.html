Check a Complete Binary Tree in Python

A complete binary tree fills every level except possibly the last, and the last level is filled from left to right.

1Why this matters

Completeness is the structural property that allows binary heaps to use an array representation efficiently.

Approach

Use level-order traversal. After the first missing child position, every later node must have no children.

2Python implementation

Python
from collections import deque

class Node:
    def __init__(self, value, left=None, right=None):
        self.value = value
        self.left = left
        self.right = right

def is_complete(root):
    if root is None:
        return True
    q = deque([root])
    seen_gap = False
    while q:
        node = q.popleft()
        for child in (node.left, node.right):
            if child is None:
                seen_gap = True
            else:
                if seen_gap:
                    return False
                q.append(child)
    return True

root = Node(1, Node(2, Node(4), Node(5)), Node(3, Node(6)))
print(is_complete(root))

3Expected output

OUTPUT / RESULT
True

4Line by line

CodeMeaning
seen_gap = FalseRecords whether a missing child position has appeared.
if child is None:A gap in level order has been found.

5Dry run

Level order sees nodes 1, 2, 3, 4, 5, 6. The missing right child of 3 comes after all existing children, so the tree remains complete.

6Complexity

O(n) time; O(n) queue space in the widest level.

7Common mistakes

  • Checking only node counts.
  • Forgetting that the final level must be left-aligned.
  • Confusing complete with perfect.

8When to use it

Use when validating heap-like tree shape or any left-filled binary tree requirement.

9Interview questions

Why are heaps complete binary trees?

Completeness keeps the height logarithmic and lets nodes map naturally to array indices.

10Try it yourself
