Cycle Detection — Undirected in Python

In undirected DFS, a visited neighbor that is not the parent proves a cycle.

1Why this matters

It distinguishes trees from cyclic networks.

Approach

Parent tracking is the key.

2Python implementation

Python
g={1:[2,3],2:[1,3],3:[1,2]}; seen=set()
def cycle(u,p):
 seen.add(u)
 for v in g[u]:
  if v not in seen:
   if cycle(v,u): return True
  elif v!=p: return True
 return False
print(cycle(1,-1))

3Expected output

OUTPUT / RESULT
True

4Line by line

CodeMeaning

5Dry run

3 sees already-visited 1, which is not its parent, so a cycle exists.

6Complexity

O(V+E).

Use to validate undirected trees and networks.
