Recognize a Skewed Binary Tree in Python

A skewed binary tree has each node continuing through only one child, making the tree behave like a chain.

1Why this matters

Recognizing skewed shape helps explain why an unbalanced BST can degrade from logarithmic height to linear height.

Approach

Walk down the tree and reject any node that has both children. A node with two children is not part of a purely skewed chain.

2Python implementation

Python
class Node:
    def __init__(self, value, left=None, right=None):
        self.value = value
        self.left = left
        self.right = right

def is_skewed(root):
    while root:
        if root.left and root.right:
            return False
        root = root.left or root.right
    return True

root = Node(1, Node(2, None, Node(3)))
print(is_skewed(root))

5Dry run

Node 1 has only a left child; node 2 has only a right child; node 3 is a leaf. The structure is a chain, so it is skewed.

6Complexity

O(h) time; O(1) extra space.

7Common mistakes

  • Calling every unbalanced tree skewed.
  • Forgetting that the single-child direction can change.

8When to use it

Use to detect a tree whose nodes each have at most one child along the path.

9Interview questions

Why is a skewed BST slow?

Its height becomes O(n), so search, insertion and deletion can degrade to O(n).
