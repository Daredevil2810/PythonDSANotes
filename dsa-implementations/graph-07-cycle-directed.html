Cycle Detection — Directed in Python

In directed DFS, an edge to a currently active node is a cycle.

1Why this matters

It is essential for dependency validation.

Approach

Three states: unvisited, visiting, finished.

2Python implementation

Python
g={"A":["B"],"B":["C"],"C":["A"]}; state={}
def dfs(u):
 state[u]=1
 for v in g[u]:
  if state.get(v,0)==1: return True
  if state.get(v,0)==0 and dfs(v): return True
 state[u]=2; return False
print(dfs("A"))

3Expected output

OUTPUT / RESULT
True

4Line by line

CodeMeaning
state[u]=1Marks u as active on the recursion path.
state[u]=2Marks u finished.

5Dry run

C points back to active A, proving a directed cycle.

6Complexity

O(V+E).

7Common mistakes

  • Using the undirected parent rule.

8When to use it

Use for prerequisite/dependency cycles.
