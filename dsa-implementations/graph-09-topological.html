Topological Sort — Kahn in Python

A topological order places every prerequisite before its dependent node.

1Why this matters

It models build systems, courses, and dependency graphs.

Approach

Kahn = indegree + queue.

2Python implementation

Python
from collections import deque
g={"A":["C"],"B":["C"],"C":["D"],"D":[]}; indeg={u:0 for u in g}
for u in g:
 for v in g[u]: indeg[v]+=1
q=deque([u for u in g if indeg[u]==0]); order=[]
while q:
 u=q.popleft(); order.append(u)
 for v in g[u]:
  indeg[v]-=1
  if indeg[v]==0:q.append(v)
print(order)

3Expected output

OUTPUT / RESULT
['A', 'B', 'C', 'D']

4Line by line

CodeMeaning
indeg[v]+=1Counts prerequisites.
indeg[v]-=1Removes a completed prerequisite.

5Dry run

A and B become ready first; C then D follow.

6Complexity

O(V+E).

7Common mistakes

  • Using it on cyclic input without checking output size.

8When to use it

Use on DAG dependencies.

9Interview questions

Cycle detection with Kahn?

If fewer than V nodes are output, a cycle exists.
