Depth-First Search in Python

DFS follows one branch deeply before backtracking.

1Why this matters

It is the base for components, cycle detection, topological sorting, bridges, and SCCs.

Approach

Stack = depth.

2Python implementation

Python
g={"A":["B","C"],"B":["D"],"C":["D"],"D":[]}
seen=set(); order=[]
def dfs(u):
 seen.add(u); order.append(u)
 for v in g[u]:
  if v not in seen: dfs(v)
dfs("A"); print(order)

3Expected output

OUTPUT / RESULT
['A', 'B', 'D', 'C']

4Line by line

CodeMeaning
dfs(v)Finishes one branch before moving to the next.

5Dry run

A→B→D, backtrack, then C.

6Complexity

O(V+E) time; O(V) space.

7Common mistakes

  • No visited set in cyclic graphs.
  • Recursion depth on huge graphs.

8When to use it

Use for structural graph algorithms.

9Interview questions

BFS vs DFS?

BFS is layer-first; DFS is branch-first.
