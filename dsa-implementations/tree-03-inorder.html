Inorder Traversal in Python

Inorder is left → root → right.

1Why this matters

For a BST, inorder returns values in sorted order.

Approach

Think: left, root, right.

2Python implementation

Python
class Node:
    def __init__(self, value, left=None, right=None):
        self.value = value
        self.left = left
        self.right = right
def inorder(node):
    if not node: return
    inorder(node.left)
    print(node.value, end=" ")
    inorder(node.right)

root = Node(2, Node(1), Node(3))
inorder(root)

3Expected output

OUTPUT / RESULT
1 2 3

4Line by line

CodeMeaning
inorder(node.left)Finishes the left subtree first.
print(node.value, end=" ")Processes the root between both subtrees.

5Dry run

1 prints before 2, and 3 prints after 2.

6Complexity

O(n) time; O(h) recursion space.

7Common mistakes

  • Assuming inorder is sorted for every binary tree.

8When to use it

Use for sorted traversal of a BST.

9Interview questions

Why is BST inorder sorted?

BST ordering puts smaller values left and larger values right.
