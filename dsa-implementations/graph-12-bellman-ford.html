Bellman-Ford in Python

Bellman-Ford handles negative edges and can detect reachable negative cycles.

1Why this matters

It is used when Dijkstra’s weight restriction is invalid.

Approach

Repeated edge relaxation is the core.

2Python implementation

Python
edges=[("A","B",4),("A","C",5),("B","C",-2),("C","D",3)]; d={"A":0,"B":float("inf"),"C":float("inf"),"D":float("inf")}
for _ in range(len(d)-1):
 changed=False
 for u,v,w in edges:
  if d[u]!=float("inf") and d[u]+w<d[v]: d[v]=d[u]+w; changed=True
 if not changed: break
print(d)

3Expected output

OUTPUT / RESULT
{'A': 0, 'B': 4, 'C': 2, 'D': 5}

4Line by line

CodeMeaning
d[u]+w<d[v]Relaxes an edge.

5Dry run

C improves from 5 to 2 through B; D then becomes 5.

6Complexity

O(VE) time; O(V) space.

7Common mistakes

  • Stopping after one pass.

8When to use it

Use when negative edges may exist.

9Interview questions

Dijkstra vs Bellman-Ford?

Dijkstra is faster but needs non-negative weights; Bellman-Ford is slower but handles negative edges.
