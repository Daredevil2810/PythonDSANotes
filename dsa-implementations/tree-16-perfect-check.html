Check a Perfect Binary Tree in Python

A perfect binary tree has two children at every internal node and all leaves at the same depth.

1Why this matters

Perfectness combines a branching rule with a depth rule, making it a useful tree-invariant exercise.

Approach

Find the expected leaf depth from the left edge, then verify every leaf reaches exactly that depth and every internal node has two children.

2Python implementation

Python
class Node:
    def __init__(self, value, left=None, right=None):
        self.value = value
        self.left = left
        self.right = right

def left_depth(node):
    depth = 0
    while node:
        depth += 1
        node = node.left
    return depth

def check(node, depth, expected):
    if node is None:
        return True
    if node.left is None and node.right is None:
        return depth == expected
    if node.left is None or node.right is None:
        return False
    return check(node.left, depth + 1, expected) and check(node.right, depth + 1, expected)

root = Node(1, Node(2, Node(4), Node(5)), Node(3, Node(6), Node(7)))
print(check(root, 1, left_depth(root)))

5Dry run

The leftmost path has depth 3. Every leaf is at depth 3 and every internal node has two children, so the tree is perfect.

6Complexity

O(n) time; O(h) recursion space.

7Common mistakes

  • Checking only that the number of nodes is 2^h-1 without validating shape.
  • Confusing perfect with complete.

8When to use it

Use when both equal leaf depth and two-child structure must hold.

9Interview questions

How is a perfect tree different from a full tree?

A full tree only requires 0 or 2 children; a perfect tree also requires all leaves at the same depth.

10Try it yourself

Remove one leaf and verify the tree is no longer perfect.
