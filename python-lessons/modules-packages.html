Modules & packages

Split code across files and reuse code that others wrote.

1What is it?

A module is a single .py file. A package is a folder of modules that contains an __init__.py file. You bring them in with import.

2Why do we need it?

No real project lives in one file. Modules keep code organised, and Python's huge standard library (math, random, os, datetime…) is available just by importing it.

3In plain words

Everyday example

A module is a toolbox with tools for one job. A package is the garage shelf holding several toolboxes. You don't forge a hammer each time: you open the box and take it out.

Precise definition

import math loads the module and you use math.sqrt. from math import sqrt, pi pulls names directly. Imports can be at the top of a file (usual) or inside a function.

4Code, step by step

Using built-in modules

lesson_1.py
import math
print(math.sqrt(25))
print(math.pi)

from math import sqrt, pi
print(sqrt(16))
OUTPUT
5.0
3.141592653589793
4.0
LineWhat it means
import mathLoads the whole math module. You must write math. before its functions.
math.sqrt(25)Square root, always returned as a float.
from math import sqrt, piImports just those two names, so you can use them without the math. prefix.

Making your own module

example.py
# file: greet.py
def say_hello(name):
    return f"Hello, {name}!"

# file: main.py (in the same folder)
import greet
print(greet.say_hello("Devanshu"))
LineWhat it means
# file: greet.pyAny .py file can be imported. The file name (without .py) is the module name.
import greetPython finds greet.py in the same folder and loads it.
greet.say_hello(...)Calls the function that lives inside that module.

5Common mistakes

  • Naming your own file the same as a standard module (e.g. random.py), which hides the real one.
  • from module import * makes it unclear where names come from.
  • Circular imports: file A imports B and B imports A.

6When should I use it?

Split code when a file grows long or when pieces are reusable. Import only what you need.

7Interview questions

Difference between module and package?

A module is a single Python file. A package is a collection of modules in a folder with __init__.py.

How do you import specific things?

from math import sqrt, pi.

Can you import a module inside a function?

Yes, imports can be local or global.

8Try it yourself

Write save_user_info(name, age) that appends name - age to user_info.txt using with, wrapped in try/except/finally. Print User info saved successfully. on success and Operation complete. at the end.

Show hint
Hint: Combine the file and exception lessons: try: → with open(..., "a") → except Exception as e: → finally:.
Show solution
solution.py
def save_user_info(name, age):
    try:
        with open("user_info.txt", "a") as f:
            f.write(f"{name} - {age}\n")
        print("User info saved successfully.")
    except Exception as e:
        print("Error saving user info:", e)
    finally:
        print("Operation complete.")

save_user_info("Devanshu", 22)
OUTPUT
User info saved successfully.
Operation complete.
