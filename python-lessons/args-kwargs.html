*args and **kwargs

Accept any number of inputs in one function.

1What is it?

args collects any number of extra positional arguments into a tuple. kwargs collects any number of extra keyword* arguments into a dictionary.

2Why do we need it?

Sometimes you can't know how many inputs a function will get, for example a total() that adds 2 numbers today and 20 tomorrow. You also see args, *kwargs constantly in Django and library code.

3In plain words

Everyday example

You are ordering at a food stall. args is "and a few more things, whatever you have" in a plain list. kwargs is "and these special requests"*, each with a label: spice="high", extra="cheese".

Precise definition

The single packs leftover positional arguments into a tuple. The double packs leftover keyword arguments into a dict*. The names args and kwargs are only convention; the stars are what matter.

4Code, step by step

*args

lesson_1.py
def total(*nums):
    print(nums)
    return sum(nums)

print(total(1, 2, 3))
print(total(10, 20, 30, 40, 50))
OUTPUT
(1, 2, 3)
6
(10, 20, 30, 40, 50)
150
LineWhat it means
def total(*nums):The star means: put every positional argument into one tuple called nums.
print(nums)Shows that it really is a tuple.
return sum(nums)sum() adds up all items, however many there are.

All of it together

lesson_2.py
def info(name, *skills, **details):
    print("Name:", name)
    print("Skills:", skills)
    print("Details:", details)

info("Devanshu", "Python", "Django", location="India", experience="Fresher")
OUTPUT
Name: Devanshu
Skills: ('Python', 'Django')
Details: {'location': 'India', 'experience': 'Fresher'}
LineWhat it means
def info(name, *skills, **details):name is a normal parameter. skills swallows any extra positional values. *details swallows any extra key=value pairs.
info("Devanshu", "Python", "Django", ...)"Devanshu" → name. "Python" and "Django" → the skills tuple.
location="India", experience="Fresher"These have names, so they go into the details dictionary.

5Common mistakes

  • Putting args after kwargs. The order must be: normal parameters, args, keyword defaults, **kwargs.
  • Expecting args to be a list. It is a tuple.
  • Passing keyword arguments to a function that only has *args; that raises a TypeError.

6When should I use it?

Use args/*kwargs for flexible helpers, wrappers that pass inputs on to another function, and when you cannot predict the number of inputs.

7Interview questions

What are args and *kwargs used for?

args accepts multiple positional arguments (as a tuple). *kwargs accepts multiple keyword arguments (as a dictionary).

Can you use both in one function?

Yes, in this order: def func(positional, args, keyword_default=None, *kwargs).

8Try it yourself

Write average(*nums) that returns the average of any numbers. Print average(10, 20, 30).

Show hint
Hint: Total divided by how many: sum(nums) / len(nums).
Show solution
solution.py
def average(*nums):
    return sum(nums) / len(nums)

print(average(10, 20, 30))
OUTPUT
20.0
