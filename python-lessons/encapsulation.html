Encapsulation & private attributes

Protect data so it is changed only in safe ways.

1What is it?

Encapsulation means restricting direct access to data and exposing safe methods instead. In Python, a name that starts with a double underscore (__balance) is treated as private.

2Why do we need it?

If anyone can set balance = -999 directly, bugs are guaranteed. With encapsulation, changes go through methods like deposit() which can check the rules.

3In plain words

Everyday example

A bank doesn't let you walk into the vault. You talk to the cashier, who follows rules for deposits and withdrawals. The vault is the private data; the cashier is the method.

Precise definition

Python does not have true private members. A double-underscore name is name-mangled to _ClassName__name, which makes accidental access fail. A single underscore (_x) is only a convention that means "internal, please don't touch".

4Code, step by step

BankAccount

lesson_1.py
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance      # private

    def deposit(self, amount):
        self.__balance += amount

    def get_balance(self):
        return self.__balance

acc = BankAccount(1000)
acc.deposit(500)
print(acc.get_balance())

try:
    print(acc.__balance)
except AttributeError:
    print("AttributeError: __balance is private")
OUTPUT
1500
AttributeError: __balance is private

5Common mistakes

  • Believing __x is truly secret. It can still be reached as _BankAccount__balance.
  • Making everything private. Do it only for data that needs protecting.

6When should I use it?

Use it for data with rules (money, passwords, counters) where you want to control how it changes.

7Interview questions

How do you make attributes private in Python?

Prefix the name with a double underscore (__).

What is encapsulation?

Hiding internal data and exposing it only through methods.

solution.py
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance

    def withdraw(self, amount):
        if amount <= self.__balance:
            self.__balance -= amount
        else:
            print("Insufficient funds")

    def get_balance(self):
        return self.__balance

acc = BankAccount(1000)
acc.withdraw(1500)
acc.withdraw(300)
print(acc.get_balance())
OUTPUT
Insufficient funds
700
