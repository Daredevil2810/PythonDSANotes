Python libraries, for working with data

Pandas for tables, NumPy for fast number crunching and Matplotlib for charts. Short lessons with code you can run, the exact output and a practice task.

Pandas for Data Analysis

Load, clean and explore tables of data with Pandas, the most used Python library for data work.

  • Pandas Series: labelled 1-D data — Meet Pandas and its simplest building block, the Series: one column of data with a label on every value.
  • Pandas DataFrame: tables in Python — Create a table, pick out columns and rows, and add a new column calculated from the others.
  • Read and save CSV and JSON files — Load data from files into a DataFrame, pick only the columns you need and save your results back to disk.
  • Explore, sort and filter data — Get a quick overview of a DataFrame, then sort it and pull out only the rows that match a rule.
  • Handle missing values — Find empty cells, then either drop those rows or fill the gaps with a sensible value.
  • Fix wrong formats, wrong values and duplicates — Convert messy dates, spot and repair impossible values, and remove duplicate rows.
  • Group and summarise data with groupby — Split a table into groups, summarise each group (sum, mean, count) and put the answers back together.
  • Correlation: do two columns move together? — Measure how strongly two numeric columns are related with `corr()`, and learn how to read the result honestly.

NumPy for Numerical Work

Fast arrays for numbers: create, slice, reshape, summarise and filter data the way data-science libraries do.

  • NumPy arrays: fast lists of numbers — Meet NumPy and its array, and see why `array * 2` behaves very differently from `list * 2`.
  • Create arrays: zeros, ones, arange, linspace — Build arrays without typing every number: starter grids, number ranges and evenly spaced points.
  • Indexing and slicing arrays — Pick out single values, rows, columns and blocks from an array, and learn why a slice is a view, not a copy.
  • Shape, reshape and transpose — Read the shape of an array and re-arrange the same numbers into rows and columns without changing the data.
  • Array maths and summaries: sum, mean, max, axis — Do maths on a whole array at once, then summarise it by overall, by column and by row.
  • Broadcasting: maths between different shapes — See how NumPy combines arrays of different shapes, such as a table plus a single row, without copying data.
  • Filter arrays with conditions and np.where — Pick values that match a rule, count them, change them, and label them with np.where.
  • Random numbers and simulations — Generate random numbers the modern way, make them repeatable with a seed, and run a small dice simulation.

Matplotlib for Charts

Turn numbers into line, bar, scatter, histogram and pie charts, then combine and save them.

  • Your first chart with Matplotlib — Install Matplotlib, draw a line chart in three lines, and learn how x and y values turn into a picture.
  • Titles, labels, legends and grids — Turn a bare chart into one that explains itself, with a title, axis labels, a legend and a grid.
  • Markers, colours and line styles — Change how a line looks: add markers, pick colours, switch to dashed lines and set the thickness.
  • Bar charts: compare categories — Draw vertical and horizontal bar charts, colour the bars and print the value on top of each one.
  • Scatter plots: find relationships — Plot pairs of values as dots to see whether two things move together, and add colour and size to show more.
  • Histograms: see how values are spread — Group numbers into ranges called bins and draw how many fall in each, to see the shape of your data.
  • Pie charts: parts of a whole — Draw a pie chart, print percentages on the slices, pull a slice out and keep it readable.
  • Subplots and saving charts — Put several charts in one figure, meet the figure/axes way of working, and save your chart as an image file.
