Trees

  • Build a Binary Tree in Python — A binary tree gives each node at most a left and a right child.
  • Preorder Traversal in Python — Preorder is root → left → right.
  • Inorder Traversal in Python — Inorder is left → root → right.
  • Postorder Traversal in Python — Postorder is left → right → root.
  • Level Order Traversal in Python — Level order is tree BFS: process nodes by depth using a queue.
  • Maximum Depth / Height in Python — Maximum depth is one plus the deeper child depth, with empty tree depth 0.
  • Count Leaf Nodes in Python — A leaf has no left and no right child.
  • Binary Tree Diameter in Python — The diameter is the longest path between two nodes; here it is measured in edges.
  • Check Balanced Tree in Python — A height-balanced binary tree keeps child heights within one at every node.
  • BST Search in Python — A BST stores smaller values left and larger values right.
  • BST Insertion in Python — BST insertion places a value while preserving the ordering invariant.
  • BST Deletion in Python — BST deletion has leaf, one-child, and two-child cases.
  • AVL Rotation — LL Case in Python — AVL trees rebalance after updates using rotations. This program demonstrates a right rotation for a left-left imbalance.
  • Serialize & Deserialize Tree in Python — Serialization stores tree values and null markers so the exact shape can be reconstructed.
  • Check a Full Binary Tree in Python — A full binary tree has either 0 or 2 children at every node.
  • Check a Perfect Binary Tree in Python — A perfect binary tree has two children at every internal node and all leaves at the same depth.
  • Check a Complete Binary Tree in Python — A complete binary tree fills every level except possibly the last, and the last level is filled from left to right.
  • Recognize a Skewed Binary Tree in Python — A skewed binary tree has each node continuing through only one child, making the tree behave like a chain.

Graphs

  • Adjacency List in Python — Store each vertex with its neighbors.
  • Adjacency Matrix in Python — Store graph connectivity in a V×V table.
  • Breadth-First Search in Python — BFS explores by distance layers using a queue.
  • Depth-First Search in Python — DFS follows one branch deeply before backtracking.
  • Connected Components in Python — A component is a maximal reachable group in an undirected graph.
  • Cycle Detection — Undirected in Python — In undirected DFS, a visited neighbor that is not the parent proves a cycle.
  • Cycle Detection — Directed in Python — In directed DFS, an edge to a currently active node is a cycle.
  • Bipartite Check in Python — A bipartite graph can be colored with two colors so every edge crosses colors.
  • Topological Sort — Kahn in Python — A topological order places every prerequisite before its dependent node.
  • Shortest Path — Unweighted in Python — BFS gives minimum edge count when every edge has equal cost.
  • Dijkstra Shortest Path in Python — Dijkstra finds single-source shortest paths with non-negative edge weights.
  • Bellman-Ford in Python — Bellman-Ford handles negative edges and can detect reachable negative cycles.
  • Floyd-Warshall in Python — Floyd-Warshall computes all-pairs shortest paths using DP over intermediate vertices.
  • Disjoint Set Union in Python — DSU maintains disjoint sets with fast find and union using compression and size/rank.
  • Kruskal MST in Python — Kruskal builds a minimum spanning tree by taking lightest edges that do not create a cycle.
  • Prim MST in Python — Prim grows an MST by repeatedly taking the cheapest frontier edge.
  • Strongly Connected Components — Kosaraju in Python — An SCC is a maximal directed group where every vertex can reach every other.
  • Model Directed vs Undirected Graphs in Python — Directed edges have a direction; undirected edges represent a two-way relationship.
  • Model Weighted vs Unweighted Graphs in Python — Weighted graphs attach a cost/value to each edge; unweighted graphs treat each edge as equal cost.
