Python, from the ground up

Seventeen short lessons that cover the core of the language, each with a plain-language explanation, line-by-line code and a practice task.

Python Basics & Data Types

What Python is, how it runs your code, and the data types you will use every day.

  • What is Python & how it runs — What kind of language Python is, and what happens between pressing Run and seeing output.
  • Variables & data types — Store values in named boxes, and meet the eight types you will use every single day.

Control Flow & Loops

Make decisions and repeat work: the logic behind almost every program.

  • Decisions: if, elif, else — Make your program choose between paths based on a condition.
  • Loops: for, while & range() — Repeat work without repeating code.
  • break, continue, pass, for…else & nested loops — Control exactly how a loop runs, and write the classic prime-number check.

Functions & Lambda

Package logic into reusable pieces, then learn the shortcuts.

  • Functions: def, parameters & return — Write a piece of logic once and reuse it anywhere.
  • *args and **kwargs — Accept any number of inputs in one function.
  • Scope & the LEGB rule — Where a variable lives, and how Python finds it.
  • lambda, map, filter & reduce — Tiny one-line functions, and the tools that use them.

Object-Oriented Programming

Classes and objects, and why Django (and most big codebases) are built on them.

  • Classes & objects — Bundle data and behaviour together using a blueprint.
  • Instance, class & static methods — Three kinds of methods, and when each one fits.
  • Inheritance, super() & overriding — Build a new class on top of an existing one.
  • Encapsulation & private attributes — Protect data so it is changed only in safe ways.
  • Polymorphism & abstraction — Same method name, different behaviour, and forcing a structure on child classes.

Files, Exceptions & Modules

Read and write files safely, handle errors, and organise code into modules.

  • File handling — Read from and write to files, safely.
  • Exception handling — Keep your program alive when things go wrong.
  • Modules & packages — Split code across files and reuse code that others wrote.
