Python interview questions

Practice the Python concepts already taught in PyDSA, with concise answers and interview tips.

What is the difference between a list and a tuple in Python?

A list is mutable, so its contents can be changed after creation. A tuple is immutable, so its structure cannot be changed after creation. Both preserve order and can hold mixed types, but tuples are useful for fixed records and can be hashable when all their elements are hashable.

Tip: Mention mutability first, then give a practical use case for each.

What does mutable versus immutable mean in Python?

A mutable object can be changed in place after it is created. An immutable object cannot be changed in place; an apparent modification creates another object instead. Lists and dictionaries are mutable, while integers, strings and tuples are immutable.

Tip: Use a list append versus string concatenation as a simple comparison.

What is the difference between a dictionary and a set?

A dictionary stores key-value pairs, while a set stores unique values. Both are hash-based and provide average constant-time membership or key lookup in typical cases.

Tip: Say 'unique values' for sets and 'mapping from key to value' for dictionaries.

What is a list comprehension and when would you use it?

A list comprehension is a compact way to build a list from an iterable, optionally applying a condition. It is useful when the transformation is short and remains readable; a normal loop is better when the logic becomes complicated.

Tip: Interviewers often care more about readability than clever one-line code.

What is a generator in Python?

A generator produces values lazily, usually with yield, instead of creating the entire result in memory at once. Iterating over it requests values as they are needed, which can reduce memory usage for large sequences.

Tip: Contrast yield with return: return finishes the function, while yield pauses a generator and resumes it later.

What is the difference between yield and return?

return sends a final value back and ends the function call. yield produces a value from a generator and suspends execution so the function can continue from that point when the next value is requested.

Tip: Mention lazy evaluation when explaining why yield is useful.

What are *args and **kwargs?

args collects extra positional arguments into a tuple, while *kwargs collects extra keyword arguments into a dictionary. They are useful when a function needs a flexible number of arguments.

Tip: Be precise: the names args and kwargs are conventions; the and * syntax is what matters.

Why can a mutable default argument be dangerous?

Default argument expressions are evaluated once when the function is defined, not every time it is called. If the default is a mutable object such as a list, calls can accidentally share and modify the same object.

Tip: The common safe pattern is None as the default followed by creating a new list inside the function.

What is the LEGB rule?

LEGB describes Python's name lookup order: Local, Enclosing, Global, then Built-in. Python searches those scopes in that order when resolving a name.

Tip: Give a nested-function example if the interviewer asks what Enclosing means.

What is a lambda function?

A lambda is a small anonymous function written as an expression. It is useful for short operations passed to functions such as sorted, map or filter, but a normal def is clearer for substantial logic.

Tip: Do not describe lambda as a different kind of runtime function; focus on its concise syntax and intended use.

What are map and filter used for?

map applies a function to each item of an iterable, while filter keeps items for which a predicate is true. In modern Python, comprehensions are often clearer for simple transformations and filtering.

Tip: Explain the result as an iterable rather than assuming map or filter always creates a list.

What is the difference between a class and an object?

A class defines the structure and behavior that instances should have. An object is a particular instance created from that class, with its own state.

Tip: A class is the blueprint; an object is one concrete instance, but keep the explanation technical.

What is self in a Python class?

self is the conventional name for the first parameter of an instance method. It refers to the current object, allowing the method to access that object's attributes and other instance methods.

Tip: self is not a reserved keyword, but using the convention is strongly recommended.

What does __init__ do?

__init__ is an initializer method that runs after a new instance is created. It is commonly used to set the object's initial instance attributes.

Tip: Technically, object creation and initialization are separate steps; __new__ participates in creation and __init__ initializes the instance.

What is the difference between @classmethod and @staticmethod?

A class method receives the class as its first argument, conventionally cls, and can work with class-level state. A static method receives neither the instance nor the class automatically; it is simply a function placed in the class namespace.

Tip: Use classmethod for alternate constructors as a common example.

What is inheritance in Python?

Inheritance lets a class derive behavior and attributes from another class. The child class can reuse, extend or override inherited behavior.

Tip: Mention that inheritance is useful for a genuine is-a relationship, not simply for sharing unrelated code.

What does super() do?

super() provides access to methods from a parent or next class in the method resolution order. It is commonly used to extend a parent's initializer or behavior instead of duplicating it.

Tip: In multiple inheritance, explain that super follows the method resolution order rather than meaning 'call my immediate parent' in every case.

What is polymorphism in Python?

Polymorphism means code can work with objects through a common behavior or interface without needing to know their concrete type. Python's duck typing often enables this naturally.

Tip: A useful phrase is 'if an object supports the required operation, the caller can use it.'

What is the purpose of try, except, else and finally?

try contains code that may raise an exception, except handles selected exceptions, else runs when the try block succeeds, and finally runs whether an exception occurred or not. finally is commonly used for cleanup.

Tip: Avoid catching every exception with a bare except unless you have a specific reason.

Why would you use raise?

raise lets your code explicitly signal an exception. It is useful when an input violates a function's requirements or when you want to propagate an exception after adding context.

Tip: Choose a specific built-in or custom exception type when possible.

Why is with open(...) recommended for files?

A with statement uses a context manager to ensure the file is properly closed when the block exits, including when an exception occurs. It makes resource management safer and clearer.

Tip: The important idea is deterministic cleanup, not merely shorter syntax.

What is the difference between read(), readline() and readlines()?

read() reads the requested content as one string, readline() reads one line, and readlines() returns the remaining lines as a list. For very large files, iterating over the file object can be more memory efficient than readlines().

Tip: Mention file size when discussing which method to choose.

What is the difference between a module and a package?

A module is a Python file that contains code such as functions, classes or variables. A package is a directory-based namespace used to organize related modules; modern Python packages can be namespace packages even without an __init__.py file.

Tip: Keep the distinction about organization rather than saying every package must have __init__.py.

What happens when you import a module?

Python finds the module using its import system, executes its top-level code the first time it is imported in a process, and binds the requested module or names in the importing namespace. Loaded modules are cached in sys.modules.

Tip: Avoid saying the whole module executes on every import; caching changes that behavior.

What is the difference between == and is?

== compares values for equality, while is checks whether two references point to the same object. Use is for identity checks such as value is None, not as a general substitute for ==.

Tip: The classic interview example is None: use is None.

What is the difference between a shallow copy and a deep copy?

A shallow copy creates a new outer container but keeps references to nested objects. A deep copy recursively copies nested objects as well, so changes to nested mutable data are separated.

Tip: Explain the difference with a nested list rather than only giving definitions.

What is the Python GIL?

In CPython, the Global Interpreter Lock allows only one thread at a time to execute Python bytecode in a process. It simplifies parts of memory management and interpreter internals, but it limits CPU-bound parallelism with ordinary threads; multiprocessing or other approaches can be used when true CPU parallelism is needed.

Tip: Qualify the answer with CPython; the GIL is not a universal property of every Python implementation.

What is the difference between threading and multiprocessing in Python?

Threads share a process's memory and are useful for many I/O-bound workloads. Separate processes have independent memory and can achieve CPU parallelism in CPython, but they have higher communication and startup costs.

Tip: Tie the choice to the workload: I/O waiting versus CPU computation.

What is the typical time complexity of dictionary lookup?

Average-case lookup, insertion and deletion are O(1) because dictionaries use hashing. Worst-case behavior can degrade, so O(1) should be described as average or expected rather than guaranteed in every theoretical situation.

Tip: Interviewers often test whether you know the difference between average and worst-case complexity.

What is the difference between pass, break and continue?

pass does nothing and acts as a placeholder. break exits the nearest loop completely. continue skips the rest of the current iteration and moves to the next iteration.

Tip: A short loop example makes the distinction easy to communicate.
