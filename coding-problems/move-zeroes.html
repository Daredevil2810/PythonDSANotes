Move Zeroes — Python Solution

Move every zero to the end while keeping the non-zero values in their original order.

1How to recognise it

Partition useful values and unwanted values while preserving relative order.

2Key idea

Keep a write pointer for the next non-zero position, then fill the remaining positions with zeroes.

3Approach, step by step

  1. Scan the array with a read pointer.
  2. When a non-zero appears, place it at the write position and advance write.
  3. Fill from write onward with zeroes.

4Python solution

solution.py
def move_zeroes(nums):
    write = 0
    for x in nums:
        if x != 0:
            nums[write] = x
            write += 1
    while write < len(nums):
        nums[write] = 0
        write += 1

5Dry run

[0,1,0,3,12] → write 1,3,12 forward → remaining positions become 0 → [1,3,12,0,0].

6Time and space complexity

O(n) time, O(1) space.

7Common mistakes

  • Sorting the array.
  • Moving zeroes with repeated insert/delete operations.
