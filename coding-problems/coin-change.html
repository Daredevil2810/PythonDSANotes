Coin Change — Python Solution

Find the minimum number of coins needed to make a target amount, or -1 if impossible.

1How to recognise it

Minimise a cost over repeated choices where smaller states lead to larger states.

2Key idea

dp[a] stores the fewest coins needed for amount a. Try every coin as the final choice.

3Approach, step by step

  1. Initialise dp[0] = 0 and other states to infinity.
  2. For each amount, try every coin that fits.
  3. Use 1 + dp[amount-coin].
  4. Return dp[amount] if reachable.

4Python solution

solution.py
def coin_change(coins, amount):
    dp = [amount + 1] * (amount + 1)
    dp[0] = 0
    for a in range(1, amount + 1):
        for coin in coins:
            if coin <= a:
                dp[a] = min(dp[a], 1 + dp[a-coin])
    return -1 if dp[amount] > amount else dp[amount]

5Dry run

coins=[1,2,5], amount=11 → dp[11] eventually becomes 3 via 5+5+1.

6Time and space complexity

O(amount × number_of_coins) time, O(amount) space.

7Common mistakes

  • Assuming greedy always gives the minimum.
  • Using an invalid base value for unreachable states.
