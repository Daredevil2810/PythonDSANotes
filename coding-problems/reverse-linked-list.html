Reverse Linked List — Python Solution

Reverse all next pointers so the original tail becomes the new head.

1How to recognise it

A linked structure must be reversed without losing the next node.

2Key idea

Keep previous, current, and next references. Reverse one pointer at a time.

3Approach, step by step

  1. Start prev as None and current at head.
  2. Save current.next before changing it.
  3. Point current.next to prev.
  4. Move prev and current forward.
  5. Return prev.

4Python solution

solution.py
def reverse_list(head):
    prev = None
    cur = head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt
    return prev

5Dry run

1→2→3→None becomes None←1←2←3, so 3 is the new head.

6Time and space complexity

O(n) time, O(1) extra space.

7Common mistakes

  • Changing next before saving it.
  • Returning the old head.

8Interview follow-ups

Why must next be saved before reversing current.next?
