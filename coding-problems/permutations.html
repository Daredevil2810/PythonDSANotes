Permutations — Python Solution

Generate all orderings of distinct numbers.

1How to recognise it

Every position can choose one unused value.

2Key idea

Build a path and choose any unused number for the next position.

3Approach, step by step

  1. Track the current path and used values.
  2. If path length equals n, save a copy.
  3. Try each unused value.
  4. Choose it, recurse, then undo.

4Python solution

solution.py
def permute(nums):
    out, path = [], []
    used = [False] * len(nums)
    def dfs():
        if len(path) == len(nums):
            out.append(path.copy()); return
        for i, x in enumerate(nums):
            if used[i]: continue
            used[i] = True; path.append(x)
            dfs()
            path.pop(); used[i] = False
    dfs()
    return out

5Dry run

[1,2,3] → choose 1, then 2, then 3 → backtrack and try 3 at the second position, etc.

6Time and space complexity

O(n·n!) time including output, O(n) recursion/used space excluding output.

7Common mistakes

  • Reusing a value in the same permutation.
  • Failing to restore used state after recursion.
