Binary Search — Python Solution

Find a target in a sorted array and return its index, or -1 if absent.

1How to recognise it

Sorted data and a yes/no decision that becomes monotonic.

2Key idea

Each comparison eliminates half the remaining search space.

3Approach, step by step

  1. Set left and right boundaries.
  2. Check the middle value.
  3. If it is too small, discard the left half; if too large, discard the right half.
  4. Repeat until the range is empty.

4Python solution

solution.py
def binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

5Dry run

[1,3,5,7,9], target 7 → mid 5 is too small → search right half → find 7.

6Time and space complexity

O(log n) time, O(1) space.

7Common mistakes

  • Wrong boundary updates causing infinite loops.
  • Using binary search on data that is not ordered or otherwise monotonic.
