Word Break — Python Solution

Decide whether the whole string can be split into one or more dictionary words.

1How to recognise it

Can a string be segmented into valid dictionary words?

2Key idea

dp[i] means the prefix ending before i can be formed. Try dictionary words that can start at each reachable position.

3Approach, step by step

  1. Set dp[0] = true for the empty prefix.
  2. For each end position, test possible start positions.
  3. If dp[start] is true and s[start:end] is a dictionary word, set dp[end] true.
  4. Return dp[len(s)].

4Python solution

solution.py
def word_break(s, word_dict):
    words = set(word_dict)
    dp = [False] * (len(s) + 1)
    dp[0] = True
    for end in range(1, len(s) + 1):
        for start in range(end):
            if dp[start] and s[start:end] in words:
                dp[end] = True
                break
    return dp[-1]

5Dry run

'leetcode' with ['leet','code'] → dp[4] true from leet → dp[8] true from code.

6Time and space complexity

O(n²) substring checks, with hash-set lookup average O(1); slicing costs depend on language/runtime.

7Common mistakes

  • Defining dp as a property of individual characters instead of prefixes.
  • Greedy longest-word matching.
