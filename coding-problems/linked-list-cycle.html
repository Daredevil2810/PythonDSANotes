Linked List Cycle — Python Solution

Determine whether following next pointers eventually revisits a node.

1How to recognise it

Detect a cycle without extra memory.

2Key idea

A fast pointer moves two steps and a slow pointer one. If a cycle exists, they eventually meet.

3Approach, step by step

  1. Set slow and fast to head.
  2. Move slow one step and fast two steps while possible.
  3. If they point to the same node, a cycle exists.
  4. If fast reaches None, there is no cycle.

4Python solution

solution.py
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False

5Dry run

In a cycle, fast gains one node per iteration relative to slow, eventually meeting it.

6Time and space complexity

O(n) time, O(1) space.

7Common mistakes

  • Comparing node values instead of node identity.
  • Dereferencing fast.next without checking fast.
