3Sum — Python Solution

Return unique triplets whose values sum to zero.

1How to recognise it

Find triples meeting a sum condition and avoid duplicates.

2Key idea

Sort first, fix one value, then use two pointers to solve the remaining two-sum problem while skipping duplicates.

3Approach, step by step

  1. Sort the array.
  2. Fix i and skip duplicate fixed values.
  3. Set left=i+1 and right=end.
  4. Move pointers according to the sum and skip duplicate results.

4Python solution

solution.py
def three_sum(nums):
    nums.sort(); out = []
    for i in range(len(nums) - 2):
        if i and nums[i] == nums[i-1]: continue
        l, r = i + 1, len(nums) - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s == 0:
                out.append([nums[i], nums[l], nums[r]])
                l += 1; r -= 1
                while l < r and nums[l] == nums[l-1]: l += 1
                while l < r and nums[r] == nums[r+1]: r -= 1
            elif s < 0: l += 1
            else: r -= 1
    return out

5Dry run

[-1,0,1,2,-1,-4] → sorted → fix -1 → pairs 0+1 and -1+2 give the two unique triples.

6Time and space complexity

O(n²) time after sorting, O(1) extra space excluding output.

7Common mistakes

  • Forgetting duplicate skipping.
  • Moving the wrong pointer based on the sum.
