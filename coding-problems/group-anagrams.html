Group Anagrams — Python Solution

Group words that contain the same letters with the same frequencies.

1How to recognise it

Different strings belong to the same group when a canonical representation matches.

2Key idea

Use a frequency signature (or sorted string) as the dictionary key.

3Approach, step by step

  1. Create a map from signature to list of words.
  2. Build a 26-count signature for each lowercase word.
  3. Append the word to its signature's group.
  4. Return the groups.

4Python solution

solution.py
from collections import defaultdict

def group_anagrams(strs):
    groups = defaultdict(list)
    for word in strs:
        count = [0] * 26
        for ch in word:
            count[ord(ch) - ord('a')] += 1
        groups[tuple(count)].append(word)
    return list(groups.values())

5Dry run

'eat', 'tea', 'ate' all create the same frequency tuple, so they share one group.

6Time and space complexity

O(n·k) time for n words of average length k; O(n·k) output/storage.

7Common mistakes

  • Using a mutable list directly as a dictionary key.
  • Using a signature that loses character frequency.
