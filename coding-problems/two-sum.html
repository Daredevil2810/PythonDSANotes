Two Sum — Python Solution

Return the indices of two different numbers that add up to target. You only need one valid pair.

1How to recognise it

Find two values whose sum equals a target.

2Key idea

Store each value's index while scanning. For the current value x, the needed partner is target - x.

3Approach, step by step

  1. Create an empty map from value to index.
  2. For each number, calculate the complement target - number.
  3. If the complement is already in the map, return its saved index and the current index.
  4. Otherwise save the current number and index.

4Python solution

solution.py
def two_sum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return [seen[need], i]
        seen[x] = i
    return []

5Dry run

nums = [2, 7, 11, 15], target = 9 → see 2 → need 7; see 7 → 7 is already stored → [0, 1].

6Time and space complexity

O(n) time, O(n) extra space.

7Common mistakes

  • Using the same element twice.
  • Returning values instead of indices.
  • Checking only after overwriting a value in a way that breaks duplicate cases.
