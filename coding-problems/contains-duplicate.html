Contains Duplicate — Python Solution

Return true if any number occurs at least twice.

1How to recognise it

Need to know whether a value has appeared before.

2Key idea

A set gives average O(1) membership checks while scanning once.

3Approach, step by step

  1. Create an empty set.
  2. For each number, check whether it is already present.
  3. If yes, return true; otherwise add it.
  4. Return false after the scan.

4Python solution

solution.py
def contains_duplicate(nums):
    seen = set()
    for x in nums:
        if x in seen:
            return True
        seen.add(x)
    return False

5Dry run

[1,2,3,1] → store 1,2,3 → the next 1 is already present → true.

6Time and space complexity

O(n) average time, O(n) space.

7Common mistakes

  • Using nested loops when a set solves the membership problem directly.
