Best Time to Buy and Sell Stock — Python Solution

Choose one day to buy and a later day to sell for the largest positive difference.

1How to recognise it

Choose a later value after an earlier low value to maximise profit.

2Key idea

Track the cheapest price seen so far and the best profit produced by selling today.

3Approach, step by step

  1. Start with the first price as the minimum.
  2. For each price, update the best profit using price - minimum.
  3. Then update the minimum price.
  4. Return the best profit.

4Python solution

solution.py
def max_profit(prices):
    low = prices[0]
    best = 0
    for price in prices[1:]:
        best = max(best, price - low)
        low = min(low, price)
    return best

5Dry run

[7,1,5,3,6,4] → low becomes 1; selling at 5 gives 4; selling at 6 gives 5 → answer 5.

6Time and space complexity

O(n) time, O(1) space.

7Common mistakes

  • Allowing the sell day before the buy day.
  • Trying every pair unnecessarily.
