Course Schedule — Python Solution

Determine whether every course can be completed given prerequisite edges.

1How to recognise it

Prerequisites form a directed dependency graph; detect whether all nodes can be ordered.

2Key idea

A valid course order exists exactly when the directed graph has no cycle. Kahn's algorithm repeatedly removes zero-indegree nodes.

3Approach, step by step

  1. Build adjacency lists and indegrees.
  2. Queue every node with indegree zero.
  3. Remove a node and reduce its neighbours' indegrees.
  4. If all courses are removed, there is no cycle.

4Python solution

solution.py
from collections import deque

def can_finish(num_courses, prerequisites):
    graph = [[] for _ in range(num_courses)]
    indeg = [0] * num_courses
    for a, b in prerequisites:
        graph[b].append(a); indeg[a] += 1
    q = deque(i for i in range(num_courses) if indeg[i] == 0)
    done = 0
    while q:
        u = q.popleft(); done += 1
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0: q.append(v)
    return done == num_courses

5Dry run

0→1 and 1→2 gives indegrees [0,1,1] → remove 0, then 1, then 2 → all courses finish.

6Time and space complexity

O(V+E) time, O(V+E) space.

7Common mistakes

  • Reversing prerequisite edge direction.
  • Treating an undirected cycle check as the same problem.
