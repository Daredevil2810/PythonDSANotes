Maximum Subarray — Python Solution

Return the largest sum obtainable from a non-empty contiguous subarray.

1How to recognise it

Find the best contiguous range while scanning left to right.

2Key idea

At each position, decide whether extending the previous subarray is better than starting fresh here.

3Approach, step by step

  1. Keep the best sum ending at the current position.
  2. Update it as max(current value, previous best ending here + current value).
  3. Track the global maximum.

4Python solution

solution.py
def max_sub_array(nums):
    cur = best = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)
        best = max(best, cur)
    return best

5Dry run

[-2,1,-3,4,-1,2,1,-5,4] → the best running segment becomes [4,-1,2,1] with sum 6.

6Time and space complexity

O(n) time, O(1) space.

7Common mistakes

  • Resetting on every negative value instead of comparing with the current value.
  • Initialising best to 0, which fails for all-negative arrays.

8Interview follow-ups

What does cur represent after each iteration?

9Practice
