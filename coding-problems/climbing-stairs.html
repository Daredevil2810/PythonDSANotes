Climbing Stairs — Python Solution

Count ways to reach step n when each move is either 1 or 2 steps.

1How to recognise it

The number of ways to reach a state depends on a few previous states.

2Key idea

Ways(n) = Ways(n-1) + Ways(n-2), so only the previous two results are needed.

3Approach, step by step

  1. Handle the first two base cases.
  2. Iterate from 3 through n.
  3. Compute the next value from the previous two.
  4. Return the final value.

4Python solution

solution.py
def climb_stairs(n):
    a, b = 1, 1
    for _ in range(n):
        a, b = b, a + b
    return a

5Dry run

n=5 → 1,2,3,5,8 ways → answer 8.

6Time and space complexity

O(n) time, O(1) space.

7Common mistakes

  • Using exponential recursion without memoisation.
  • Confusing number of moves with number of ways.
