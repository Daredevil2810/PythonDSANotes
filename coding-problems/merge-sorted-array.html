Merge Sorted Array — Python Solution

Merge nums2 into nums1, where nums1 has enough trailing space.

1How to recognise it

Two sorted sequences need to be merged while preserving order.

2Key idea

Fill from the back so writing a large value never destroys an unread value in nums1.

3Approach, step by step

  1. Point one pointer at the last real value in nums1 and one at the end of nums2.
  2. Compare the two values.
  3. Write the larger value at the final free position.
  4. Copy any remaining nums2 values.

4Python solution

solution.py
def merge(nums1, m, nums2, n):
    i, j, k = m - 1, n - 1, m + n - 1
    while j >= 0:
        if i >= 0 and nums1[i] > nums2[j]:
            nums1[k] = nums1[i]
            i -= 1
        else:
            nums1[k] = nums2[j]
            j -= 1
        k -= 1

5Dry run

[1,2,3,0,0,0] + [2,5,6] → fill from the back: 6,5,3,2,2,1.

6Time and space complexity

O(m+n) time, O(1) extra space.

7Common mistakes

  • Merging from the front and overwriting unread data.
  • Forgetting nums2 can contain all remaining values.
