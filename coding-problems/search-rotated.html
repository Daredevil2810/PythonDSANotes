Search in Rotated Sorted Array — Python Solution

Find a target in a rotated sorted array with distinct values.

1How to recognise it

Sorted data has been rotated once, but one half is still ordered.

2Key idea

At every step, at least one half is normally sorted. Decide whether the target belongs to that half.

3Approach, step by step

  1. Compute mid.
  2. If left..mid is sorted, test whether target lies inside it.
  3. Otherwise use the right sorted half.
  4. Discard the impossible half and continue.

4Python solution

solution.py
def search(nums, target):
    l, r = 0, len(nums) - 1
    while l <= r:
        m = (l + r) // 2
        if nums[m] == target: return m
        if nums[l] <= nums[m]:
            if nums[l] <= target < nums[m]: r = m - 1
            else: l = m + 1
        else:
            if nums[m] < target <= nums[r]: l = m + 1
            else: r = m - 1
    return -1

5Dry run

[4,5,6,7,0,1,2], target 0 → left half is sorted but 0 is outside it → search right half.

6Time and space complexity

O(log n) time, O(1) space.

7Common mistakes

  • Using ordinary binary-search comparisons without handling rotation.
  • Getting inclusive boundaries wrong.
