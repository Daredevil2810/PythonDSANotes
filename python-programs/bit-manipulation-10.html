Find the Two Non-Repeating Elements (when others appear twice) in Python

Find the two values that appear once when every other value appears twice by first XOR-ing everything, then splitting values using a distinguishing set bit.

1Python program

program_10.py
#  Find the Two Non-Repeating Elements (when others appear twice) :

def find_two_unique(arr):
    xor_all = 0
    for num in arr:
        xor_all ^= num

    # Rightmost set bit
    rightmost_set_bit = xor_all & -xor_all

    num1, num2 = 0, 0
    for num in arr:
        if num & rightmost_set_bit:
            num1 ^= num
        else:
            num2 ^= num

    print("The two unique elements are:", num1, "and", num2)

arr = [2, 4, 7, 9, 2, 4]
find_two_unique(arr)


# Output :

# The two unique elements are: 7 and 9

2Why it matters

It extends the single-unique XOR trick and teaches how one XOR result can reveal a bit where the two unique values differ.

Simple example

For [2, 4, 7, 9, 2, 4], the total XOR is 7 ^ 9. Its rightmost set bit separates 7 and 9 into different groups; duplicates still cancel within their groups.

3How it works

  1. XOR every array element to get xor_all = unique1 ^ unique2.
  2. Extract the rightmost set bit with xor_all & -xor_all.
  3. Partition elements according to whether that bit is set.
  4. XOR each partition separately.
  5. Duplicates cancel inside their partition, leaving the two unique values.

4Line-by-line meaning

6Time and space complexity

Time: O(n)

Space: O(1) auxiliary

7Common mistakes

  • Using the method when more than two values are unique.
  • Skipping the partition step and expecting xor_all itself to give both answers.
  • Forgetting that the isolated bit must be set in one unique value and clear in the other.

8When to use it (and when not to)

Use it when: Use it for the classic constraint where exactly two elements occur once and all remaining elements occur twice.

Avoid it when: Use a frequency map when the occurrence rules are different or clarity is more important than constant extra space.

9Interview questions to expect

  • Why does xor_all contain unique1 ^ unique2?
  • Why does xor_all & -xor_all isolate the rightmost set bit?
  • Why must the two unique values land in different groups?
