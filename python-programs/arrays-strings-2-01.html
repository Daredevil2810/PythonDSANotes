Find Maximum and Minimum in an Array in Python

Find both extremes in one traversal by maintaining two running values.

1Python program

program_01.py
# Find Maximum and Minimum in an Array : 

arr = [5, 3, 9, 1, 6]
max_val = arr[0]
min_val = arr[0]

for i in arr:
    if i > max_val:
        max_val = i
    if i < min_val:
        min_val = i

print(f"Maximum element is {max_val}")
print(f"Minimum element is {min_val}")


# Output : 

# Maximum element is 9
# Minimum element is 1

2Why it matters

Two related statistics can often be computed in one pass instead of scanning or sorting multiple times.

Simple example

As you read temperatures, keep the coldest and hottest value seen so far.

3How it works

  1. Initialize min and max with the first element.
  2. For each value, update max if it is larger.
  3. Update min if it is smaller.
  4. Return both values after the scan.

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • Empty arrays need explicit handling.
  • Do not initialize both to zero when negative values are possible.
  • Both comparisons are needed; use separate if statements rather than accidentally making them mutually exclusive.

8When to use it (and when not to)

Use it when: Use this one-pass pattern when you need multiple independent aggregate values.

Avoid it when: If the data source cannot be traversed again and the required statistic needs more state, design the state carefully before coding.

9Interview questions to expect

  • Can min and max be found with fewer than 2n comparisons?
  • How do you handle an empty array?
  • What changes for a stream of values?
