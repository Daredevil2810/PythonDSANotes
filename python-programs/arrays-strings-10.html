Check Prime number in Python

Determine whether a number has any divisor other than 1 and itself by testing possible divisors only up to sqrt(n).

1Python program

program_10.py
# Check Prime number : 

n = 2
is_prime = True

if n < 2:
    is_prime = False

for i in range(2, int(n**0.5) + 1):    # (n**0.5) means sqrt(n)
    if n % i == 0:
        is_prime = False
        break

if is_prime:
    print(f"{n} is prime")
else:
    print(f"{n} is not prime")


# Output : 

# 2 is prime

2Why it matters

Checking every number up to n-1 is unnecessary. If n has a factor larger than sqrt(n), it must have a matching factor smaller than sqrt(n).

Simple example

For 36, if a factor pair exists beyond 6, the other factor must already be below 6. So testing through sqrt(36)=6 is enough.

3How it works

  1. Numbers below 2 are not prime.
  2. Try divisors from 2 through floor(sqrt(n)).
  3. If any divisor divides n evenly, n is composite.
  4. If none divide evenly, n is prime.

6Time and space complexity

Time: O(sqrt(n))

Space: O(1)

7Common mistakes

  • 1 is not prime.
  • The upper bound must include floor(sqrt(n)).
  • Do not assume an even number is always composite without handling 2.

8When to use it (and when not to)

Use it when: Use this direct test for individual numbers when you need a simple primality check.

Avoid it when: For generating many primes up to a large limit, the Sieve of Eratosthenes is usually better.
