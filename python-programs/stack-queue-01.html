Stack Using Array in Python

Build a LIFO (Last In, First Out) stack with a fixed-size Python list and a top index.

1Python program

program_01.py
# Stack Using Array :

# Support basic stack operations:
# Push – add element to the top
# Pop – remove element from the top
# Peek/Top – see the top element
# IsEmpty – check if stack is empty
# IsFull – check if stack is full

class Stack:
    def __init__(self, size):
        self.size = size
        self.arr = [0] * size
        self.top = -1

    def push(self, value):
        if self.top >= self.size - 1:
            print("Stack Overflow")
            return
        self.top += 1
        self.arr[self.top] = value

    def pop(self):
        if self.top < 0:
            print("Stack Underflow")
            return None
        value = self.arr[self.top]
        self.top -= 1
        return value

    def peek(self):
        if self.top < 0:
            print("Stack is empty")
            return None
        return self.arr[self.top]

    def is_empty(self):
        return self.top == -1

    def is_full(self):
        return self.top == self.size - 1

stack = Stack(5)
stack.push(10)
stack.push(20)
stack.push(30)

print("Top element:", stack.peek())
print("Popped:", stack.pop())
print("Top element after pop:", stack.peek())


# Output :

# Top element: 30
# Popped: 30
# Top element after pop: 20

2Why it matters

A stack appears whenever the most recently added item must be handled first: undo history, browser back behavior, function calls, and expression processing.

Simple example

Push 10, 20, 30. The top is 30. Pop removes 30 first, leaving 20 on top.

3How it works

  1. Create a fixed-size array and set top to -1.
  2. For push, check overflow, move top forward, then store the value.
  3. For pop, check underflow, read the top value, then move top backward.
  4. Peek reads the top without removing it.
  5. is_empty and is_full inspect the top position.

6Time and space complexity

Time: O(1) per operation

Space: O(n)

7Common mistakes

  • Confusing top with an array index that starts at zero.
  • Forgetting overflow or underflow checks.
  • Moving top before or after the wrong operation.

8When to use it (and when not to)

Use it when: Use an array-backed stack when a bounded capacity is acceptable and fast O(1) operations are wanted.

Avoid it when: Avoid a fixed-size implementation when the required capacity is unknown or highly dynamic.
