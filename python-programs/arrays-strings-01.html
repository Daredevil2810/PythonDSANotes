Find the Largest Element in an Array in Python

Find the largest value in an array by visiting each element once and keeping track of the largest value seen so far.

1Python program

program_01.py
# Find the Largest Element in an Array : 

arr = [10,20,5,14,35]

max_val = arr[0]

for num in arr:
    if num > max_val:
        max_val = num
        
print("Largest element is", max_val)


# Output : 

# Largest element is 35

2Why it matters

You often need the best value in a collection: the highest score, largest number, maximum temperature, or biggest transaction. A single scan is enough when the elements do not need to be sorted first.

Simple example

Think of checking five exam scores one by one. Keep the highest score in your hand. Whenever a new score is higher, replace the one you are holding.

3How it works

  1. Start with the first element as the current maximum.
  2. Visit every remaining element.
  3. If the current element is larger, update the maximum.
  4. After the scan, the stored value is the largest element.

4Line-by-line meaning

CodeWhat it means

for num in arr:Visit each element in the array.
if num > max_val:Check whether the current value is better than the best value so far.

print(...) Display the final maximum after the scan is complete.

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • Starting max_val at 0 fails when all input numbers are negative.
  • Sorting the array first works, but adds unnecessary work for this problem.
  • For an empty array, arr[0] is invalid; production code should decide how empty input is handled.

8When to use it (and when not to)

Use it when: Use this pattern when you need one best value and can inspect each item independently.

Avoid it when: If you need many range queries or repeated maximum lookups after updates, a different data structure may be more appropriate.

9Interview questions to expect

  • Why is the time complexity O(n) rather than O(log n)?
  • How would you handle an empty array?
  • How would you find both the minimum and maximum in one pass?
