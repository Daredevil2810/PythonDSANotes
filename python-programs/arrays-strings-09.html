Find factorial of a number in Python

Calculate n! by multiplying an accumulator by every integer from 1 through n.

1Python program

program_09.py
# Find factorial of a number : 

n = 5
factorial = 1

for i in range(1, n+1):
    factorial *= i

print(f"Factorial of {n} is {factorial}")


# Output : 

# Factorial of 5 is 120

2Why it matters

Factorial is a simple example of a running-product pattern and prepares you for recursive definitions.

Simple example

For 5!, start at 1 and multiply by 1, then 2, then 3, then 4, then 5.

3How it works

  1. Start factorial at 1.
  2. Loop from 1 through n.
  3. Multiply the accumulator by the current number.
  4. Return the final product.

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • Starting the accumulator at 0 makes every result zero.
  • 0! should be 1.
  • For very large n, factorial values grow extremely quickly.

8When to use it (and when not to)

Use it when: Use this pattern when a result is the product of a sequence of factors.

Avoid it when: Do not compute factorial by a loop if the real problem has a different mathematical structure.
