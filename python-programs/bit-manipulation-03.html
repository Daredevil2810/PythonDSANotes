Set the ith Bit in Python

Force a selected bit to 1 by OR-ing the number with a mask containing a 1 at that position.

1Python program

program_03.py
# Set the ith Bit : 

def set_bit(num, i):
    return num | (1 << i)

# Example
n = 10   # (1010 in binary)
i = 1    # set 1st bit (counting from 0)
print("Original:", bin(n), "=", n)
print("After setting bit", i, ":", bin(set_bit(n, i)), "=", set_bit(n, i))


# Output :

# Original: 0b1010 = 10
# After setting bit 1 : 0b1010 = 10

2Why it matters

It teaches how OR can turn a specific bit on without changing the other bit positions.

Simple example

10 is 1010. Setting bit 1 uses mask 0010: 1010 | 0010 remains 1010 because bit 1 was already 1.

3How it works

  1. Create 1 << i as the mask.
  2. OR the number with that mask.
  3. The selected bit becomes 1 whether it was originally 0 or already 1.
  4. All unrelated bits remain unchanged.

4Line-by-line meaning

6Time and space complexity

Time: O(1)

Space: O(1)

7Common mistakes

  • Using XOR when the requirement is always to set the bit to 1.
  • Forgetting that OR leaves an already-set bit unchanged.
  • Using the wrong bit index.

8When to use it (and when not to)

Use it when: Use it for bit flags, feature masks, permissions, and compact state representations.

Avoid it when: Avoid it when the data is naturally represented by ordinary booleans or named fields and bit-level storage adds unnecessary complexity.

9Interview questions to expect

  • What happens if the bit is already 1?
  • How would you set multiple bits at once?
