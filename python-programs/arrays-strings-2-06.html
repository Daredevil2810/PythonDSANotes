Count Occurrences of element in Array in Python

Count how many times one target value occurs while scanning the array.

1Python program

program_06.py
# Count occurances of element in Array :

arr = [10, 20, 30, 20, 10, 20]
target = 20
count = 0

for i in arr:
    if i == target:
        count += 1
    
print(f"Element {target} occurs {count} times")


# Output : 

# Element 20 occurs 3 times

2Why it matters

This reinforces the same frequency pattern while showing that the concept can appear in multiple program groups.

Simple example

Count how many times the number 20 appears in a list of scores.

3How it works

  1. Set count to zero.
  2. Scan each value.
  3. Increment when it equals target.
  4. Report count.

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • “Occurrences” means frequency, not the first index.
  • Do not stop after the first match.
  • If many targets are needed, repeatedly scanning is inefficient.

8When to use it (and when not to)

Use it when: Use a counter for one target value or as a first step toward frequency maps.

Avoid it when: For many targets, build a dictionary in one traversal.
