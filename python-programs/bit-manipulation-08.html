Swap Two Numbers without Temporary Variable (using XOR) in Python

Exchange two integer values through three XOR operations without a temporary variable.

1Python program

program_08.py
# Swap Two Numbers without Temporary Variable (using XOR) :

# Swap two numbers using XOR
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

print(f"Before Swap: a = {a}, b = {b}")

a = a ^ b
b = a ^ b
a = a ^ b

print(f"After Swap: a = {a}, b = {b}")

# Output :

# Enter first number: 3  
# Enter second number: 5
# Before Swap: a = 3, b = 5
# After Swap: a = 5, b = 3

2Why it matters

It is a classic XOR exercise that demonstrates cancellation properties, although modern Python normally has a clearer tuple-swap syntax.

Simple example

For a = 3 and b = 5: a becomes 3^5, then b becomes (3^5)^5 = 3, and finally a becomes (3^5)^3 = 5.

3How it works

  1. Set a = a ^ b.
  2. Set b = a ^ b; this recovers the original a.
  3. Set a = a ^ b; this recovers the original b.
  4. The values are exchanged without a third numeric variable.

6Time and space complexity

Time: O(1)

Space: O(1)

7Common mistakes

  • Forgetting that the three assignments depend on their exact order.
  • Trying the trick with references or objects where aliasing makes the idea inappropriate.
  • Using it in Python when a, b = b, a is much clearer.

8When to use it (and when not to)

Use it when: Use it mainly as a bitwise/XOR interview exercise or to understand XOR cancellation.

Avoid it when: In normal Python code, prefer a, b = b, a because it is clearer and idiomatic.

9Interview questions to expect

  • Why does the third XOR recover the original b?
  • What happens if a and b are equal?
  • Why is tuple unpacking preferable in Python?

10Try it yourself

  • Prove the three XOR identities algebraically.
  • Implement the same swap with tuple unpacking.
  • Test the XOR version with negative integers and discuss Python integer behavior.
