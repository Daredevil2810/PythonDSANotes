Hollow Diamond Pattern in Python

Create the diamond outline by printing stars only at the two edge positions of each row, with a separate upper and lower half.

1Python program

program_08.py
# Hollow Diamond Pattern :

# Hollow Diamond Pattern
rows = int(input("Enter number of rows: "))

# Upper hollow pyramid
for i in range(1, rows + 1):
    print(" " * (rows - i), end="")
    for k in range(1, 2 * i):
        if k == 1 or k == 2 * i - 1:
            print("*", end="")
        else:
            print(" ", end="")
    print()

# Lower hollow inverted pyramid
for i in range(rows - 1, 0, -1):
    print(" " * (rows - i), end="")
    for k in range(1, 2 * i):
        if k == 1 or k == 2 * i - 1:
            print("*", end="")
        else:
            print(" ", end="")
    print()

2Why it matters

It combines centered spacing, nested loops, and conditional boundary logic.

Simple example

For row i in the upper half, the star positions are k = 1 and k = 2*i-1; all positions between them are spaces.

3How it works

  1. For each upper-half row, print its leading spaces.
  2. Loop across the row width.
  3. Print a star only at the first or last position; otherwise print a space.
  4. Repeat symmetrically for the lower half.

4Line-by-line meaning

6Time and space complexity

Time: O(rows²) character positions overall

Space: O(1) auxiliary aside from output buffering

7Common mistakes

  • Printing stars for every k and accidentally making a solid diamond.
  • Using the wrong final boundary index.
  • Duplicating the center row.

8When to use it (and when not to)

Use it when: Use it to practice combining shape formulas with conditions and nested loops.

Avoid it when: Avoid complex boundary loops when a filled shape is all that is required.

9Interview questions to expect

  • How are the two boundary positions calculated?
  • Why is the center of the diamond hollow?
  • How does the lower half mirror the upper half?
