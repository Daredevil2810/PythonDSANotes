Minimum Path Sum in Matrix Problem in Python

Find the minimum sum from the top-left to the bottom-right of a grid when movement is allowed right or down.

1Python program

program_09.py
# Minimum Path Sum in Matrix Problem :

# Matrix:
# 1 3 1
# 1 5 1
# 4 2 1

# Minimum Path Sum = 7
# Path: 1 → 3 → 1 → 1 → 1

def min_path_sum(grid):
    m, n = len(grid), len(grid[0])
    dp = [[0]*n for _ in range(m)]

    dp[0][0] = grid[0][0]

    for j in range(1, n): dp[0][j] = dp[0][j-1] + grid[0][j]
    for i in range(1, m): dp[i][0] = dp[i-1][0] + grid[i][0]

    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])

    return dp[m-1][n-1]

grid = [
    [1,3,1],
    [1,5,1],
    [4,2,1]
]
print("Minimum Path Sum:", min_path_sum(grid))


# Output :

# Minimum Path Sum: 7

2Why it matters

This is a clean two-dimensional DP example: the best path to a cell must come from the best path to the cell above or to the left.

Simple example

3How it works

  1. Let dp[i][j] be the minimum cost to reach cell (i,j).
  2. Initialize the first row and column because they have only one possible direction.
  3. For every other cell, add its value to min(top, left).
  4. The bottom-right cell is the minimum path sum.

4Line-by-line meaning

min(dp[i-1][j], dp[i][j-1])Chooses the cheaper predecessor.

6Time and space complexity

Time: O(mn)

Space: O(mn)

7Common mistakes

  • Only right and down moves are allowed in this recurrence.
  • Do not forget first-row and first-column initialization.
  • The path sum includes the starting and ending cells.

8When to use it (and when not to)

Use it when: Use this pattern for grid problems where each cell depends on a small set of previous cells.

Avoid it when: If movement can go in arbitrary directions, this simple DP recurrence may no longer be valid.

9Interview questions to expect

  • Why can each cell depend only on top and left?
  • How can the matrix be updated in place?
  • How would you reconstruct the path?
