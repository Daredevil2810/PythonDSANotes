Counting sort in Python

Sort non-negative integers by counting how often each value occurs and using cumulative counts to determine each value's final position.

1Python program

program_10.py
# Counting sort systematically : 

# Counting Sort counts occurrences of each element and calculates their positions in the sorted array.

def counting_sort(arr):
    max_val = max(arr)
    count = [0] * (max_val + 1)
    output = [0] * len(arr)

    for num in arr:  # Count occurrences
        count[num] += 1

    for i in range(1, len(count)):  # Cumulative count
        count[i] += count[i - 1]

    for num in reversed(arr):  # Build output
        output[count[num] - 1] = num
        count[num] -= 1

    for i in range(len(arr)):
        arr[i] = output[i]  # Copy back

arr = [4, 2, 2, 8, 3, 3, 1]
counting_sort(arr)
print("Sorted array:", arr)


# Output :

# Sorted array: [1, 2, 2, 3, 3, 4, 8]

2Why it matters

Counting sort can beat comparison-based sorting when the range of integer values is small relative to the number of elements.

Simple example

For [4,2,2,8,3,3,1], count how many 1s, 2s, 3s, 4s and so on occur, then use cumulative positions to build the sorted output.

3How it works

  1. Find the maximum value to size the count array.
  2. Count each input value.
  3. Convert counts into cumulative positions.
  4. Traverse the input backward and place each value into its final output position.
  5. Copy the output back into the input array.

6Time and space complexity

Time: O(n + k), where k is the value range

Space: O(n + k)

7Common mistakes

  • This implementation assumes non-negative integer values.
  • A huge maximum value can make the count array impractically large.
  • Counting sort is not based on element comparisons, so its complexity depends on the value range.

8When to use it (and when not to)

Use it when: Use it when values are integers and the range k is reasonably small compared with n.

Avoid it when: Avoid it when the value range is enormous, sparse, or the input contains arbitrary objects.
