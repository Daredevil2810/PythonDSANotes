Two sum problem (Find two numbers with target sum) in Python

Find pairs of array elements whose sum equals a target value by checking every possible pair.

1Python program

program_05.1.py
# Two sum problem (Find two numbers with target sum) :

arr = [2, 7, 11, 15, 1, 8]
target = 9
found = False

for i in range(len(arr)):
    for j in range(i+1, len(arr)):
        if arr[i] + arr[j] == target:
            print(f"Pair found: {arr[i]} + {arr[j]} = {target}\nTheir Index position are : {arr[i]} -> {i}, {arr[j]} -> {j}")
            found = True
            # break

    # if found:
    #     break

if not found:
    print("No pair found")


# Output : 

# Pair found: 2 + 7 = 9
# Their Index position are : 2 -> 0, 7 -> 1
# Pair found: 1 + 8 = 9
# Their Index position are : 1 -> 4, 8 -> 5

2Why it matters

Pair-sum questions teach nested loops, indexes, and the idea of trading a straightforward solution for a faster one later. The brute-force version is often the easiest correct solution to understand first.

Simple example

If you have prices and a spending target, you can compare every pair of prices until you find two that add up to the target.

3How it works

  1. Choose the first element as the first member of a pair.
  2. Compare it with every element after it, avoiding duplicate/reversed pairs.
  3. If the two values add to the target, record the pair.
  4. Continue scanning because this particular program is designed to report every matching pair.

6Time and space complexity

Time: O(n²)

Space: O(1)

7Common mistakes

  • Using j = 0 checks the same pair in reverse order and may compare an element with itself.
  • Breaking too early changes the goal from finding all pairs to finding one pair.
  • For large arrays, O(n²) becomes expensive; a hash-map solution can reduce the typical lookup work.

8When to use it (and when not to)

Use it when: Use brute force as a simple baseline, for small inputs, or when teaching the problem before introducing optimization.

Avoid it when: Avoid it for large input sizes when a hash-based O(n) approach is acceptable.
