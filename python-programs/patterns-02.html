Hollow Rectangle Pattern in Python

Print stars only on the first/last row or first/last column, and spaces inside.

1Python program

program_02.py
# Hollow Rectangle Pattern :

rows = int(input("Enter number of rows: "))
cols = int(input("Enter number of columns: "))

for i in range(rows):
    for j in range(cols):
        if i == 0 or i == rows - 1 or j == 0 or j == cols - 1:
            print("*", end="")
        else:
            print(" ", end="")
    print()


# Output : 

# Enter number of rows: 4
# Enter number of columns: 6
# ******
# *    *
# *    *
# ******

2Why it matters

It teaches how loop indexes can describe the boundary of a shape instead of printing every position the same way.

Simple example

For 4 × 6, the first and last rows are all stars, while middle rows have a star at each end.

3How it works

  1. Loop through every row and column position.
  2. A position is on the boundary if row is first/last or column is first/last.
  3. Print * for boundary positions and a space otherwise.
  4. Finish each row with a newline.

4Line-by-line meaning

CodeWhat it means
if i == 0 or i == rows - 1 or j == 0 or j == cols - 1Checks whether the current cell lies on the rectangle boundary.
print("*", end="")Draws the boundary.
else: print(" ", end="")Leaves the interior hollow.
print()Starts the next row.

6Time and space complexity

Time: O(rows × cols)

Space: O(1) auxiliary

7Common mistakes

  • Using AND instead of OR in the boundary condition.
  • Forgetting that indexes start at 0.
  • Testing only rows and accidentally filling the whole rectangle.

8When to use it (and when not to)

Use it when: Use boundary conditions to practice grid logic and hollow-shape patterns.

Avoid it when: Avoid this style when the shape is not naturally represented by row/column boundaries.

9Interview questions to expect

  • How do you identify a boundary cell?
  • Why is OR used between the four boundary tests?
  • How would you make only the border of a square?

10Try it yourself

  • Create a hollow square.
  • Make the border use # instead of *.
  • Change the condition to draw only the top and bottom edges.
