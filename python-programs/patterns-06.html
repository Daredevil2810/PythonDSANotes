Inverted Pyramid Pattern in Python

Use the same odd-width pyramid formula while decreasing the row size from rows to 1.

1Python program

program_06.py
# Inverted Pyramid Pattern :

rows = int(input("Enter number of rows: "))

for i in range(rows, 0, -1):
    print(" " * (rows - i) + "*" * (2 * i - 1))


# Output : 

# Enter number of rows: 5
# *********
#  *******
#   *****
#    ***
#     *

2Why it matters

It combines descending iteration with the spacing formula used by the normal pyramid.

Simple example

For 5 rows, star counts are 9, 7, 5, 3, 1 while leading spaces increase from 0 to 4.

3How it works

  1. Start i at rows and count down to 1.
  2. Print rows - i spaces.
  3. Print 2*i - 1 stars.
  4. Repeat until i reaches 1.

4Line-by-line meaning

CodeWhat it means
for i in range(rows, 0, -1):Visits pyramid widths from largest to smallest.
" " * (rows - i)Adds more indentation as the shape narrows.
"*" * (2 * i - 1)Keeps each row an odd width.

5Dry run

StepWhat happens
i = 50 spaces + 9 stars
i = 41 space + 7 stars
i = 32 spaces + 5 stars
i = 14 spaces + 1 star

6Time and space complexity

Time: O(rows²) characters overall

Space: O(rows) for the temporary row string

7Common mistakes

  • Keeping rows-i as the star count.
  • Forgetting that the indentation grows while i decreases.
  • Using an even-width star formula.

8When to use it (and when not to)

Use it when: Use it to practice reversing a centered pattern while keeping its geometry aligned.

Avoid it when: Avoid it when a simple left-aligned decreasing triangle is sufficient.

9Interview questions to expect

  • What changes between the normal and inverted pyramid?
  • Why does indentation increase?
  • Why does the star count remain odd?

10Try it yourself

  • Combine this with the normal pyramid.
  • Replace stars with numbers.
  • Derive the output for rows = 3 by hand.
