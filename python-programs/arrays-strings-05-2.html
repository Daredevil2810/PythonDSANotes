Two sum problem (Find two numbers with target sum) using Dictionary (Hash Map) in Python

Find a target-sum pair by remembering values already seen, so each new value can be checked against its required complement in near-constant average time.

1Python program

program_05.2.py
# Two sum problem (Find two numbers with target sum)
# using Dictionary (Hash Map) :

def two_sum_all_pairs(arr, target):
    seen = {}
    pairs = []

    for i, num in enumerate(arr):
        complement = target - num
        if complement in seen:
            pairs.append((seen[complement], i))  # store indexes
        seen[num] = i   # save current number and index
    
    return pairs

# Example
arr = [2, 7, 11, 15, 1, 8, 2]
target = 9
result = two_sum_all_pairs(arr, target)

if result:
    for i, j in result:
        print(f"Pair found: {arr[i]} + {arr[j]} = {target} "
              f"\nTheir Index positions: {i}, {j}")
else:
    print("No pair found")


# Output : 

# Pair found: 2 + 7 = 9 
# Their Index positions: 0, 1
# Pair found: 1 + 8 = 9
# Their Index positions: 4, 5
# Pair found: 7 + 2 = 9
# Their Index positions: 1, 6

2Why it matters

This is a classic example of using extra memory to reduce repeated searching. Instead of scanning the rest of the array for every number, store what you have already seen.

Simple example

For target 9 and current number 7, the needed complement is 2. If 2 is already in the dictionary, the pair is immediately available.

3How it works

  1. Create a dictionary that maps a value to its earlier index.
  2. For each number, calculate complement = target - number.
  3. If the complement is already stored, a valid pair has been found.
  4. Otherwise store the current number and continue.

6Time and space complexity

Time: O(n) average

Space: O(n)

7Common mistakes

  • Checking the dictionary after inserting the current value can accidentally reuse the same element when the target is twice that value.
  • For duplicate values, decide whether you need the first index, last index, or all valid pairs.
  • The O(1) dictionary lookup is average-case, not a mathematical guarantee for every implementation detail.

8When to use it (and when not to)

Use it when: Use this pattern when you repeatedly need to ask whether a complementary value has already appeared.

Avoid it when: If memory is severely constrained or the input is tiny, the simpler brute-force version may be preferable.

9Interview questions to expect

  • Why does the dictionary reduce the time from O(n²) to O(n) average?
  • Why do we calculate the complement before storing the current number?
  • How would you solve the problem if the array were already sorted?
