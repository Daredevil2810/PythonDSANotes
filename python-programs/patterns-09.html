Number Pyramid Pattern in Python

Print leading spaces for alignment, then print the numbers 1 through the current row number.

1Python program

program_09.py
# Number Pyramid Pattern :

# Number Pyramid Pattern
rows = int(input("Enter number of rows: "))

for i in range(1, rows + 1):
    print(" " * (rows - i), end="")
    for k in range(1, i + 1):
        print(k, end="")
    print()


# Output : 

# Enter number of rows: 5
#     1
#    12
#   123
#  1234
# 12345

2Why it matters

It shows that pattern problems can control values as well as spacing, not just characters.

Simple example

For row 4, print three leading spaces followed by 1234.

3How it works

  1. Loop i from 1 through rows.
  2. Print rows-i leading spaces.
  3. Run k from 1 through i and print each k without a separator.
  4. Print a newline after the row.

4Line-by-line meaning

CodeWhat it means
for i in range(1, rows + 1):Controls the current row and its length.
" " * (rows - i)Centers the increasing number sequence.
for k in range(1, i + 1):Generates values from 1 through i.
print(k, end="")Keeps the numbers on the same row.

5Dry run

StepWhat happens
i = 14 spaces + 1
i = 23 spaces + 12
i = 32 spaces + 123
i = 50 spaces + 12345

6Time and space complexity

Time: O(rows²) printed values/characters

Space: O(1) auxiliary aside from output buffering

7Common mistakes

  • Using k in range(i) and printing 0 as the first number.
  • Adding spaces between numbers when the expected pattern is 12345.
  • Forgetting the alignment spaces.

8When to use it (and when not to)

Use it when: Use it to practice nested loops where the inner loop generates data rather than a repeated symbol.

Avoid it when: Avoid it when values should continue across rows; that is the purpose of Floyd’s triangle.

9Interview questions to expect

  • What determines the largest number in a row?
  • Why does k start at 1?
  • How would you print 1 2 3 with spaces instead?
