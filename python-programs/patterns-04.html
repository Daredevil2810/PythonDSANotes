Inverted Right Triangle Pattern in Python

Start with rows stars and reduce the count by one on each successive row.

1Python program

program_04.py
# Inverted Right Triangle Pattern :

rows = int(input("Enter number of rows: "))

for i in range(rows, 0, -1):
    print("*" * i)

# Output : 

# Enter number of rows: 5
# *****
# ****
# ***
# **
# *

2Why it matters

It reinforces controlling a loop in descending order and shows that the same triangle idea can be reversed.

Simple example

For 5 rows, the row lengths are 5, 4, 3, 2, 1.

3How it works

  1. Start the row count at rows.
  2. Continue while the value is at least 1.
  3. Print that many stars.
  4. Decrease the value after every row.

4Line-by-line meaning

CodeWhat it means
for i in range(rows, 0, -1):Counts backward from rows to 1.
"*" * iCreates i stars for the current row.
print(...)Prints one completed row.

5Dry run

StepWhat happens
i = 5*****
i = 4****
i = 3***
i = 2**
i = 1*

6Time and space complexity

Time: O(rows²) characters overall

Space: O(rows) for the temporary row string

7Common mistakes

  • Using range(rows, 0) and getting no iterations.
  • Forgetting the -1 step and creating an increasing pattern.
  • Starting at rows - 1 and losing the first full row.

8When to use it (and when not to)

Use it when: Use it when a decreasing row width is needed or to practice descending ranges.

Avoid it when: Avoid it when the output should grow rather than shrink.

9Interview questions to expect

  • What does the -1 step in range do?
  • How is this different from the normal right triangle?
  • How many total stars are printed?
