Reverse a string in Python

Construct a reversed string by visiting the original characters from the final index down to zero.

1Python program

program_08.py
# Reverse a string : 

str_val = "HelloWorld"
reversed_str = ""

for i in range(len(str_val)-1, -1, -1):
    reversed_str += str_val[i]

print("Reversed string: ", reversed_str)


# Output : 

# Reversed string:  dlroWolleH

2Why it matters

It reinforces reverse indexing and loop ranges, and makes the direction of traversal explicit.

Simple example

Reading a word from its last letter to its first naturally produces the reversed word.

3How it works

  1. Start at len(string)-1.
  2. Move backward one index at a time until index 0.
  3. Append each character to the result.
  4. Print or return the completed string.

6Time and space complexity

Time: O(n²) with repeated string concatenation in CPython

Space: O(n)

7Common mistakes

  • Python strings are immutable, so repeated concatenation can create many intermediate strings.
  • range must use a negative step when counting backward.
  • String slicing str_val[::-1] is simpler when the goal is only reversal.

8When to use it (and when not to)

Use it when: Use explicit reverse traversal when learning indexing or when the traversal itself is the concept.

Avoid it when: For production code where only the reversed string is needed, str[::-1] is usually clearer and efficient.
