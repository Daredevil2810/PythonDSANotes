Clear the ith Bit of a Number in Python

Turn a selected bit off by AND-ing with the inverse of a mask.

1Python program

program_04.py
# Clear the ith Bit of a Number :

def clear_bit(num, i):
    return num & ~(1 << i)

# Example
n = 10   # (1010 in binary)
i = 3    # clear 3rd bit
print("Original:", bin(n), "=", n)
print("After clearing bit", i, ":", bin(clear_bit(n, i)), "=", clear_bit(n, i))


# Output :

# Original: 0b1010 = 10
# After clearing bit 3 : 0b10 = 2

2Why it matters

It demonstrates how AND can preserve chosen bits while forcing one target bit to zero.

Simple example

10 is 1010. Clearing bit 3 uses mask 1000, inverted to ...0111 for the relevant low bits. 1010 & 0111 = 0010, which is 2.

3How it works

  1. Build the mask 1 << i.
  2. Invert the mask with ~ so every bit except i is 1.
  3. AND the number with the inverted mask.
  4. The target bit becomes 0 while the other bits are preserved.

4Line-by-line meaning

CodeWhat it means
def clear_bit(num, i):Defines a reusable clearing operation.
1 << iCreates a mask for the target position.
~(1 << i)Makes the target mask bit 0 and the other bits 1.
num & ...Preserves every other bit and clears bit i.

6Time and space complexity

Time: O(1)

Space: O(1)

7Common mistakes

  • Using OR, which cannot clear a 1 bit.
  • Forgetting the ~ operator in this common mask pattern.
  • Getting confused by Python’s signed representation of ~; the AND operation still produces the intended bit result.

8When to use it (and when not to)

Use it when: Use it when one flag must be switched off while other packed flags remain unchanged.

Avoid it when: Avoid it when named boolean variables make the state easier to understand.

9Interview questions to expect

  • Why is the mask inverted before AND?
  • What happens if the target bit is already 0?
  • How is clearing different from toggling?
