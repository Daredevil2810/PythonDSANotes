Insertion sort in Python

Build a sorted portion of the array one element at a time by shifting larger values right and inserting the current key into its correct position.

1Python program

program_06.py
# Insertion sort systematically :

# Insertion Sort builds the sorted portion of the array one element at a time by inserting each element into its correct position.

arr = [12, 11, 13, 5, 6]
n = len(arr)

for i in range(1, n):
    key = arr[i]
    j = i - 1
    while j >= 0 and arr[j] > key: 
        arr[j + 1] = arr[j]
        j -= 1
    arr[j + 1] = key

print("Sorted array : ", arr)


# Output : 

# Sorted array :  [5, 6, 11, 12, 13]

2Why it matters

Insertion sort is efficient for small or nearly sorted data and closely matches how people often sort a hand of cards.

Simple example

Take 12, then insert 11 before it; then insert 13 after the sorted prefix; continue with 5 and 6.

3How it works

  1. Treat the first element as already sorted.
  2. Take the next element as key.
  3. Shift larger sorted values one position right.
  4. Insert key into the gap.
  5. Repeat until the array is processed.

4Line-by-line meaning

CodeWhat it means
key = arr[i]Save the value that needs to be inserted.
j = i - 1Start comparing with the last element of the sorted prefix.
while j >= 0 and arr[j] > keyShift larger values right until the correct position is reached.
arr[j + 1] = arr[j]Move a larger value one position to the right.
arr[j + 1] = keyInsert the saved key into the open position.

5Dry run

StepWhat happens
Start[12] | [11,13,5,6]
Insert 11Shift 12 → [11,12]
Insert 13Already after 12 → [11,12,13]
Insert 5Shift 13,12,11 → [5,11,12,13]
Insert 6Shift 13,12,11 → [5,6,11,12,13]
Result[5,6,11,12,13]

6Time and space complexity

Time: O(n²) average/worst; O(n) best

Space: O(1)

7Common mistakes

  • Save key before shifting, otherwise its value can be overwritten.
  • The final insertion belongs at j+1.
  • The best case becomes O(n) when the array is already sorted because few shifts are needed.

8When to use it (and when not to)

Use it when: Use it for small arrays or data that is already nearly sorted.

Avoid it when: For large randomly ordered arrays, more efficient general-purpose algorithms are usually better.
