Count Set Bits in a Number in Python

Count how many 1 bits appear in a number by repeatedly checking the least significant bit and shifting right.

1Python program

program_06.py
# Count Set Bits in a Number :

def count_set_bits(num):
    count = 0
    while num:
        count += num & 1   # check last bit
        num >>= 1          # right shift
    return count

# Example
n = 29   # (11101 in binary → 4 ones)
print("Number:", n, "Binary:", bin(n))
print("Set bits:", count_set_bits(n))


# Output :

# Number: 29 Binary: 0b11101
# Set bits: 4

2Why it matters

It connects bit inspection, shifts, loops, and binary representation in one simple algorithm.

Simple example

29 is 11101. The loop examines each final bit and counts four 1s before the number becomes zero.

3How it works

  1. Start count at 0.
  2. While the number is non-zero, add num & 1 to count.
  3. Right-shift num by one position to discard the bit just checked.
  4. Return the count when all bits have been processed.

4Line-by-line meaning

CodeWhat it means
count = 0Initializes the number of set bits found.
while num:Continues until no relevant bits remain.
count += num & 1Adds 1 only when the current last bit is set.
num >>= 1Moves the next bit into the last-bit position.
return countReturns the total number of 1s.

6Time and space complexity

Time: O(log n) for a non-negative n

Space: O(1)

7Common mistakes

  • Forgetting to shift, causing an infinite loop.
  • Counting the number of binary digits instead of the number of 1 bits.
  • Using this exact loop for negative integers without considering Python’s signed/infinite-precision shift behavior.

8When to use it (and when not to)

Use it when: Use it as a beginner-friendly set-bit counter and to understand shifts.

Avoid it when: For performance-sensitive code, a built-in bit-count operation or a more efficient set-bit technique may be preferable.
