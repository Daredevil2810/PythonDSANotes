Sum of Array Elements in Python

Compute the sum of all array elements by adding each value to an accumulator.

1Python program

program_03.py
# Sum of Array Elements :

arr = [1, 2, 3, 4, 5]
sum_val = 0

for i in arr:
    sum_val += i

print("Sum of array element is ", sum_val)


# Output : 

# Sum of array element is  15

2Why it matters

The accumulator pattern appears everywhere in programming: totals, counts, scores, balances, and many DP transitions.

Simple example

Add each purchase price to a running bill total as you process the receipt.

3How it works

  1. Initialize sum to zero.
  2. Visit each element.
  3. Add it to the running sum.
  4. Return the final total.

4Line-by-line meaning

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • Starting at 1 adds an unwanted value.
  • Be careful with empty input; sum([]) is 0 in Python.
  • Do not confuse the sum with the average.

8When to use it (and when not to)

Use it when: Use an accumulator when a result can be built incrementally from each item.

Avoid it when: If Python’s built-in sum() is appropriate and readability is the priority, use it instead of reimplementing it.
