Search element in Array (Linear Search) in Python

Find a target value by checking array elements from left to right until the target is found or the array ends.

1Python program

program_05.py
# Search element in Array (Linear Search)

arr = [10, 20, 30, 40, 50]
target = 30
found_index = -1

for i in range(len(arr)):
    if arr[i] == target:
        found_index = i
        break

if found_index != -1:
    print(f"Element {target} found at index {found_index}")
else:
    print(f"Element {target} not found")


# Output :

# Element 30 found at index 2

2Why it matters

Linear search works even when data is unsorted, so it is the simplest general-purpose search strategy.

Simple example

Looking for a name in an unsorted contact list means checking entries one by one until the name appears.

3How it works

  1. Start at index 0.
  2. Compare the current value with the target.
  3. If they match, return or record the index.
  4. If the scan reaches the end, report that the target was not found.

4Line-by-line meaning

6Time and space complexity

Time: O(n) worst case

Space: O(1)

7Common mistakes

  • Forgetting that indexes start at 0.
  • Continuing unnecessarily after finding the first required match.
  • Assuming the input must already be sorted; linear search does not require sorting.

8When to use it (and when not to)

Use it when: Use it for unsorted data, small collections, or when a simple scan is sufficient.

Avoid it when: For large sorted arrays with many searches, binary search or another indexed structure may be better.

9Interview questions to expect

  • What is the best-case time complexity?
  • Why is the worst case O(n)?
  • How would you return all matching indexes instead of the first one?

10Try it yourself

  • Return -1 directly when the target is absent.
  • Return every index containing the target.
  • Count comparisons made before finding the target.
