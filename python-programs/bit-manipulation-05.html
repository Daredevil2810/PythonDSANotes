Toggle the ith Bit of a Number in Python

Flip a selected bit from 0 to 1 or from 1 to 0 by XOR-ing with a mask.

1Python program

program_05.py
# Toggle the ith Bit of a Number :

def toggle_bit(num, i):
    return num ^ (1 << i)

# Example
n = 10   # (1010 in binary)
i = 2    # toggle 2nd bit
print("Original:", bin(n), "=", n)
print("After toggling bit", i, ":", bin(toggle_bit(n, i)), "=", toggle_bit(n, i))


# Output :

# Original: 0b1010 = 10
# After toggling bit 2 : 0b1110 = 14

2Why it matters

XOR is especially useful for toggling because XOR with 1 flips a bit and XOR with 0 leaves it unchanged.

Simple example

10 is 1010. Toggling bit 2 uses 0100: 1010 ^ 0100 = 1110, which is 14.

3How it works

  1. Create the mask 1 << i.
  2. XOR the number with the mask.
  3. The selected bit flips.
  4. Every other bit stays the same because it is XOR-ed with 0.

6Time and space complexity

Time: O(1)

Space: O(1)

7Common mistakes

  • Using OR, which can only turn a bit on.
  • Using AND, which is suited to testing or clearing rather than toggling.
  • Assuming XOR always changes every bit; only positions aligned with 1s in the mask change.

8When to use it (and when not to)

Use it when: Use XOR masks for toggles, parity-like state changes, and compact flag operations.

Avoid it when: Avoid bit tricks when the state transition is clearer with ordinary boolean values.

9Interview questions to expect
