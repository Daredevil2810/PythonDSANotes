Implement Queue Using Array in Python

Build a FIFO (First In, First Out) queue with front and rear indexes over a fixed-size array.

1Python program

program_03.py
# Implement Queue Using Array :

class Queue:
    def __init__(self, size):
        self.size = size
        self.arr = [0] * size
        self.front = -1
        self.rear = -1

    def is_empty(self):
        return self.front == -1 or self.front > self.rear

    def is_full(self):
        return self.rear == self.size - 1

    def enqueue(self, value):
        if self.is_full():
            print("Queue Overflow")
            return
        if self.front == -1:
            self.front = 0
        self.rear += 1
        self.arr[self.rear] = value

    def dequeue(self):
        if self.is_empty():
            print("Queue Underflow")
            return None
        value = self.arr[self.front]
        self.front += 1
        return value

    def peek(self):
        if self.is_empty():
            print("Queue is empty")
            return None
        return self.arr[self.front]

    def display(self):
        if self.is_empty():
            print("Queue is empty")
            return
        for i in range(self.front, self.rear + 1):
            print(self.arr[i], end=" -> ")
        print("None")

queue = Queue(5)
queue.enqueue(10)
queue.enqueue(20)
queue.enqueue(30)

print("Queue:")
queue.display()
print("Front element:", queue.peek())
print("Dequeued:", queue.dequeue())
print("Queue after dequeue:")
queue.display()


# Output :

# Queue:
# 10 -> 20 -> 30 -> None
# Front element: 10
# Dequeued: 10
# Queue after dequeue:
# 20 -> 30 -> None

2Why it matters

Queues model waiting lines and task scheduling: the oldest waiting item should normally be processed first.

Simple example

Enqueue 10, 20, 30. The front is 10. Dequeue removes 10, leaving 20 → 30.

3How it works

  1. Start front and rear at -1.
  2. On the first enqueue, initialize front to zero.
  3. Increase rear and store the value there.
  4. Dequeue the value at front and advance front.
  5. Check overflow before enqueue and underflow before dequeue.

6Time and space complexity

Time: O(1) enqueue/dequeue

Space: O(n)

7Common mistakes

  • Forgetting the first-enqueue front initialization.
  • Confusing front and rear roles.
  • Assuming freed front slots are reused in this simple implementation.

8When to use it (and when not to)

Use it when: Use this simple array queue for learning or bounded workloads where reuse is not the main concern.

Avoid it when: For repeated enqueue/dequeue with reusable capacity, prefer a circular queue.
