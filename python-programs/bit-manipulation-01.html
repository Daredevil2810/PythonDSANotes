Check if a Number is Even or Odd using Bitwise Problem in Python

Use num & 1 to inspect the rightmost binary bit. A 0 means even and a 1 means odd.

1Python program

program_01.py
# Check if a Number is Even or Odd using Bitwise Problem :

# Bit manipulation problems are very common in coding interviews. They test your understanding of how integers are stored in binary and how bitwise operators (&, |, ^, ~, <<, >>) work.

num = 7

if (num & 1) == 0:
    print(f"{num} is Even")
else:
    print(f"{num} is Odd")


# Output :

# 7 is Odd

2Why it matters

It is a simple introduction to bitwise AND and shows that parity is encoded directly in the least significant bit.

Simple example

7 in binary is 111. Its last bit is 1, so 7 is odd. For 8 (1000), the last bit is 0, so 8 is even.

3How it works

  1. Take the number and AND it with 1.
  2. If the result is 0, the least significant bit is clear and the number is even.
  3. If the result is 1, the least significant bit is set and the number is odd.

6Time and space complexity

Time: O(1)

Space: O(1)

7Common mistakes

  • Thinking & 1 calculates a normal remainder in decimal rather than inspecting the last binary bit.
  • Forgetting that bit positions are normally counted from 0.
  • Using a slower loop to determine parity when a constant-time bit test is enough.

8When to use it (and when not to)

Use it when: Use it when learning bitwise operations or when a compact parity check is appropriate.

Avoid it when: Avoid bitwise syntax if the audience is not yet comfortable with binary and num % 2 is clearer for the context.
