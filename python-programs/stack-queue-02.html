Stack Using Linked List in Python

Use the head of a singly linked list as the stack top so push and pop can both happen at the front.

1Python program

program_02.py
# Stack Using Linked List :

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class Stack:
    def __init__(self):
        self.top = None

    def push(self, value):
        new_node = Node(value)
        new_node.next = self.top
        self.top = new_node

    def pop(self):
        if self.top is None:
            print("Stack Underflow")
            return None
        value = self.top.data
        self.top = self.top.next
        return value

    def peek(self):
        if self.top is None:
            print("Stack is empty")
            return None
        return self.top.data

    def is_empty(self):
        return self.top is None

    def display(self):
        current = self.top
        while current:
            print(current.data, end=" -> ")
            current = current.next
        print("None")

stack = Stack()
stack.push(10)
stack.push(20)
stack.push(30)

print("Stack:")
stack.display()
print("Top element:", stack.peek())
print("Popped:", stack.pop())
print("Stack after pop:")
stack.display()


# Output :

# Stack:
# 30 -> 20 -> 10 -> None
# Top element: 30
# Popped: 30
# Stack after pop:
# 20 -> 10 -> None

2Why it matters

A linked-list stack can grow dynamically without a fixed array capacity.

Simple example

Pushing 10, 20, 30 creates 30 → 20 → 10, with 30 at the top.

3How it works

  1. Represent each value with a node.
  2. Keep top pointing to the first node.
  3. Push by creating a node and linking it before the current top.
  4. Pop by moving top to top.next.
  5. Peek reads top.data without changing the link.

4Line-by-line meaning

CodeWhat it means
new_node = Node(value)Creates the new stack node.
new_node.next = self.topLinks it to the old top.
self.top = new_nodeMakes the new node the top.
self.top = self.top.nextRemoves the old top from the stack.

6Time and space complexity

Time: O(1) per push/pop/peek

Space: O(n)

7Common mistakes

  • Adding at the wrong end and losing O(1) operations.
  • Forgetting to update top after pop.
  • Dereferencing top when it is None.

8When to use it (and when not to)

Use it when: Use it when dynamic stack size is useful and linked nodes are appropriate.

Avoid it when: Avoid it when contiguous storage and lower per-element overhead are more important.
