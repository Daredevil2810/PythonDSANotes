Factorial using Recursion in Python

Compute n! by defining the factorial of n in terms of the smaller problem (n-1)!.

1Python program

program_01.py
# Factorial using Recursion : 

def factorial(n):
    if n <= 1:
        return 1
    else:
        return n*factorial(n-1)

n = 5
print(f"Factorial of {n} is {factorial(n)}")


# Output : 

# Factorial of 5 is 120

2Why it matters

Factorial is one of the clearest ways to learn the two essential parts of recursion: a base case and a smaller recursive call.

Simple example

5! becomes 5 × 4!, then 4 × 3!, until 1! returns 1. The calls then return upward: 1 → 2 → 6 → 24 → 120.

3How it works

  1. Handle the base case when n is 0 or 1 by returning 1.
  2. For a larger n, call factorial(n - 1).
  3. Multiply n by the result returned by the smaller call.
  4. The recursive calls stop at the base case and then unwind.

4Line-by-line meaning

CodeWhat it means
if n <= 1Stops recursion for 0 and 1.
return 1Provides the smallest known factorial result.
return n * factorial(n - 1)Reduces the problem and multiplies the returned answer by n.

5Dry run

6Time and space complexity

Time: O(n)

Space: O(n) call stack

7Common mistakes

  • A recursive function must have a base case.
  • The recursive call must move toward the base case.
  • 0! is 1, not 0.
  • Deep recursion can hit Python's recursion limit.

8When to use it (and when not to)

Use it when: Use recursion when the problem naturally breaks into the same smaller problem and the recursive structure improves understanding.

Avoid it when: Prefer an iterative solution when recursion adds overhead without making the logic clearer.

9Interview questions to expect

  • What is the base case?
  • What happens on the call stack during factorial(5)?
  • How would you write factorial iteratively?
