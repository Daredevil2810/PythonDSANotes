0/1 Knapsack Problem in Python

Choose items with weights and values to maximize total value without exceeding a capacity, where each item can be chosen at most once.

1Python program

program_03.py
# 0/1 Knapsack Problem :

def knapsack(values, weights, W):
    n = len(values)
    dp = [[0]*(W+1) for _ in range(n+1)]

    for i in range(n+1):
        for w in range(W+1):
            if i == 0 or w == 0:
                dp[i][w] = 0
            elif weights[i-1] <= w:
                dp[i][w] = max(values[i-1] + dp[i-1][w - weights[i-1]], dp[i-1][w])
            else:
                dp[i][w] = dp[i-1][w]
    return dp[n][W]

values = [60, 100, 120]
weights = [10, 20, 30]
W = 50
print("Maximum Value:", knapsack(values, weights, W))


# Output :

# Maximum Value: 220

2Why it matters

Knapsack is a core decision-DP problem. Each item creates a choice: take it or leave it.

Simple example

3How it works

  1. Let dp[i][w] be the best value using the first i items with capacity w.
  2. If the current item is too heavy, skip it.
  3. Otherwise compare taking it with skipping it.
  4. The final cell gives the maximum value for all items and full capacity.

4Line-by-line meaning

CodeWhat it means
dp = [[0] * (W+1) ...]Creates states for each item count and capacity.
weights[i-1] <= wChecks whether the current item fits.
values[i-1] + dp[i-1][w-weight]Value when the item is taken.
dp[i-1][w]Value when the item is skipped.
max(...)Chooses the better decision.

5Dry run

StepWhat happens

First two itemsTaking both gives value 160 at weight 30.
Add 120All three weigh 60, so they cannot all fit.

6Time and space complexity

Time: O(nW)

Space: O(nW)

7Common mistakes

  • 0/1 means each item is used at most once.
  • Do not accidentally use dp[i] when the recurrence requires the previous item row.
  • Capacity W is part of the state, so the complexity depends on W.

8When to use it (and when not to)

Use it when: Use it when each item creates a take/skip decision under a capacity or budget constraint.

Avoid it when: Do not use it when items can be taken unlimited times without adapting the recurrence; that is a different knapsack variant.
