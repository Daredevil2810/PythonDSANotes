Maximum Product Subarray Problem in Python

Find the contiguous subarray with the largest product, including cases where negative numbers change the sign of the product.

1Python program

program_08.py
# Maximum Product Subarray Problem :

def max_product_subarray(arr):
    max_ending = arr[0]
    min_ending = arr[0]
    max_so_far = arr[0]

    for i in range(1, len(arr)):
        if arr[i] < 0:
            max_ending, min_ending = min_ending, max_ending

        max_ending = max(arr[i], arr[i] * max_ending)
        min_ending = min(arr[i], arr[i] * min_ending)

        max_so_far = max(max_so_far, max_ending)
    return max_so_far

arr = [2, 3, -2, 4]
print("Maximum Product Subarray:", max_product_subarray(arr))


# Output :

# Maximum Product Subarray: 6

2Why it matters

Unlike maximum-sum problems, a negative number can turn the smallest negative product into the largest positive product. That means one state is not enough.

Simple example

3How it works

  1. Track both the maximum and minimum product ending at the current position.
  2. When the current number is negative, swap those two states before updating.
  3. Use the current value alone or extend either previous product.
  4. Keep the best maximum seen globally.

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • Tracking only the maximum fails when negatives appear.
  • Do not forget zero resets the useful product chain.
  • The subarray must be contiguous.

8When to use it (and when not to)

Use it when: Use it for contiguous-product optimization where negative values are possible.

Avoid it when: For problems without negative values, the simpler positive-product reasoning may be enough.

9Interview questions to expect
