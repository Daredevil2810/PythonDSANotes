Power of a number using Recursion in Python

Calculate a^b by multiplying a by the result of a^(b-1) until the exponent reaches zero.

1Python program

program_05.py
# Power of a number using Recursion :

def power(a, b):
    if b == 0:
        return 1
    else:
        return a * power(a, b - 1)
    
a, b = 2, 5
print(f"{a}^{b} = {power(a, b)}")


# Output : 

# 2^5 = 32

2Why it matters

It teaches how a mathematical definition can directly become a recursive function.

Simple example

2^5 becomes 2 × 2^4, then 2 × 2^3, until 2^0 returns 1. The results multiply back to 32.

3How it works

  1. If the exponent is zero, return 1.
  2. Otherwise compute power(a, b - 1).
  3. Multiply that result by a.
  4. Continue until the base case is reached.

4Line-by-line meaning

CodeWhat it means
if b == 0Any non-zero number raised to zero is 1.
return 1Provides the base result.
return a * power(a, b - 1)Reduce the exponent by one and multiply by a.

5Dry run

StepWhat happens
power(2,5)2 × power(2,4)
power(2,4)2 × power(2,3)
power(2,3)2 × power(2,2)
power(2,2)2 × power(2,1)
power(2,1)2 × power(2,0) = 2
Unwind2 × 2 × 2 × 2 × 2 = 32

6Time and space complexity

Time: O(b) for non-negative integer b

Space: O(b) call stack

7Common mistakes

  • Forgetting that a^0 = 1 breaks the recursion.
  • This implementation does not handle negative exponents.
  • There is a faster exponentiation-by-squaring technique for large exponents.

8When to use it (and when not to)

Use it when: Use repeated recursive multiplication when teaching the relationship between powers and recursion.

Avoid it when: For large exponents, use Python's built-in power operation or exponentiation by squaring.

9Interview questions to expect

  • How would you support negative exponents?
  • Can this be reduced to O(log b)?
  • Why is the base case 1?
