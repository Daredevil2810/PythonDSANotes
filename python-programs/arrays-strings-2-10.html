Check Palindrome String in Python

Determine whether a string is identical when read from left to right and right to left.

1Python program

program_10.py
# Check Palindrome String :

str_val = "Madam"
lower_str = str_val.lower()
is_palindrome = True

for i in range(len(lower_str)):
    if lower_str[i] != lower_str[-1 -i]:
        is_palindrome = False
        break

if is_palindrome:
    print(f"{str_val} is a palindrome")
else:
    print(f"{str_val} is not a palindrome")


# Output :

# Madam is a palindrome

2Why it matters

It is a classic interview problem for practicing indexes, two pointers, and string normalization.

Simple example

“madam” is a palindrome because the first and last letters match, then the second and second-last match.

3How it works

  1. Compare characters from both ends.
  2. Move inward after each match.
  3. Return false immediately on a mismatch.
  4. If all mirrored pairs match, return true.

7Common mistakes

  • Clarify whether case, spaces, and punctuation should be ignored.
  • Do not compare only the first and last characters.
  • A single mismatch is enough to stop.

8When to use it (and when not to)

Use it when: Use the two-pointer palindrome pattern for symmetric sequence checks.

Avoid it when: If normalization rules are complex, separate normalization from the palindrome check for clarity.

9Interview questions to expect

  • How would you ignore punctuation?
  • Can a palindrome be checked recursively?
  • How would you check an integer palindrome without converting to a string?
