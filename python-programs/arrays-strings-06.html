Move Zeros to end of array in Python

Keep non-zero values in their original relative order and fill the remaining positions with zeros.

1Python program

program_06.py
# Move Zeros to end of array :

arr = [0, 1, 0, 3, 12]
count = 0

for i in range(len(arr)):
    if arr[i] != 0:
        arr[count] = arr[i]
        count += 1

print(count)

while count < len(arr):
    arr[count] = 0
    count += 1

print("Array after moving zeros : ", arr)


# Output : 

# 3
# Array after moving zeros :  [1, 3, 12, 0, 0]

2Why it matters

The write-pointer pattern lets you rearrange an array in place without repeatedly shifting elements.

Simple example

Imagine moving all occupied seats toward the front while keeping their order, then filling the empty seats at the back.

3How it works

  1. Use count as the next position where a non-zero value should be written.
  2. Scan every element.
  3. When a non-zero value appears, write it at count and increment count.
  4. After the scan, fill all remaining positions with zero.

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • This algorithm relies on preserving the order of non-zero values.
  • The final fill loop must begin at the number of non-zero values found.
  • Printing count is debugging output, not part of the requested result.

8When to use it (and when not to)

Use it when: Use a write pointer for stable in-place filtering or compaction problems.

Avoid it when: If the input should not be modified, create a new result array instead.

9Interview questions to expect

  • How would you solve it with two pointers?
  • Why is the relative order preserved?
  • Can you minimize the number of writes?
