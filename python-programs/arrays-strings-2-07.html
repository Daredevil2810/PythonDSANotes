Remove Duplicates from Array in Python

Create a new array containing each value only once, keeping the first occurrence order.

1Python program

program_07.py
# Remove Duplicates from Array :

arr = [1, 2, 3, 2, 4, 1, 5]
unique_arr = list(dict.fromkeys(arr))

print("Array after removing duplicates : ", unique_arr)


# Output :

# Array after removing duplicates :  [1, 2, 3, 4, 5]

2Why it matters

This introduces uniqueness and the useful property of Python dictionaries preserving insertion order.

Simple example

From [1,2,3,2,4,1], keep the first 1,2,3,4 and ignore later repeats.

3How it works

  1. Use a dictionary as an insertion-ordered set of seen values.
  2. Convert its keys back to a list.
  3. The first occurrence of each value determines its position in the result.

4Line-by-line meaning

CodeWhat it means
dict.fromkeys(arr)Creates dictionary keys from the values, discarding duplicate keys while preserving insertion order in modern Python.
list(...)Converts the unique keys back into a list.

6Time and space complexity

Time: O(n) average

Space: O(n)

7Common mistakes

  • This requires hashable elements; lists cannot be dictionary keys.
  • If order does not matter, a set may be enough.
  • Creating a new list means the original array is not modified.

8When to use it (and when not to)

Use it when: Use it when you need unique hashable values while preserving first-seen order.

Avoid it when: For unhashable elements or when custom equality rules are needed, use a different approach.
