Insert Node at Beginning in Python

Create a new node, point it to the current head, and make it the new head.

1Python program

program_02.py
# Insert Node at Beginning

# Update the head pointer to the new node.

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

def insert_at_beginning(head, data):
    new_node = Node(data)
    new_node.next = head
    return new_node  # Update head

def display(head):
    current = head
    while current:
        print(current.data, end=" -> ")
        current = current.next
    print("None")

head = Node(20)
head.next = Node(30)

print("Original Linked List:")
display(head)

head = insert_at_beginning(head, 10)
print("After Inserting 10 at Beginning:")
display(head)


# Output : 

# Original Linked List:
# 20 -> 30 -> None
# After Inserting 10 at Beginning:
# 10 -> 20 -> 30 -> None

2Why it matters

It demonstrates that linked-list insertion changes references rather than shifting existing elements.

Simple example

For 20 → 30, create 10, set 10.next to 20, then make head point to 10.

3How it works

  1. Create the new node.
  2. Set new_node.next to the current head.
  3. Return the new node as the new head.

6Time and space complexity

Time: O(1)

Space: O(1) auxiliary

7Common mistakes

  • Forgetting to return the new head.
  • Losing the old head before linking it to the new node.
  • Not considering an empty list.

8When to use it (and when not to)

Use it when: Use it when constant-time insertion at the front is needed.

Avoid it when: Do not choose a linked list solely for this if another collection better fits the overall workload.

9Interview questions to expect

  • Why is beginning insertion O(1)?
  • What happens when head is None?
  • Why must the caller update head?
