Selection sort in Python

Repeatedly find the smallest value in the unsorted portion and swap it into the next sorted position.

1Python program

program_05.py
# Selection sort systematically : 

# Selection Sort repeatedly selects the minimum element from the unsorted part and places it at the beginning.

arr = [64, 25, 12, 22 , 11]
n = len(arr)

for i in range(n - 1):
    min_index = i
    for j in range(i + 1, n):
        if arr[j] < arr[min_index]:
            min_index = j
    if min_index != i:
        arr[i], arr[min_index] = arr[min_index], arr[i]

print("Sorted array : ", arr)


# Output :

# Sorted array :  [11, 12, 22, 25, 64]

2Why it matters

Selection sort makes the idea of separating sorted and unsorted regions very clear and uses few swaps.

Simple example

For [64,25,12,22,11], find 11 first and put it at index 0, then find 12 for index 1, and continue.

3How it works

  1. Treat the current index as the start of the unsorted region.
  2. Search the remaining elements for the smallest value.
  3. Remember its index.
  4. Swap it into the current position.
  5. Move the boundary one position right.

4Line-by-line meaning

if arr[j] < arr[min_index]Update the minimum candidate.
arr[i], arr[min_index] = ...Place the minimum at its final position for this pass.

5Dry run

StepWhat happens
i=0Minimum of entire array is 11 → swap with 64
i=1Minimum of remaining [25,12,22,64] is 12

i=3Minimum of remaining is 25

6Time and space complexity

Time: O(n²)

Space: O(1)

7Common mistakes

  • The inner loop must begin at i+1.
  • Do not swap every time a smaller value is found; remember the minimum and swap once per pass.
  • Selection sort is not generally stable in this swap-based form.

8When to use it (and when not to)

Use it when: Use it for teaching or when minimizing the number of swaps matters on very small inputs.

Avoid it when: Avoid it for large arrays because its comparisons remain quadratic.

9Interview questions to expect

  • Why does Selection Sort perform O(n²) comparisons even on sorted input?
  • How many swaps does it make at most?
  • Is this implementation stable?
