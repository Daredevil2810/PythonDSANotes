Next Greater Element Problem in Python

For every array element, find the first element to its right that is strictly greater; if none exists, return -1.

1Python program

program_03.py
# Next Greater Element Problem :

def next_greater_element(arr):
    n = len(arr)
    result = [-1] * n
    stack = []

    for i in range(n-1, -1, -1):
        while stack and stack[-1] <= arr[i]:
            stack.pop()
        if stack:
            result[i] = stack[-1]
        stack.append(arr[i])
    return result

arr = [4, 5, 2, 25]
nge = next_greater_element(arr)
print("Next Greater Elements:", nge)


# Output : 

# Next Greater Elements: [5, 25, 25, -1]

2Why it matters

The problem teaches the monotonic stack pattern, one of the most useful stack techniques for interview problems involving nearest greater or smaller values.

Simple example

For [4, 5, 2, 25], the next greater values are [5, 25, 25, -1].

3How it works

  1. Scan the array from right to left.
  2. Maintain a stack of candidates that may be greater than the current value.
  3. Pop candidates that are smaller than or equal to the current value because they can never be the answer for this element.
  4. If the stack is non-empty, its top is the nearest greater candidate.
  5. Push the current value so it can help elements further left.

6Time and space complexity

Time: O(n) amortized

Space: O(n)

7Common mistakes

  • Scanning rightward with a nested loop and accidentally making it O(n²).
  • Forgetting the <= condition when duplicates exist.
  • Using the wrong traversal direction for this implementation.

8When to use it (and when not to)

Use it when: Use a monotonic stack for next greater/smaller, nearest greater/smaller, and similar one-pass range problems.

Avoid it when: A monotonic stack is unnecessary when the input is tiny or a simple brute-force solution is clearer for learning.

9Interview questions to expect

  • Why is this O(n) even though there is a while loop inside the for loop?
  • What is a monotonic stack?
  • How would you find the next smaller element instead?

10Try it yourself
