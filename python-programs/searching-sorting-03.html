Binary Search (Recursive Method) in Python

Implement binary search by making a recursive call on only the half that can still contain the target.

1Python program

program_03.py
# Binary Search (Recursive Method) :

def binary_search(arr, target, low, high):
    if low > high:
        return -1
    
    mid = (low + high)//2

    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binary_search(arr, target, mid + 1, high)
    else:
        return binary_search(arr, target, low, mid - 1)

arr = [10, 20, 30, 40, 50]
target = 30
index = binary_search(arr, target, 0, len(arr)-1)

if index != -1:
    print(f"Element {target} found at index {index}")
else:
    print(f"Element {target} not found")


# Output :

# Element 30 found at index 2

2Why it matters

It demonstrates how divide-and-conquer search can be expressed recursively while preserving logarithmic search depth.

Simple example

After checking the middle element, the function calls itself with either low..mid-1 or mid+1..high.

3How it works

  1. Use low and high to describe the current range.
  2. If low becomes greater than high, the target is absent.
  3. Check the middle element.
  4. Recurse into the appropriate half when the middle is not the target.

4Line-by-line meaning

CodeWhat it means
if low > highBase case: the search range is empty.
mid = (low + high)//2Choose the middle element.
return midReturn immediately when the target is found.
binary_search(..., mid + 1, high)Search only the right half when the target is larger.
binary_search(..., low, mid - 1)Search only the left half when the target is smaller.

6Time and space complexity

Time: O(log n)

Space: O(log n) call stack

7Common mistakes

  • Forgetting the empty-range base case causes infinite recursion.
  • The recursive bounds must move beyond mid.
  • The input still needs to be sorted.

8When to use it (and when not to)

Use it when: Use it when learning recursion together with divide-and-conquer or when a recursive API is useful.

Avoid it when: Prefer the iterative form when minimizing call-stack usage is important.

9Interview questions to expect

  • What is the space difference between iterative and recursive binary search?
  • What is the base case?
  • Why are the new ranges mid+1..high and low..mid-1?
