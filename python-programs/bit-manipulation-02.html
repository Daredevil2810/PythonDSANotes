Check if the ith Bit is Set in Python

Create a mask with 1 << i and use AND to isolate the bit at position i.

1Python program

program_02.py
# Check if the ith Bit is Set :

# Given a number num and a position i, check if the ith bit in the binary representation of num is set (1) or not (0).

num = 13  # 1101
i = 2

mask = 1 << i

if (num & mask) != 0:
    print(f"Bit at position {i} is SET")
else:
    print(f"Bit at position {i} is NOT SET")


# Output :

# Bit at position 2 is SET

2Why it matters

Bit masks are the foundation of many low-level and algorithmic bit-manipulation techniques.

Simple example

For 13 (1101) and i = 2, the mask is 0100. 1101 & 0100 is 0100, so bit 2 is set.

3How it works

  1. Choose the zero-based bit position i.
  2. Create a mask by shifting 1 left by i positions.
  3. AND the number with the mask.
  4. A non-zero result means that bit is 1; zero means it is 0.

4Line-by-line meaning

CodeWhat it means
mask = 1 << iMoves a single 1 into the requested bit position.
if (num & mask) != 0Checks whether the selected bit overlaps a 1 in num.
print(... SET)Reports that the bit is 1.
elseRuns when the selected bit is 0.

5Dry run

StepWhat happens
num = 13Binary: 1101
i = 2Target the third bit from the right.
1 << 2Mask = 0100
13 & 01001101 & 0100 = 0100
ResultNon-zero → bit 2 is SET

6Time and space complexity

Time: O(1)

Space: O(1)

7Common mistakes

  • Using 1 << i incorrectly as the answer instead of as a mask.
  • Counting bit positions from 1 instead of 0.
  • Using OR when the goal is only to test a bit.

8When to use it (and when not to)

Use it when: Use masks to inspect flags, permissions, binary representations, and individual bits.

Avoid it when: Avoid bit masks when a straightforward numeric condition communicates the intent much more clearly.

9Interview questions to expect

  • Why is 1 << i used as the mask?
  • What does a zero result from num & mask mean?
  • How would you check the most significant set bit?
