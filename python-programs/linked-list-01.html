Create a Singly Linked List and Display in Python

Build a simple linked list from nodes and traverse it from the head until the current node becomes None.

1Python program

program_01.py
# Create a Singly Linked List and Display objectives :

# Traverse the list using a pointer starting at head.

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

def display(head):
    current = head
    while current:
        print(current.data, end=" -> ")
        current = current.next
    print("None")

head = Node(10)
head.next = Node(20)
head.next.next = Node(30)

print("Linked List:")
display(head)


# Output : 

# Linked List:
# 10 -> 20 -> 30 -> None

2Why it matters

Linked lists teach references between objects. Unlike an array, the nodes do not need to sit next to one another in memory conceptually; each node points to the next node.

Simple example

Think of a treasure hunt where each clue tells you where to find the next clue. You start with the first clue and follow next links until there is no next clue.

3How it works

  1. Create a Node class containing data and a next reference.
  2. Create the first node and store it as head.
  3. Connect each node through its next reference.
  4. Start a current pointer at head and repeatedly move current = current.next.
  5. Stop when current becomes None.

6Time and space complexity

Time: O(n) traversal

Space: O(n) for n nodes

7Common mistakes

  • Forgetting to advance current causes an infinite loop.
  • Changing head during traversal can lose the starting reference.
  • Accessing current.data after current becomes None causes an error.

8When to use it (and when not to)

Use it when: Linked lists are useful when frequent insertions/deletions are needed around known nodes and random indexing is not the main operation.

Avoid it when: If you frequently need arr[i]-style random access, arrays/lists are usually simpler and faster.
