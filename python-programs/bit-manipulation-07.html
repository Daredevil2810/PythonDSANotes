Find XOR of Two Numbers in Python

Apply the XOR operator (^) to two integers to combine their binary bits according to XOR rules.

1Python program

program_07.py
# Find XOR of Two Numbers :

# XOR of two numbers
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

result = a ^ b   # XOR operation
print(f"XOR of {a} and {b} is: {result}")


# Output : 

# Enter first number: 5
# Enter second number: 2
# XOR of 5 and 2 is: 7

2Why it matters

XOR is a core bitwise operation and its properties become especially powerful in array and duplicate-cancellation problems.

Simple example

5 is 0101 and 2 is 0010. XOR gives 0111, which is 7.

3How it works

  1. Read the two input integers.
  2. Apply a ^ b.
  3. For each bit, the result is 1 when the two corresponding bits differ.
  4. Print the resulting integer.

6Time and space complexity

Time: O(1) for fixed-width machine integers; Python integer cost depends on bit length

Space: O(1) auxiliary space

7Common mistakes

  • Confusing XOR with OR: OR returns 1 when either bit is 1, while XOR requires different bits.
  • Assuming XOR is arithmetic addition.
  • Forgetting that XOR is useful because a ^ a = 0 and a ^ 0 = a.

8When to use it (and when not to)

Use it when: Use XOR when you need bitwise difference, cancellation, parity-like operations, or XOR-based array algorithms.

Avoid it when: Do not use XOR merely to make ordinary arithmetic look clever; addition or other operators are usually clearer for numeric calculations.

9Interview questions to expect

  • Why is a ^ a equal to 0?
  • Why is a ^ 0 equal to a?
