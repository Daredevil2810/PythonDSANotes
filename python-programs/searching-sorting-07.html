Merge Sort in Python

Recursively split an array into halves, sort each half, and merge the sorted halves into one sorted array.

1Python program

program_07.py
# Merge Sort systematically :

# Merge Sort recursively divides the array into halves, sorts them, and then merges the sorted halves.

def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])

    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

arr = [12, 11, 13, 5, 6, 7]
sorted_arr = merge_sort(arr)
print("Sorted array : ", sorted_arr)


# Output : 

# Sorted array :  [5, 6, 7, 11, 12, 13]

2Why it matters

Merge sort introduces divide-and-conquer thinking and guarantees O(n log n) time regardless of the initial ordering.

Simple example

[12,11,13,5,6,7] is repeatedly split until single-element arrays remain, then those small sorted pieces are merged.

3How it works

  1. Split the array around the midpoint.
  2. Recursively sort the left half.
  3. Recursively sort the right half.
  4. Merge the two sorted halves by repeatedly taking the smaller front element.
  5. Append any remaining values.

6Time and space complexity

Time: O(n log n)

Space: O(n) for this array-slicing implementation

7Common mistakes

  • The base case must stop recursion for arrays of length 0 or 1.
  • The merge step assumes both inputs are already sorted.
  • This Python implementation creates slices and a result list, so it is not an in-place merge sort.

8When to use it (and when not to)

Use it when: Use it when predictable O(n log n) sorting and stable behavior are useful.

Avoid it when: Avoid assuming it is in-place; memory-sensitive situations may require another implementation.
