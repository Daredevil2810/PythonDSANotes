Pyramid Pattern in Python

Each row has leading spaces followed by an odd number of stars: 1, 3, 5, ...

1Python program

program_05.py
# Pyramid Pattern :

rows = int(input("Enter number of rows: "))

for i in range(1, rows + 1):
    print(" " * (rows - i) + "*" * (2 * i - 1))

# Output :

# Enter number of rows: 5
#     *
#    ***
#   *****
#  *******
# *********

2Why it matters

It teaches that visual alignment is controlled by both indentation and content width.

Simple example

For 5 rows, row i has 5-i leading spaces and 2i-1 stars.

3How it works

  1. Loop i from 1 through rows.
  2. Print rows - i leading spaces.
  3. Print 2 * i - 1 stars.
  4. Move to the next line.

4Line-by-line meaning

CodeWhat it means
" " * (rows - i)Centers the current row by adding leading spaces.
"*" * (2 * i - 1)Produces the odd-width star sequence.
print(... + ...)Combines spaces and stars into one row.

5Dry run

StepWhat happens
i = 14 spaces + 1 star
i = 23 spaces + 3 stars
i = 32 spaces + 5 stars
i = 50 spaces + 9 stars

6Time and space complexity

Time: O(rows²) characters overall

Space: O(rows) for the temporary row string

7Common mistakes

  • Using i stars instead of 2*i-1 and getting a non-centered shape.
  • Forgetting leading spaces.
  • Using rows-i+1 and shifting the whole pyramid.

8When to use it (and when not to)

Use it when: Use it to practice formulas for centered shapes and row-dependent spacing.

Avoid it when: Avoid manual string literals when the number of rows should be variable.

9Interview questions to expect

  • Why are pyramid widths odd?
  • Why is the star count 2*i-1?
  • How many characters are printed in row i?

10Try it yourself

  • Create a centered pyramid of #.
  • Derive the formula for the leading spaces.
  • Make the pyramid start with 3 stars instead of 1.
