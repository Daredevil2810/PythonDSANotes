Count Nodes in Linked List in Python

Visit every node and increment a counter until the next reference is None.

1Python program

program_09.py
# Count Nodes in Linked List :

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

def count_nodes(head):
    current = head
    count = 0
    while current:
        count += 1
        current = current.next
    return count

def display(head):
    current = head
    while current:
        print(current.data, end=" -> ")
        current = current.next
    print("None")

head = Node(10)
head.next = Node(20)
head.next.next = Node(30)
head.next.next.next = Node(40)

print("Linked List:")
display(head)

total_nodes = count_nodes(head)
print(f"Total nodes in the linked list: {total_nodes}")


# Output :

# Linked List:
# 10 -> 20 -> 30 -> 40 -> None
# Total nodes in the linked list: 4

2Why it matters

The counting pattern is a foundation for length checks, indexing, and many other linked-list algorithms.

Simple example

10 → 20 → 30 → 40 requires four visits, so the final count is 4.

3How it works

  1. Initialize count to zero.
  2. Start current at head.
  3. Increment count for each node.
  4. Move to current.next until the list ends.

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • Do not count None as a node.
  • Remember an empty list has length zero.
  • Do not forget to advance current.

8When to use it (and when not to)

Use it when: Use traversal when the list does not maintain a stored size.

Avoid it when: If length is queried constantly, maintaining a size field can provide O(1) queries.
