Minimum Coin Change Problem in Python

Find the minimum number of coins needed to make a target amount when each coin denomination can be reused.

1Python program

program_04.py
# Minimum Coin Change Problem :

def min_coins(coins, V):
    dp = [float('inf')] * (V+1)
    dp[0] = 0

    for coin in coins:
        for i in range(coin, V+1):
            if dp[i - coin] != float('inf'):
                dp[i] = min(dp[i], 1 + dp[i - coin])
    return -1 if dp[V] == float('inf') else dp[V]

coins = [1, 2, 5]
V = 11
print("Minimum Coins Needed:", min_coins(coins, V))


# Output :

# Minimum Coins Needed: 3

2Why it matters

This demonstrates a one-dimensional DP where each amount depends on smaller amounts already solved.

Simple example

3How it works

  1. Let dp[x] be the minimum coins needed to make amount x.
  2. Set dp[0] = 0 because no coins are needed for zero.
  3. For each coin, update reachable amounts using 1 + dp[amount - coin].
  4. If the target remains unreachable, return -1.

4Line-by-line meaning

CodeWhat it means
dp = [inf] * (V+1)Starts every nonzero amount as unreachable.
dp[0] = 0Sets the base case.
dp[i - coin]Looks at the smaller amount left after taking a coin.
1 + dp[i-coin]Adds the current coin to that solution.
return -1 if ...Reports impossible targets.

Time: O(kV)

Space: O(V)

7Common mistakes

  • Do not initialize every amount to 0; that would falsely make unreachable states look optimal.
  • This program allows unlimited use of each coin.
  • Coin-change greedy choices do not always produce the minimum number of coins.

8When to use it (and when not to)

Use it when: Use DP when denominations do not guarantee a greedy solution.

Avoid it when: For special coin systems where a proven greedy strategy works, DP may be unnecessary.

9Interview questions to expect

  • Why does greedy fail for some coin systems?
  • What does dp[x] represent?
  • How would you reconstruct the actual coins used?
