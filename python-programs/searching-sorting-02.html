Binary Search in Python

Search a sorted array by repeatedly comparing the target with the middle element and discarding half of the remaining search range.

1Python program

program_02.py
# Binary Search :

# Binary search repeatedly divides the search range in half until the element is found or the range is empty.

arr = [10, 20, 30, 40, 50]
target = 30
low, high = 0, len(arr) - 1
found_index = -1

while low <= high:
    mid = (low + high)//2
    if arr[mid] == target:
        found_index = mid
        break
    elif arr[mid] < target:
        low = mid + 1
    else:
        high = mid - 1

if found_index != -1:
    print(f"Element {target} found at index {found_index}")
else:
    print(f"Element {target} not found")


# Output :

# Element 30 found at index 2

2Why it matters

When data is sorted, binary search avoids checking every element and reduces the search space exponentially.

Simple example

Searching for 70 in [10,20,30,40,50,60,70,80] lets you eliminate half the array after each comparison.

3How it works

  1. Set low to the first index and high to the last index.
  2. Calculate the middle index.
  3. If the middle value equals the target, stop.
  4. If the middle value is smaller, search the right half; otherwise search the left half.
  5. Repeat while low <= high.

6Time and space complexity

Time: O(log n)

Space: O(1)

7Common mistakes

  • Binary search requires sorted data under the ordering being searched.
  • Using low = mid or high = mid can cause an infinite loop; move past mid.
  • Off-by-one errors commonly occur at the boundaries.

8When to use it (and when not to)

Use it when: Use it for sorted data when you need fast repeated searches.

Avoid it when: Do not use it directly on unsorted data, and consider simpler linear search for tiny collections.
