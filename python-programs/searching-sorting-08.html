Quick Sort in Python

Choose a pivot, move values smaller than or equal to it to the left, place the pivot in its final position, then recursively sort both sides.

1Python program

program_08.py
# Quick Sort systematically : 

# Partition the array around the pivot: elements smaller go left, larger go right.

def quick_sort(arr, low, high):
    if low < high:
        pi = partition(arr, low, high)
        quick_sort(arr, low, pi - 1)
        quick_sort(arr, pi + 1, high)

def partition(arr, low, high):
    pivot = arr[high]
    i = low - 1

    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1

arr = [10, 7, 8, 9, 1, 5]
quick_sort(arr, 0, len(arr) - 1)
print("Sorted array : ", arr)


# Output :

# Sorted array :  [1, 5, 7, 8, 9, 10]

2Why it matters

Quick sort is a major divide-and-conquer algorithm and is often fast in practice because partitioning works in place.

Simple example

With pivot 5 in [10,7,8,9,1,5], values ≤5 are moved left and the pivot is placed between the smaller and larger regions.

3How it works

  1. Choose the last element as pivot in this implementation.
  2. Scan the range and move values <= pivot toward the left partition.
  3. Swap the pivot into the boundary position.
  4. Recursively sort the ranges before and after the pivot.

6Time and space complexity

Time: O(n log n) average, O(n²) worst case

Space: O(log n) average recursion stack; O(n) worst case

7Common mistakes

  • Partitioning is the core step; a wrong boundary can lose elements or recurse incorrectly.
  • The pivot choice affects performance.
  • The algorithm is not guaranteed O(n log n) for every input.

8When to use it (and when not to)

Use it when: Use it when you want fast in-place-style sorting and understand the trade-off around pivot selection.

Avoid it when: Do not assume its worst case is logarithmic; use a more predictable algorithm when worst-case guarantees are important.
