Sum of digits using Recursion in Python

Separate the last digit using modulo 10 and remove it using integer division by 10, then recursively process the remaining number.

1Python program

program_06.py
# Sum of digits using Recursion : 

def sum_of_digits(n):
    if n == 0:
        return 0
    else:
        return (n % 10) + sum_of_digits(n // 10)
    
n = 12345
print(f"Sum of digits of {n} is {sum_of_digits(n)}")


# Output : 

# Sum of digits of 12345 is 15

2Why it matters

It is a simple way to see how arithmetic operations can shrink a numeric problem one digit at a time.

Simple example

12345 becomes 5 + sum(1234), then 4 + sum(123), continuing until zero. The total is 15.

3How it works

  1. Take the last digit with n % 10.
  2. Remove the last digit with n // 10.
  3. Recursively sum the remaining digits.
  4. Add the extracted digit to the returned sum.

6Time and space complexity

Time: O(d), where d is the number of digits

Space: O(d) call stack

7Common mistakes

  • Use // rather than / so the remaining value stays an integer.
  • The base case must eventually be reached.
  • Negative numbers require an explicit sign-handling decision.

8When to use it (and when not to)

Use it when: Use this pattern for recursive digit-processing exercises and number decomposition.

Avoid it when: A simple loop is usually clearer when recursion itself is not part of the learning objective.

9Interview questions to expect

  • Why does n % 10 get the last digit?
  • What does n // 10 do?
  • How would you handle negative integers?
