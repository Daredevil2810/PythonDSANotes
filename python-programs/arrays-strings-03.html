Check if a String is a Palindrome in Python

Check whether a string reads the same from both ends by comparing matching characters while moving inward.

1Python program

program_03.py
# Check if a string is a palindrome : 

# str_val = "Hello"
str_val = "lolol"
is_palindrome = True

start = 0
end = len(str_val) -1

while start < end:
    if str_val[start] != str_val[end]:
        is_palindrome = False
        break

    start += 1
    end -= 1

if is_palindrome:
    print(f"{str_val} is a palindrome")
else:
    print(f"{str_val} is not a palindrome")


# Output : 

# lolol is a palindrome

2Why it matters

It teaches a reusable two-pointer pattern and avoids building a reversed copy of the string.

Simple example

For “level”, compare l with l, then e with e. The middle character does not need a partner.

3How it works

  1. Set one pointer at the first character and one at the last.
  2. Compare the characters at both pointers.
  3. If they differ, the string is not a palindrome.
  4. Otherwise move both pointers inward until they meet.

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • Case and spaces are treated literally unless you normalize them first.
  • Do not forget to move both pointers after a successful comparison.
  • The empty string is normally considered a palindrome; decide the expected rule explicitly.

8When to use it (and when not to)

Use it when: Use two pointers when a sequence must be compared symmetrically from both ends.

Avoid it when: If the problem requires ignoring punctuation or case, normalize the input first.
