Maximum Subarray Sum Problem (Kadane’s Algorithm) in Python

Find the largest possible sum of a contiguous subarray.

1Python program

program_05.py
# Maximum Subarray Sum Problem (Kadane’s Algorithm) :

def max_subarray(arr):
    max_current = arr[0]
    max_global = arr[0]

    for i in range(1, len(arr)):
        max_current = max(arr[i], max_current + arr[i])
        max_global = max(max_global, max_current)

    return max_global

arr = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
print("Maximum Subarray Sum:", max_subarray(arr))


# Output :

# Maximum Subarray Sum: 6

2Why it matters

Kadane’s algorithm is a compact DP recurrence: at each position, decide whether the best subarray ending here should start fresh or extend the previous one.

Simple example

3How it works

  1. max_current means the best sum of a subarray ending at the current index.
  2. Either start with arr[i] or extend max_current + arr[i].
  3. max_global stores the best ending sum seen anywhere.
  4. The global maximum is the answer.

4Line-by-line meaning

CodeWhat it means
max_current = arr[0]Starts the best subarray ending at index 0.
max(arr[i], max_current + arr[i])Chooses a new subarray or extends the old one.
max_global = max(...)Preserves the best sum found anywhere.

5Dry run

StepWhat happens
[-2]current = -2, global = -2

-3max(-3, 1-3) = -2

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • Do not initialize the answer to 0 if all values may be negative.
  • The subarray must be contiguous.
  • Do not confuse maximum sum with maximum subsequence sum.

8When to use it (and when not to)

Use it when: Use it when you need the maximum sum of a contiguous range in one pass.

Avoid it when: If you need the actual subarray, keep start/end indexes in addition to the sums.
