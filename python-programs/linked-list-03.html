Insert Node at End in Python

Traverse to the last node and connect its next reference to a new node.

1Python program

program_03.py
# Insert Node at End :

# Traverse the list to reach the last node, then link the new node.

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

def insert_at_end(head, data):
    new_node = Node(data)
    if head is None:
        return new_node  # Empty list

    current = head
    while current.next:
        current = current.next
    current.next = new_node
    return head

def display(head):
    current = head
    while current:
        print(current.data, end=" -> ")
        current = current.next
    print("None")

head = Node(10)
head.next = Node(20)

print("Original Linked List:")
display(head)

head = insert_at_end(head, 30)
print("After Inserting 30 at End:")
display(head)


# Output : 

# Original Linked List:
# 10 -> 20 -> None
# After Inserting 30 at End:
# 10 -> 20 -> 30 -> None

2Why it matters

It shows how linked-list performance depends on whether a tail reference is available.

Simple example

For 10 → 20, reach 20 and set 20.next to a new node containing 30.

3How it works

  1. Create the new node.
  2. If the list is empty, return it as head.
  3. Traverse until current.next is None.
  4. Attach the new node and return head.

6Time and space complexity

Time: O(n)

Space: O(1) auxiliary

7Common mistakes

  • Stopping one node too early or too late.
  • Forgetting the empty-list case.
  • Repeated O(n) appends can become expensive.

8When to use it (and when not to)

Use it when: Use this version when there is no maintained tail pointer.

Avoid it when: Avoid repeated end insertion on large lists without a tail reference.
