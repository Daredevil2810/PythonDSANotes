Heap sort in Python

Build a max heap so the largest element is at the root, repeatedly move that root to the end, and restore the heap property on the remaining prefix.

1Python program

program_09.py
# Heap sort :

# Repeatedly remove the root (largest element), swap with the last element, and heapify the reduced heap.

def heapify(arr, n, i):
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2

    if left < n and arr[left] > arr[largest]: largest = left
    if right < n and arr[right] > arr[largest]: largest = right

    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)

def heap_sort(arr):
    n = len(arr)
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)
    
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]
        heapify(arr, i, 0)

arr = [12, 11, 13, 5, 6, 7]
heap_sort(arr)
print("Sorted array : ", arr)


# Output : 

# Sorted array :  [5, 6, 7, 11, 12, 13]

2Why it matters

Heap sort provides O(n log n) worst-case time and connects sorting directly to the heap data structure.

Simple example

For [12,11,13,5,6,7], heapify builds a max heap with the largest value at index 0, then each extraction places that maximum at the end.

3How it works

  1. Build a max heap from the array.
  2. Swap the root with the last element in the active heap.
  3. Reduce the heap size by one.
  4. Heapify the root again.
  5. Repeat until one element remains.

6Time and space complexity

Time: O(n log n)

Space: O(log n) recursion stack in this implementation

7Common mistakes

  • Child indexes must use the current heap representation correctly.
  • The heap size shrinks after each extraction; the sorted suffix is no longer part of the heap.
  • Heap construction and sorting are separate phases.

8When to use it (and when not to)

Use it when: Use it when you want O(n log n) worst-case sorting and want to learn the connection between heaps and sorting.

Avoid it when: For beginner code, it can be more complex than necessary; built-in sorting is usually preferable in application code.
