Find Maximum and Minimum Node in Linked List in Python

Scan the list once while maintaining the smallest and largest values seen so far.

1Python program

program_10.py
# Find Maximum and Minimum Node in Linked List systematically :

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

def find_max_min(head):
    if head is None:
        print("List is empty")
        return

    max_val = head.data
    min_val = head.data
    current = head.next

    while current:
        if current.data > max_val:
            max_val = current.data
        if current.data < min_val:
            min_val = current.data
        current = current.next

    print(f"Maximum value: {max_val}")
    print(f"Minimum value: {min_val}")

def display(head):
    current = head
    while current:
        print(current.data, end=" -> ")
        current = current.next
    print("None")

head = Node(10)
head.next = Node(50)
head.next.next = Node(30)
head.next.next.next = Node(5)

print("Linked List:")
display(head)

find_max_min(head)


# Output :

# Linked List:
# 10 -> 50 -> 30 -> 5 -> None
# Maximum value: 50
# Minimum value: 5

2Why it matters

It combines linked-list traversal with the accumulator pattern without needing sorting.

Simple example

For 10 → 50 → 30 → 5, max becomes 50 and min becomes 5 after one pass.

3How it works

  1. Handle an empty list.
  2. Initialize min and max from head.data.
  3. Traverse the remaining nodes.
  4. Update each extreme independently.

6Time and space complexity

Time: O(n)

7Common mistakes

  • Do not initialize extrema to zero when values may be negative.
  • Handle an empty list.
  • Use separate comparisons for min and max.

8When to use it (and when not to)

Use it when: Use one-pass aggregation when you need extrema without sorting.

Avoid it when: Do not sort the list merely to find minimum and maximum.

9Interview questions to expect

  • Why is sorting unnecessary?
  • How do you handle all-negative values?
  • Can both values be found in one traversal?
