Longest Increasing Subsequence (LIS) Problem in Python

Find the length of the longest subsequence whose values are strictly increasing.

1Python program

program_07.py
# Longest Increasing Subsequence (LIS) Problem :

def lis(arr):
    n = len(arr)
    dp = [1]*n

    for i in range(1, n):
        for j in range(i):
            if arr[i] > arr[j]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)

arr = [10, 22, 9, 33, 21, 50, 41, 60]
print("Length of LIS:", lis(arr))


# Output :

# Length of LIS: 5

2Why it matters

LIS teaches one-dimensional DP where the state describes the best increasing subsequence that ends at a particular position.

Simple example

3How it works

  1. Set dp[i] to 1 because every element alone forms an increasing subsequence.
  2. For each earlier j, check whether arr[j] < arr[i].
  3. If so, arr[i] can extend the subsequence ending at j.
  4. The largest dp value is the LIS length.

6Time and space complexity

Time: O(n²)

Space: O(n)

7Common mistakes

  • A subsequence does not need to be contiguous.
  • Strictly increasing means equal values cannot extend the sequence.
  • The quadratic DP is not the fastest known LIS solution, but it is easier to learn first.

8When to use it (and when not to)

Use it when: Use this version when clarity is more important than the advanced O(n log n) optimization.

Avoid it when: For very large arrays, learn the patience-sorting/binary-search based O(n log n) solution.
