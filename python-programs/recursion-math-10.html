Factorial of a number using Recursion in Python

Calculate factorial recursively using n == 0 as the base case. This is mathematically equivalent to the first factorial version but highlights a different stopping condition.

1Python program

program_10.py
# Factorial of a number using Recursion : 

def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n-1)

n = 5
print(f"Factorial of {n} is {factorial(n)}")


# Output : 

# Factorial of 5 is 120

2Why it matters

Comparing two correct recursive implementations helps you see that the same mathematical definition can have slightly different but equivalent base cases.

Simple example

For 5!, the calls reach factorial(0), which returns 1, then the results unwind to 120.

3How it works

  1. Return 1 when n equals zero.
  2. For positive n, call factorial(n - 1).
  3. Multiply the returned value by n.
  4. Allow the recursive calls to unwind back to the original call.

6Time and space complexity

Time: O(n)

Space: O(n) call stack

7Common mistakes

  • Do not use 0 as the base return value; that would make every factorial zero.
  • The recursive call must decrease n.
  • This version assumes non-negative integer input.

8When to use it (and when not to)

Use it when: Use it when you want the implementation to mirror the definition n! = n × (n-1)! with 0! = 1.

Avoid it when: For ordinary production code, iteration or math.factorial may be preferable depending on the context.
