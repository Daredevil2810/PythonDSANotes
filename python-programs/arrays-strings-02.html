Reverse an Array in Python

Reverse an array by placing one pointer at the beginning and another at the end, swapping their values, and moving both pointers toward the center.

1Python program

program_02.py
# Reverse an Array :

arr = [10,20,30,40,50]

start = 0
end = len(arr) - 1

while start < end:

    temp = arr[start]
    arr[start] = arr[end]
    arr[end] = temp

    start += 1
    end -= 1

print("Reversed array : ", arr)


# Output : 

# Reversed array :  [50, 40, 30, 20, 10]

2Why it matters

This is a foundational two-pointer pattern. It reverses the array without creating another array.

Simple example

Put your left hand on the first book and your right hand on the last book. Swap them, then move both hands inward.

3How it works

  1. Set start to the first index and end to the last index.
  2. Swap the values at start and end.
  3. Move start one step right and end one step left.
  4. Stop when the pointers meet or cross.

4Line-by-line meaning

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • Using <= is possible but performs an unnecessary middle self-swap.
  • Moving only one pointer can cause an incorrect or infinite traversal.
  • Creating reversed_arr is simpler but changes the space complexity to O(n).

8When to use it (and when not to)

Use it when: Use two pointers when work naturally happens from both ends of a sequence.

Avoid it when: If the data must remain unchanged, use a new array/string instead of mutating the original.
