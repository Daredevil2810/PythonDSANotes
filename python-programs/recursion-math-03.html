GCD (Greatest Common Divisor) using Recursion in Python

Find the greatest common divisor by repeatedly replacing (a, b) with (b, a mod b) until the second value becomes zero.

1Python program

program_03.py
# GCD (Greatest Common Divisor) using Recursion : 

def gcd(a, b):
    if b == 0:
        return a
    else:
        return gcd(b, a%b)
    
a, b = 48, 18
print(f"GCD of {a} and {b} is {gcd(a, b)}")


# Output : 

# GCD of 48 and 18 is 6

2Why it matters

The Euclidean algorithm is a classic example of recursion driven by a mathematical invariant and is much faster than checking every possible divisor.

Simple example

For 48 and 18: 48 mod 18 = 12, then 18 mod 12 = 6, then 12 mod 6 = 0. Therefore the GCD is 6.

3How it works

  1. If b is zero, a is the GCD.
  2. Otherwise calculate a % b.
  3. Recursively solve gcd(b, a % b).
  4. Stop when the remainder becomes zero.

return aThe non-zero value is the GCD.

6Time and space complexity

Time: O(log(min(a,b)))

Space: O(log(min(a,b))) call stack

7Common mistakes

  • The recursive arguments must be gcd(b, a % b), not gcd(a, a % b).
  • The base case is b == 0.
  • Be explicit about how negative inputs should be handled if the problem allows them.

8When to use it (and when not to)

Use it when: Use the Euclidean algorithm whenever you need the GCD of integers efficiently.

Avoid it when: There is little reason to replace it with a brute-force divisor scan unless teaching the basic idea first.
