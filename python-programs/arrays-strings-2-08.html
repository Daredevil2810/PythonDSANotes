Reverse a String in Python

Build a reversed string by placing each newly visited character before the current result.

1Python program

program_08.py
# Reverse a String :

str_val = "Hello World"
# reversed_str = str_val[::-1]

reversed_str = ""
for ch in str_val:
    reversed_str = ch + reversed_str

print("Reversed string : ", reversed_str)


# Output : 

# Reversed string :  dlroW olleH

2Why it matters

It demonstrates how the direction in which a result is built changes the final ordering.

Simple example

Starting with an empty result, read H → e → l and build H, eH, leH, producing the reverse.

3How it works

  1. Start with an empty result.
  2. Read characters from left to right.
  3. Prepend each character to the result.
  4. The final string is reversed.

6Time and space complexity

Time: O(n²) with repeated immutable-string concatenation

Space: O(n)

7Common mistakes

  • Prepending to an immutable string repeatedly can be quadratic.
  • This differs from appending characters while iterating backward.
  • str[::-1] is usually the clearest production solution.

8When to use it (and when not to)

Use it when: Use it for learning string construction or when explaining how prepend operations affect order.

Avoid it when: For performance-sensitive string reversal, prefer slicing or a list plus join.

9Interview questions to expect

  • Why can repeated string concatenation be expensive?
  • How would you reverse using a list?
  • What does [::-1] mean?
