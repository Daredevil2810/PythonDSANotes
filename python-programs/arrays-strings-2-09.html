Count Vowels and Consonants in a string in Python

Count vowels and consonants by inspecting each alphabetic character and checking whether it belongs to a predefined vowel set.

1Python program

program_09.py
# Count Vowels and Consonants in a string :

str_val = "Hello World"
vowels = 0
consonants = 0
str_val = str_val.lower()

for ch in str_val:
    if 'a' <= ch <= 'z':
        if ch in "aeiou":
            vowels += 1
        else:
            consonants += 1

print(f"Vowels: {vowels}, Consonants: {consonants}")


# Output : 

# Vowels: 3, Consonants: 7

2Why it matters

It combines string traversal, membership testing, and careful input classification.

Simple example

In “Hello”, e and o are vowels; H, l, l are consonants.

3How it works

  1. Normalize the character to lowercase.
  2. Ignore non-alphabetic characters.
  3. If the character is in the vowel set, increment vowels.
  4. Otherwise increment consonants.

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • Decide whether y counts as a vowel before coding.
  • Spaces and punctuation should not automatically count as consonants.
  • Unicode letters require more careful rules than simple English vowels.

8When to use it (and when not to)

Use it when: Use this approach for simple English-alphabet classification problems.

Avoid it when: For full linguistic vowel/consonant classification across languages, a fixed English vowel set is insufficient.
