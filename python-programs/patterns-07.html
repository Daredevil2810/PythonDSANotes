Diamond Pattern in Python

Print a full pyramid, then print a smaller inverted pyramid starting from rows - 1 to avoid repeating the center row.

1Python program

program_07.py
# Diamond Pattern :

# Diamond Pattern
rows = int(input("Enter number of rows: "))

# Upper pyramid
for i in range(1, rows + 1):
    print(" " * (rows - i) + "*" * (2 * i - 1))

# Lower inverted pyramid
for i in range(rows - 1, 0, -1):
    print(" " * (rows - i) + "*" * (2 * i - 1))


# Output :

# Enter number of rows: 5
#     *
#    ***
#   *****
#  *******
# *********
#  *******
#   *****
#    ***
#     *

2Why it matters

It teaches decomposition: a more complex pattern can be built by combining two simpler patterns.

Simple example

For 5 rows, the upper half has widths 1,3,5,7,9 and the lower half has 7,5,3,1.

3How it works

  1. Print the normal centered pyramid.
  2. Start a second loop at rows - 1.
  3. Use the same spacing and odd-width formulas for the lower half.
  4. The center row is printed only once.

4Line-by-line meaning

CodeWhat it means
for i in range(1, rows + 1):Builds the upper pyramid.
for i in range(rows - 1, 0, -1):Builds the lower half without duplicating the center.
" " * (rows - i)Aligns each half around the same center.
"*" * (2 * i - 1)Keeps widths symmetric.

5Dry run

StepWhat happens
Upper half1, 3, 5, 7, 9 stars
Lower startBegin at i = 4, not 5
Lower half7, 5, 3, 1 stars
ResultA symmetric 9-row diamond

6Time and space complexity

Time: O(rows²) characters overall

Space: O(rows) for temporary row strings

7Common mistakes

  • Starting the lower loop at rows and duplicating the middle row.
  • Changing the spacing formula between halves.
  • Thinking the diamond requires a completely different algorithm.

8When to use it (and when not to)

Use it when: Use decomposition when a pattern is naturally made from two related shapes.

Avoid it when: Avoid duplicating large blocks of nearly identical code when a helper function can express the repeated row logic clearly.

9Interview questions to expect

  • Why does the lower loop start at rows - 1?
  • How is a diamond related to a pyramid?
  • How many rows does a diamond with input n contain?
