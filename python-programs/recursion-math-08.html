Check Palindrome number using Recursion in Python

Reverse the number recursively and compare the reversed value with the original value.

1Python program

program_08.py
# Check Palindrome number using Recursion : 

def reverse_num(n, rev = 0):
    if n == 0:
        return rev
    return reverse_num(n // 10, rev * 10 + n % 10)

def is_palindrome(n):
    return n == reverse_num(n)

n = 12321
print(f"{n} is a palindrome" if is_palindrome(n) else f"{n} is not a palindrome")


# Output :

# 12321 is a palindrome

2Why it matters

It combines two previously learned ideas—recursive digit reversal and equality checking—into a complete problem-solving pattern.

Simple example

12321 reverses to 12321, so the original and reversed numbers are equal and the number is a palindrome.

3How it works

  1. Keep the original number unchanged.
  2. Recursively build its reversed value.
  3. Compare the original and reversed values.
  4. If they match, the number is a palindrome.

6Time and space complexity

Time: O(d), where d is the number of digits

Space: O(d) call stack

7Common mistakes

  • Keep the original number available for comparison.
  • Do not accidentally compare after mutating the only copy of the input.
  • Clarify whether negative numbers are considered palindromes.

8When to use it (and when not to)

Use it when: Use numeric reversal when the problem specifically asks you to reason about integer digits.

Avoid it when: For straightforward Python code, string normalization may be simpler if converting to a string is allowed.
