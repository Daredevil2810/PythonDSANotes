Reverse an Array in Python

Reverse the array by swapping symmetric elements until the two pointers meet.

1Python program

program_02.py
# Reverse an Array :

arr = [1, 2, 3, 4, 5]
start = 0
end = len(arr)-1

while start < end:
    arr[start], arr[end] = arr[end], arr[start]
    start += 1
    end -= 1

print("Reversed array : ", arr)


# Output :

# Reversed array :  [5, 4, 3, 2, 1]

2Why it matters

This is the same two-pointer idea as the first reversal program, but it gives you a chance to compare two equivalent implementations.

Simple example

Swap the first and last cards, then the second and second-last cards, until the deck is reversed.

3How it works

  1. Initialize start and end.
  2. Swap arr[start] and arr[end].
  3. Move both pointers inward.
  4. Stop when start is no longer less than end.

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • Do not move pointers in the wrong direction.
  • Do not continue after they cross.
  • This mutates the original list.

8When to use it (and when not to)

Use it when: Use it when an in-place reversal is required and the language supports convenient swapping.

Avoid it when: Use a copied result if the original ordering must be preserved.
