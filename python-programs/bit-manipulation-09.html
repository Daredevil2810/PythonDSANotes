Find the Only Non-Repeating Element (when others appear twice) in Python

XOR every element in an array where exactly one value appears once and every other value appears twice.

1Python program

program_09.py
# Find the Only Non-Repeating Element (when others appear twice) :

def find_unique(arr):
    result = 0
    for num in arr:
        result ^= num  # XOR all elements
    return result

arr = [2, 3, 5, 4, 5, 3, 2]
print("The unique element is:", find_unique(arr))


# Output :

# The unique element is: 4

2Why it matters

Pairs cancel because x ^ x = 0, leaving the single unpaired value without sorting or extra frequency storage.

Simple example

[2, 3, 5, 4, 5, 3, 2] XORs to 4 because every repeated value cancels with itself.

3How it works

  1. Start result at 0.
  2. XOR result with every array element.
  3. Repeated values eventually contribute x ^ x = 0.
  4. The unique value is the only value left in the XOR result.

6Time and space complexity

Time: O(n)

Space: O(1) auxiliary

7Common mistakes

  • Applying the method when a value occurs three times or the problem has multiple unique values.
  • Forgetting the required condition that every other element appears exactly twice.
  • Sorting unnecessarily when the XOR property solves the constrained problem directly.

8When to use it (and when not to)

Use it when: Use it when exactly one element is unique and all others occur exactly twice.

Avoid it when: Do not use it when occurrence counts do not match the required XOR cancellation pattern.
