Find second largest element in array in Python

Find the second-largest distinct value without sorting by maintaining the largest and second-largest values seen so far.

1Python program

program_07.py
# Find second largest element in array : 

arr = [1, 10, 4, 11, 23, 5]
first = float('-inf')
second = float('-inf')

for num in arr:
    if num > first:
        second = first
        first = num
    elif num > second and num != first:
        second = num

print("Second largest element is ", second)


# Output :

# Second largest element is  11

2Why it matters

It demonstrates how multiple running state variables can replace sorting.

Simple example

While reading scores, keep the highest score and the best score below it. Update both whenever a new value changes the ranking.

3How it works

  1. Initialize first and second to negative infinity.
  2. For each number, if it is larger than first, move first into second and make the number first.
  3. Otherwise, if it is between first and second and is distinct from first, update second.
  4. After the scan, second is the second-largest distinct value.

4Line-by-line meaning

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • You must decide whether “second largest” means distinct values.
  • Initializing to 0 fails when all numbers are negative.
  • Sorting gives O(n log n), but is unnecessary here.

8When to use it (and when not to)

Use it when: Use this pattern when you need the top one or two values from a stream without sorting.

Avoid it when: If you need the top k values for large k, a heap may be more suitable.
