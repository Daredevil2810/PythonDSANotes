Bubble sort in Python

Sort an array by repeatedly swapping adjacent elements that are out of order, causing the largest remaining value to move toward the end.

1Python program

program_04.py
# Bubble sort systematically :

# Bubble Sort repeatedly swaps adjacent elements if they are in the wrong order.(It start with pushing the largest elment to the end of arr)

arr = [64, 34, 25, 12, 22]
n = len(arr)

for i in range(n - 1):
    for j in range(n -i -1):
        if arr[j] > arr[j + 1]:
            arr[j], arr[j + 1] = arr[j + 1], arr[j]

print("Sorted array : ", arr)


# Output :

# Sorted array :  [12, 22, 25, 34, 64]

2Why it matters

Bubble sort is simple to visualize and is useful for understanding nested loops, local swaps, and repeated passes.

Simple example

In [64,34,25,12,22], each pass pushes a large value toward the right until the entire array is sorted.

3How it works

  1. Make a pass through the unsorted portion.
  2. Compare each adjacent pair.
  3. Swap the pair when the left value is larger.
  4. After each pass, the largest remaining value reaches the end.
  5. Repeat until all positions are sorted.

4Line-by-line meaning

CodeWhat it means
for i in range(n - 1)Run enough passes to place every element.
for j in range(n - i - 1)Scan only the part that is not already fixed at the end.
if arr[j] > arr[j + 1]Detect an adjacent inversion.
arr[j], arr[j+1] = ...Swap the two values.

5Dry run

StepWhat happens
[64,34]Swap → [34,64]
[64,25]Swap → [34,25,64]
[64,12]Swap → [34,25,12,64]
[64,22]Swap → [34,25,12,22,64]
Next passesContinue bubbling the next-largest values rightward
Result[12,22,25,34,64]

6Time and space complexity

Time: O(n²) average/worst case

Space: O(1)

7Common mistakes

  • Using the wrong inner-loop boundary can access j+1 out of range.
  • Forgetting that each pass fixes one more element at the end.
  • This exact implementation does not include the early-exit optimization for an already sorted array.

8When to use it (and when not to)

Use it when: Use it mainly for learning, tiny inputs, or situations where simplicity matters more than speed.

Avoid it when: Avoid it for large arrays; faster sorting algorithms are normally preferable.

9Interview questions to expect

  • Why does the largest value move to the end after a pass?
  • How can Bubble Sort be optimized for an already sorted array?
  • Is Bubble Sort stable?
