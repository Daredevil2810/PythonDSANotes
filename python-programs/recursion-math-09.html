Count Number of Digits using Recursion in Python

Count how many times a number can be divided by 10 before reaching zero.

1Python program

program_09.py
# Count Number of Digits using Recursion : 

def count_digits(n):
    if n == 0:
        return 0
    else:
        return 1 + count_digits(n // 10)
    
n = 12345
print(f"Number of digits in {n} is {count_digits(n)}")


# Output : 

# Number of digits in 12345 is 5

2Why it matters

It reinforces the same digit-decomposition pattern used for digit sums and reversal.

Simple example

12345 becomes 1234, 123, 12, 1, and 0. There were five removals, so there are five digits.

3How it works

  1. If n is zero, return zero.
  2. Count one digit for the current number.
  3. Remove the last digit with n // 10.
  4. Add one to the recursive result.

6Time and space complexity

Time: O(d), where d is the number of digits

Space: O(d) call stack

7Common mistakes

  • The special case n = 0 is important because zero has one digit in normal decimal notation.
  • Negative inputs need explicit handling.
  • Using floating-point division changes the type and breaks the intended integer recursion.

8When to use it (and when not to)

Use it when: Use it as a recursion exercise or as a building block for digit-based problems.

Avoid it when: Use len(str(abs(n))) when conversion to a string is acceptable and clarity is the priority.
