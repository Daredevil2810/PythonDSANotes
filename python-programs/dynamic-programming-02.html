Longest Common Subsequence (LCS) Problem in Python

Find the length of the longest sequence that appears in both strings in the same relative order, without requiring the characters to be adjacent.

1Python program

program_02.py
# Longest Common Subsequence (LCS) Problem :

def lcs(X, Y):
    m, n = len(X), len(Y)
    dp = [[0] * (n+1) for _ in range(m+1)]

    for i in range(m+1):
        for j in range(n+1):
            if i == 0 or j == 0:
                dp[i][j] = 0
            elif X[i-1] == Y[j-1]:
                dp[i][j] = 1 + dp[i-1][j-1]
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]

X = "AGGTAB"
Y = "GXTXAYB"
print("Length of LCS:", lcs(X, Y))


# Output :

# Length of LCS: 4

2Why it matters

LCS teaches a classic two-dimensional DP state: each cell summarizes the best answer for prefixes of the two strings.

Simple example

3How it works

  1. Let dp[i][j] represent the LCS length for X[:i] and Y[:j].
  2. If the current characters match, extend the diagonal answer.
  3. Otherwise choose the better answer from dropping one character from either string.
  4. The bottom-right cell contains the final answer.

Time: O(mn)

7Common mistakes

  • LCS is not the same as longest common substring; characters do not need to be adjacent.
  • The DP indexes refer to prefixes, so use i-1 and j-1 for string characters.
  • Returning the length is simpler than reconstructing the actual subsequence.

8When to use it (and when not to)

Use it when: Use it for sequence comparison, diff-like tasks, and as a foundation for other string DP problems.

Avoid it when: For very large strings, a full matrix may be too memory-heavy; space-optimized variants are possible when only the length is needed.
