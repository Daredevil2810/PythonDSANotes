Insert Node at Specific Position in Python

Find the node before the target position and splice the new node into the chain.

1Python program

program_04.py
# Insert Node at Specific Position :

# If the position is 1, insert at the beginning, If the position is greater than the list length + 1, the insertion is invalid.

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

def insert_at_position(head, data, position):
    new_node = Node(data)
    if position == 1:
        new_node.next = head
        return new_node

    current = head
    count = 1
    while current and count < position - 1:
        current = current.next
        count += 1

    if current:
        new_node.next = current.next
        current.next = new_node
    else:
        print("Position out of bounds")
    return head

def display(head):
    current = head
    while current:
        print(current.data, end=" -> ")
        current = current.next
    print("None")

head = Node(10)
head.next = Node(20)
head.next.next = Node(30)

print("Original Linked List:")
display(head)

head = insert_at_position(head, 25, 3)
print("After Inserting 25 at Position 3:")
display(head)


# Output : 

# Original Linked List:
# 10 -> 20 -> 30 -> None
# After Inserting 25 at Position 3:
# 10 -> 20 -> 25 -> 30 -> None

2Why it matters

It teaches pointer rewiring: the surrounding links are changed while the rest of the list is preserved.

Simple example

Insert 25 at position 3 in 10 → 20 → 30 by linking 25 between 20 and 30.

3How it works

  1. Handle position 1 separately.
  2. Traverse to the predecessor node.
  3. Set new_node.next to current.next.
  4. Set current.next to new_node.

4Line-by-line meaning

CodeWhat it means
if position == 1Handles insertion before the current head.
while current and count < position - 1Finds the predecessor.
new_node.next = current.nextPreserves the remainder of the list.
current.next = new_nodeSplices in the new node.

6Time and space complexity

Time: O(n)

Space: O(1) auxiliary

7Common mistakes

  • Overwriting current.next before preserving it.
  • Mixing 1-based and 0-based positions.
  • Ignoring out-of-bounds positions.

8When to use it (and when not to)

Use it when: Use it when insertion is position-based and only the head reference is available.

Avoid it when: Avoid indexed linked-list operations when frequent random access is the real requirement.

9Interview questions to expect

  • Why find the predecessor first?
  • Which two links change?
  • How would zero-based indexing alter the logic?

10Try it yourself
