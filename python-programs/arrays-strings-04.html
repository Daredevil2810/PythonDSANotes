Count Occurrences of an Element in an Array in Python

Count how many times a target value appears by increasing a counter whenever the current element matches it.

1Python program

program_04.py
# Count Occurrences of an Element in an Array :

arr = [1, 2, 3, 4, 2, 5]

target = 2
count = 0

for num in arr:
    if num == target:
        count += 1

print(f"Element {target} occurs {count} times")


# Output : 

# Element 2 occurs 2 times

2Why it matters

Counting is one of the most common array operations and introduces the accumulator pattern.

Simple example

If a class list contains several grades, scan each grade and add one to the count whenever it equals the grade you are tracking.

3How it works

  1. Initialize count to zero.
  2. Visit each element once.
  3. If it equals target, increment count.
  4. Return the final count.

6Time and space complexity

Time: O(n)

Space: O(1)

7Common mistakes

  • Starting count at 1 gives an incorrect answer when the target is absent.
  • Changing the loop to stop after the first match changes the problem.
  • Do not confuse value frequency with index position.

8When to use it (and when not to)

Use it when: Use a simple counter when you need the frequency of one known value.

Avoid it when: If you need frequencies for many different values, build a frequency dictionary in one pass.

9Interview questions to expect

  • How would you count every distinct value at once?
  • What is the space complexity of a frequency dictionary?
  • How would you find the most frequent element?

10Try it yourself

  • Count values greater than a target.
  • Build a frequency dictionary for the entire array.
