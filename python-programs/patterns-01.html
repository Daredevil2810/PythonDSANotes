Solid Rectangle Pattern in Python

Use an outer loop for rows and an inner loop for the fixed number of columns.

1Python program

program_01.py
# Solid Rectangle Pattern :

rows = int(input("Enter number of rows: "))
cols = int(input("Enter number of columns: "))

for i in range(rows):
    for j in range(cols):
        print("*", end="")
    print()


# Output : 

# Enter number of rows: 3
# Enter number of columns: 5
# *****
# *****
# *****

2Why it matters

It is the simplest nested-loop pattern and teaches the important idea that one loop controls repetition of another loop.

Simple example

With 3 rows and 5 columns, each row contains five stars, so the output is a 3 × 5 block.

3How it works

  1. Read rows and columns.
  2. Repeat once for every row.
  3. Inside each row, print one star for every column without moving to a new line.
  4. After the inner loop finishes, print a newline.

4Line-by-line meaning

CodeWhat it means
for i in range(rows):Controls how many rows are produced.
for j in range(cols):Controls the number of characters in each row.
print("*", end="")Prints each star on the same line.
print()Moves to the next row after the inner loop.

5Dry run

StepWhat happens
rows = 3, cols = 5The outer loop will run 3 times.
First rowInner loop prints 5 stars → *****
Second rowInner loop prints 5 stars → *****
Third rowInner loop prints 5 stars → *****

6Time and space complexity

Time: O(rows × cols)

Space: O(1) auxiliary

7Common mistakes

  • Putting print() inside the inner loop and creating one star per line.
  • Using rows for both loops when the rectangle is not square.
  • Forgetting end="" and getting spaces/newlines between every star.

8When to use it (and when not to)

Use it when: Use it to practice nested loops or whenever a rectangular repeated-character layout is required.

Avoid it when: Avoid nested loops when a direct string repetition such as "" cols is clearer for the exact task.

9Interview questions to expect

  • Which loop controls rows and which controls columns?
  • Why is the newline printed after the inner loop?
  • What is the time complexity?

10Try it yourself

  • Change the character from * to #.
  • Print a 4 × 7 rectangle.
  • Rewrite one row using string multiplication.
