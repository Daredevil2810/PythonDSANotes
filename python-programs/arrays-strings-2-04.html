Find Average of Array elements in Python

Calculate the arithmetic mean by adding the values and dividing the total by the number of elements.

1Python program

program_04.py
# Find Average of Array elements :

arr = [1, 2, 3, 4, 5]
sum_val = 0

for i in arr:
    sum_val += i

average = sum_val / len(arr)
print("Average of array elements is ", average)


# Output : 

# Average of array elements is  3.0

2Why it matters

It combines two basic patterns—accumulation and counting—and highlights edge cases such as an empty collection.

Simple example

If five days have temperatures 1,2,3,4,5, their average is 15 / 5 = 3.

3How it works

  1. Accumulate the sum.
  2. Count or obtain the number of elements.
  3. Divide sum by length.
  4. Handle an empty array according to the problem requirements.

7Common mistakes

  • Dividing by zero for an empty array is an error.
  • / produces a float in Python.
  • Do not use integer division // if the exact average is required.

8When to use it (and when not to)

Use it when: Use the mean when every value should contribute equally to a central value.

Avoid it when: The mean can be misleading for heavily skewed data; the problem may instead ask for median or another statistic.
