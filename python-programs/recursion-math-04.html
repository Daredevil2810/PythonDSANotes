LCM (Least Common Multiple) using GCD in Python

Find the least common multiple using the relationship LCM(a,b) = |a × b| / GCD(a,b).

1Python program

program_04.py
# LCM (Least Common Multiple) using GCD :

def gcd(a, b):
    if b == 0:
        return a
    else:
        return gcd(b, a % b)

def lcm(a, b):
    return (a * b) // gcd(a, b)

a, b = 48, 18
print(f"LCM of {a} and {b} is {lcm(a, b)}")


# Output : 

# LCM of 48 and 18 is 144

2Why it matters

It connects two number-theory concepts and shows how one efficient helper function can simplify another problem.

Simple example

For 48 and 18, GCD is 6, so LCM = (48 × 18) / 6 = 144.

3How it works

  1. Compute the GCD with the Euclidean algorithm.
  2. Multiply a and b.
  3. Divide the product by the GCD.
  4. For general signed inputs, use absolute values as appropriate.

6Time and space complexity

Time: O(log(min(a,b)))

Space: O(log(min(a,b))) with recursive GCD

7Common mistakes

  • Do not divide by an arbitrary common divisor; it must be the GCD.
  • For negative inputs, decide whether the expected LCM should be positive.
  • LCM involving zero needs an explicit rule in production code.

8When to use it (and when not to)

Use it when: Use the GCD relationship when you need the LCM of two integers.

Avoid it when: For many numbers, consider reducing them pairwise rather than inventing a separate brute-force search.
