Reverse a number using Recursion in Python

Build the reversed number by moving the current last digit into an accumulator before recursively removing that digit from the original number.

1Python program

program_07.py
# Reverse a number using Recursion :

def reverse_num(n, rev = 0):
    if n == 0:
        return rev
    else:
        return reverse_num(n // 10, rev * 10 + n % 10)

n = 12345
print(f"Reverse of {n} is {reverse_num(n)}")


# Output :

# Reverse of 12345 is 54321

2Why it matters

The accumulator parameter demonstrates how information can be carried through recursive calls instead of waiting until the recursion unwinds.

Simple example

For 12345, the accumulator evolves as 5, 54, 543, 5432, and finally 54321.

3How it works

  1. Start the reverse accumulator at zero.
  2. Extract the last digit with n % 10.
  3. Append it numerically with rev * 10 + digit.
  4. Recursively process n // 10 until n is zero.

4Line-by-line meaning

CodeWhat it means
if n == 0Stops when there are no digits left.
n % 10Gets the last digit.
rev * 10 + n % 10Shifts existing digits left and appends the new digit.
reverse_num(n // 10, ...)Removes the processed digit and continues recursively.

6Time and space complexity

Time: O(d), where d is the number of digits

Space: O(d) call stack

7Common mistakes

  • The accumulator must be multiplied by 10 before adding the new digit.
  • Integer division is needed to remove the last digit.
  • Leading zeros in the reversed result are naturally lost because the result is an integer.

8When to use it (and when not to)

Use it when: Use an accumulator when a recursive computation needs to build a result as it descends.

Avoid it when: If recursion is not required, converting to a string and slicing may be simpler for basic reversal tasks.

9Interview questions to expect

  • Why is rev multiplied by 10?
  • How would you reverse a negative number?
  • How would you detect integer overflow in a fixed-width language?
