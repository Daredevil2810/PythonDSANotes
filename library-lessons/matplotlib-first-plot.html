Your first chart with Matplotlib

Install Matplotlib, draw a line chart in three lines, and learn how x and y values turn into a picture.

1What is it?

Matplotlib is Python's most popular library for drawing charts. You use its pyplot module, normally imported as plt, to turn lists of numbers into line charts, bar charts, scatter plots and more.

2Why do we need it?

Numbers in a table are hard to read. A chart shows a trend, a spike or a pattern in a second. Matplotlib is also the engine behind many other tools (Pandas plotting, Seaborn), so learning it first makes the rest easier.

3In plain words

Everyday example

Think of graph paper. You give Matplotlib the positions along the bottom (the x values) and the heights (the y values). It puts a dot at every pair and joins the dots with a line.

Precise definition

plt.plot(x, y) creates a line plot for the current figure and plt.show() displays it. The x and y sequences must have the same length. If you pass only one sequence, Matplotlib treats it as the y values and uses 0, 1, 2, ... for x.

  1. Install Matplotlib once with pip.
  2. Import matplotlib.pyplot as plt.
  3. Call plt.plot(x, y) with two lists of the same length.
  4. Call plt.show() to display the chart.
  5. Pass a third argument such as 'o' to draw dots only.

4Code, step by step

Install and import

structure
pip install matplotlib      # run once, in your terminal

import matplotlib.pyplot as plt   # at the top of every script
LineWhat it means
pip install matplotlibDownloads Matplotlib from PyPI. Run it in your terminal one time, not inside a Python file.
import matplotlib.pyplot as pltLoads the plotting module. plt is the short name everyone uses.

A line chart in three lines

lesson_2.py
import matplotlib.pyplot as plt

days = [1, 2, 3, 4, 5, 6, 7]
steps = [4, 6, 5, 8, 7, 9, 10]

plt.plot(days, steps)
plt.show()
LineWhat it means
days = [1, 2, 3, 4, 5, 6, 7]The x values, placed along the bottom of the chart.
steps = [4, 6, 5, 8, 7, 9, 10]The y values, the height at each x. There must be exactly as many as x values.
plt.plot(days, steps)Prepares a line through the points (1, 4), (2, 6), (3, 5) and so on.
plt.show()Displays the chart. Nothing appears on screen until you call this.

Only y values: x is filled in for you

lesson_3.py
import matplotlib.pyplot as plt

plt.plot([3, 8, 5, 10])
plt.show()
LineWhat it means
plt.plot([3, 8, 5, 10])With one list, Matplotlib treats it as the y values and uses the positions 0, 1, 2, 3 for x. That is why the x axis starts at 0.
plt.show()Draws the chart.

Dots instead of a line

lesson_4.py
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [2, 4, 3, 7, 6]

plt.plot(x, y, 'o')
plt.show()
LineWhat it means
plt.plot(x, y, 'o')The third argument is a format string. 'o' means draw a round marker at every point and no line.
plt.show()Displays the dots.

5Common mistakes

  • Giving x and y lists of different lengths. Matplotlib raises a ValueError about shapes.
  • Forgetting plt.show() in a script. The code runs but no window appears.
  • Naming your own file matplotlib.py or pyplot.py. Python then imports your file instead of the library and everything breaks.
  • Expecting the x axis to start at 1 when you pass only y values. It starts at 0.

6When should I use it?

Use a line chart when order matters, for example values over time: daily steps, monthly sales, temperature across a week.

7Interview questions

What is Matplotlib?

A Python library for creating static charts. Its pyplot module gives a simple, MATLAB-like way to draw them.

What does plt.plot(y) do when you give only one list?

It uses the list as the y values and sets x to 0, 1, 2, and so on.

What does plt.show() do?

It displays the figure you have prepared. Without it, a script will not open the chart.

What does the format string 'o' mean?

Draw circle markers only, with no connecting line.
