Pandas DataFrame: tables in Python

Create a table, pick out columns and rows, and add a new column calculated from the others.

1What is it?

A DataFrame is a table with rows and columns. Each column is a Series, and all the columns share the same row labels (the index).

2Why do we need it?

Almost every real dataset is a table: students and marks, orders and prices, dates and temperatures. A DataFrame lets you slice, calculate and summarise that table with a few short lines instead of nested loops.

3In plain words

Everyday example

Picture a spreadsheet or your school register: headings across the top and one row per student. A DataFrame is that sheet living inside Python, where you can ask questions about it with code.

Precise definition

A DataFrame is a two-dimensional, size-mutable table of labelled columns that can hold different dtypes. Selecting one column returns a Series; selecting several returns a smaller DataFrame. .loc selects by label and .iloc by integer position.

  1. Put each column's values in a list and collect the lists in a dictionary.
  2. Pass the dictionary to pd.DataFrame().
  3. Select columns with df["col"] or df[["a", "b"]].
  4. Select rows with .loc (labels) or .iloc (positions).
  5. Create a new column by assigning to a new name.

4Code, step by step

Create a DataFrame from a dictionary

lesson_1.py
import pandas as pd

data = {
    "name": ["Asha", "Ravi", "Meena", "Kabir"],
    "maths": [78, 90, 66, 84],
    "science": [82, 75, 70, 91],
}
df = pd.DataFrame(data)
print(df)
print("Shape:", df.shape)
OUTPUT
    name  maths  science
0   Asha     78       82
1   Ravi     90       75
2  Meena     66       70
3  Kabir     84       91
Shape: (4, 3)
LineWhat it means
data = { ... }Each key is a column heading and each list holds that column's values. All lists must be the same length.
df = pd.DataFrame(data)Turns the dictionary into a table. The row labels 0, 1, 2, 3 are added automatically.
df.shapeA tuple of (number of rows, number of columns).

Pick rows with loc and iloc

lesson_3.py
import pandas as pd

df = pd.DataFrame({
    "name": ["Asha", "Ravi", "Meena", "Kabir"],
    "maths": [78, 90, 66, 84],
})
print(df.loc[0])
print(df.iloc[1])
print(df.loc[[0, 2]])
print(df.loc[1, "name"])
OUTPUT

Name: 1, dtype: object

LineWhat it means
df.loc[0]Row labelled 0, returned as a Series whose labels are the column names.
df.iloc[1]The second row by position. Here the label and the position happen to match.
df.loc[[0, 2]]A list of labels returns those rows as a DataFrame.
df.loc[1, "name"]Row label first, column label second, which gives a single value.

Use a named index and add a column

lesson_4.py
import pandas as pd

df = pd.DataFrame({
    "name": ["Asha", "Ravi", "Meena", "Kabir"],
    "maths": [78, 90, 66, 84],
    "science": [82, 75, 70, 91],
})
df = df.set_index("name")
df["total"] = df["maths"] + df["science"]
print(df)
print(df.loc["Ravi"])
OUTPUT
       maths  science  total
name                        
Asha      78       82    160
Ravi      90       75    165
Meena     66       70    136
Kabir     84       91    175
maths       90
science     75
total      165
Name: Ravi, dtype: int64
LineWhat it means
df.set_index("name")Makes the name column the row labels. It returns a new DataFrame, so we assign it back to df.
df["total"] = df["maths"] + df["science"]Adds two columns row by row and stores the result in a new column called total.
df.loc["Ravi"]Rows are now found by name instead of by 0, 1, 2.

5Common mistakes

  • Using df["name", "maths"] for two columns. Use double brackets: df[["name", "maths"]].
  • Mixing up .loc (labels) and .iloc (positions). After set_index, the label "Ravi" and the position 1 are different things.
  • Expecting df.loc[0:2] to stop before 2. With .loc the end label is included; with .iloc the end position is excluded.

6When should I use it?

Use a DataFrame whenever your data has several related columns: any CSV, spreadsheet or database table you want to analyse.

7Interview questions

What is the difference between a Series and a DataFrame?

A Series is one labelled column. A DataFrame is a table of several columns that share one index.

What is the difference between loc and iloc?

loc selects by label (row and column names). iloc selects by integer position.

How do you add a new column?

Assign to a new column name, for example df["total"] = df["maths"] + df["science"]. The calculation runs for every row.

How do you select more than one column?

Pass a list of names: df[["name", "maths"]].

8Try it yourself

Create a DataFrame with 3 products: pen (price 10, qty 5), book (price 120, qty 2) and bag (price 450, qty 1). Add a revenue column equal to price * qty and print the DataFrame.

Show hint
Hint: Use a dictionary with item, price and qty lists, then assign df["revenue"] = df["price"] * df["qty"].
Show solution
solution.py
import pandas as pd

df = pd.DataFrame({
    "item": ["pen", "book", "bag"],
    "price": [10, 120, 450],
    "qty": [5, 2, 1],
})
df["revenue"] = df["price"] * df["qty"]
print(df)
OUTPUT
   item  price  qty  revenue
0   pen     10    5       50
1  book    120    2      240
2   bag    450    1      450
