Titles, labels, legends and grids

Turn a bare chart into one that explains itself, with a title, axis labels, a legend and a grid.

1What is it?

A chart without labels is a puzzle. Matplotlib lets you add a title, axis labels, a legend (a key that names each line) and a grid with one function call each.

2Why do we need it?

People often see your chart without you there to explain it, for example in a report or a LinkedIn post. Labels say what is measured and in which units, so the picture can be understood on its own.

3In plain words

Everyday example

Think of a map without a legend. You see colours and lines but cannot tell what they mean. Titles, labels and a legend are the key that makes the map readable.

Precise definition

plt.title(), plt.xlabel() and plt.ylabel() set the text. To get a legend, give each plot call a label='...' and then call plt.legend(). plt.grid(True) adds grid lines. Several plt.plot() calls before one plt.show() draw on the same chart.

  1. Draw your data with plt.plot(...).
  2. Add plt.title('...') for the overall message.
  3. Add plt.xlabel() and plt.ylabel(), including units.
  4. Give each line label='...' and call plt.legend().
  5. Add plt.grid(True) if it helps people read values.

4Code, step by step

Title and axis labels

lesson_1.py
import matplotlib.pyplot as plt

days = [1, 2, 3, 4, 5, 6, 7]
steps = [4, 6, 5, 8, 7, 9, 10]

plt.plot(days, steps)
plt.title('Daily steps')
plt.xlabel('Day')
plt.ylabel('Steps (thousands)')
plt.show()
LineWhat it means
plt.title('Daily steps')Adds the title above the chart. Say what the chart shows.
plt.xlabel('Day')Names the horizontal axis.
plt.ylabel('Steps (thousands)')Names the vertical axis. Putting the unit in brackets saves guessing.

Two lines, a legend and a grid

lesson_2.py
import matplotlib.pyplot as plt

days = [1, 2, 3, 4, 5, 6, 7]
this_week = [4, 6, 5, 8, 7, 9, 10]
last_week = [3, 4, 6, 5, 6, 7, 8]

plt.plot(days, this_week, label='This week')
plt.plot(days, last_week, label='Last week')
plt.title('Steps compared')
plt.xlabel('Day')
plt.ylabel('Steps (thousands)')
plt.legend()
plt.grid(True)
plt.show()
LineWhat it means
plt.plot(days, this_week, label='This week')Draws the first line and gives it a name for the legend.
plt.plot(days, last_week, label='Last week')A second plot call before show() draws on the same chart. Matplotlib picks a different colour automatically.
plt.legend()Builds the legend from the labels. It does nothing if no line has a label.
plt.grid(True)Adds grid lines that make it easier to read the values.

Position and size

lesson_3.py
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
a = [2, 4, 5, 8]
b = [1, 3, 6, 7]

plt.plot(x, a, label='Team A')
plt.plot(x, b, label='Team B')
plt.title('Points per round', fontsize=16)
plt.legend(loc='upper left')
plt.show()
LineWhat it means
fontsize=16Makes the title text bigger. Most text functions accept fontsize.
plt.legend(loc='upper left')Moves the legend. Other places include 'lower right' and 'center'. The default 'best' lets Matplotlib choose the emptiest corner.

5Common mistakes

  • Calling plt.legend() without giving any line a label. The legend is empty or missing.
  • Leaving out units in the axis labels, so nobody knows if the numbers are minutes or kilometres.
  • Putting plt.show() between the plot calls. After show() the chart is finished and later calls start a new one.
  • Using a vague title such as Graph. Say what the chart tells the reader.

6When should I use it?

Use titles and labels on every chart you share. Use a legend whenever more than one line or colour appears, and a grid when readers need to read off approximate values.

7Interview questions

How do you add a legend to a Matplotlib plot?

Pass label='...' to each plot call and then call plt.legend().

How do you draw two lines on one chart?

Call plt.plot() twice before calling plt.show().

How do you move the legend?

Use the loc argument, for example plt.legend(loc='upper left').

What are plt.xlabel and plt.ylabel for?

They name the x axis and the y axis, ideally with units.
