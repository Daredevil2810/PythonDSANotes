Scatter plots: find relationships

Plot pairs of values as dots to see whether two things move together, and add colour and size to show more.

1What is it?

A scatter plot draws one dot for every pair of values: one value sets the dot's position across, the other sets its height. The shape of the dots shows how the two values relate.

2Why do we need it?

Does more study time mean higher marks? Do expensive items sell less? A scatter plot answers questions like these by eye, and it is often the first chart you draw when exploring data. It is the picture behind the correlation number you may have met in Pandas.

3In plain words

Everyday example

Imagine a teacher sticking a dot on a wall chart for each student: how many hours they studied across the bottom and their mark up the side. If the dots form a rising band, studying and marks go together.

Precise definition

plt.scatter(x, y) draws unconnected dots. Extra arguments change them: s for size, c for colour (a single colour, or a list of numbers mapped through a colormap cmap), and alpha for transparency between 0 and 1. plt.colorbar() adds a key for the colour scale.

  1. Prepare two lists of equal length: x values and y values.
  2. Call plt.scatter(x, y).
  3. Use alpha when dots overlap.
  4. Use s and c to show a third or fourth value.
  5. Add plt.colorbar() if colour carries meaning.

4Code, step by step

Hours studied against marks

lesson_1.py
import matplotlib.pyplot as plt

hours = [1, 2, 2.5, 3, 4, 4.5, 5, 6, 7, 8]
marks = [35, 42, 48, 50, 58, 62, 65, 72, 80, 88]

plt.scatter(hours, marks)
plt.title('Study time and marks')
plt.xlabel('Hours studied')
plt.ylabel('Marks')
plt.show()
LineWhat it means
plt.scatter(hours, marks)One dot per student. Each dot sits at (hours, marks).
plt.title(...) and the two labelsAlways say what the two axes measure, with units where possible.
What the picture showsThe dots climb from bottom left to top right: more hours go with higher marks.

Let colour show a third value

lesson_3.py
import matplotlib.pyplot as plt

hours = [1, 2, 2.5, 3, 4, 4.5, 5, 6, 7, 8]
marks = [35, 42, 48, 50, 58, 62, 65, 72, 80, 88]
sleep = [5, 6, 5, 7, 6, 8, 7, 8, 7, 8]

plt.scatter(hours, marks, c=sleep, cmap='viridis', s=100)
plt.colorbar(label='Hours of sleep')
plt.xlabel('Hours studied')
plt.ylabel('Marks')
plt.show()
LineWhat it means
c=sleepPassing numbers to c colours each dot according to its value.
cmap='viridis'The colormap decides which colours the numbers map to. viridis stays readable for most colour-blind readers.
plt.colorbar(label='Hours of sleep')Adds the scale bar so people can decode the colours.

5Common mistakes

  • Joining scatter points with a line. If the order of the points does not matter, use scatter, not plot.
  • Reading a pattern as proof of cause. Dots that rise together show a relationship, not that one thing causes the other.
  • Forgetting alpha when many dots overlap, so you cannot see where they are dense.
  • Passing x and y of different lengths, which raises a ValueError.

6When should I use it?

Use scatter plots to explore the relationship between two numeric columns, to spot clusters, and to spot outliers: dots far away from all the others.

7Interview questions

What is a scatter plot used for?

To see the relationship between two numeric variables, spot clusters and find outliers.

What does the alpha argument do?

It sets transparency from 0 to 1, so overlapping dots are easier to see.

How do you colour dots by a third variable?

Pass the values to c, choose a cmap, and add plt.colorbar().

Is a rising scatter pattern proof that one variable causes the other?

No. It only shows that they move together.
