Explore, sort and filter data

Get a quick overview of a DataFrame, then sort it and pull out only the rows that match a rule.

1What is it?

Before analysing anything, you look at the data: its size, columns, types and basic statistics. After that you sort rows and filter them, which means keeping only the rows where a condition is true.

2Why do we need it?

Real files are messy and large. A fast overview shows you what you are dealing with, and filtering lets you answer questions like who scored above 80? without writing a loop.

3In plain words

Everyday example

When someone hands you a thick register, you flip to the first and last pages, check how many columns it has, then underline the rows that matter. head(), info() and filtering are those three moves.

Precise definition

head()/tail() show the first or last rows. info() lists columns, non-null counts and dtypes. describe() summarises numeric columns. A condition like df["marks"] >= 80 produces a Boolean Series, and passing it to df[...] keeps only the True rows (Boolean masking).

  1. Peek with head() and tail(), and check shape.
  2. Check types and gaps with info().
  3. Get statistics with describe().
  4. Sort with sort_values().
  5. Filter with a condition inside df[...], joining conditions with & or |.

Sort and filter

lesson_3.py
import pandas as pd

df = pd.DataFrame({
    "name": ["Asha", "Ravi", "Meena", "Kabir", "Isha", "Dev", "Nina", "Omar"],
    "section": ["A", "B", "A", "B", "A", "B", "A", "B"],
    "marks": [78, 90, 66, 84, 91, 55, 73, 84],
})
print(df.sort_values("marks", ascending=False).head(3))
print(df[df["marks"] >= 80])
print(df[(df["section"] == "A") & (df["marks"] > 70)])

5Common mistakes

  • Writing and / or instead of & / | in a filter. Python's keywords don't work on whole columns.
  • Forgetting parentheses: df["a"] > 1 & df["b"] < 5 is evaluated in the wrong order. Write (df["a"] > 1) & (df["b"] < 5).
  • Expecting sort_values() to change the DataFrame. It returns a sorted copy, so assign it back (df = df.sort_values(...)) if you want to keep it.

6When should I use it?

Use these steps at the start of any analysis: peek, check types, summarise, then sort and filter to answer specific questions.

7Interview questions

What does df.info() tell you?

The number of rows, each column's dtype and how many non-null values it has, which is the quickest way to spot missing data.

How do you filter rows by two conditions?

Wrap each condition in parentheses and join them with & (and) or | (or): df[(df["a"] > 1) & (df["b"] < 5)].

What does describe() show?

Count, mean, standard deviation, min, quartiles and max for numeric columns.

How do you sort in descending order?

df.sort_values("col", ascending=False).

8Try it yourself

Using a DataFrame with name = Asha, Ravi, Meena, Dev and marks = 78, 90, 66, 55, print a list of the names of students who scored below 70.

Show hint

import pandas as pd

df = pd.DataFrame({
    "name": ["Asha", "Ravi", "Meena", "Dev"],
    "marks": [78, 90, 66, 55],
})
print(df[df["marks"] < 70]["name"].tolist())
