NumPy arrays: fast lists of numbers

Meet NumPy and its array, and see why array 2 behaves very differently from list 2.

1What is it?

NumPy (short for Numerical Python) is a library for working with numbers in bulk. Its main object is the array (type name ndarray): a grid of values where every value has the same type.

2Why do we need it?

Python lists are flexible, but doing maths on thousands of numbers with a loop is slow and wordy. NumPy does the same work in one line and much faster. It is also the base that Pandas, Matplotlib and most machine-learning libraries are built on, so you will meet it everywhere in data work.

3In plain words

Everyday example

A Python list is like a drawer where you can throw in a pen, a key and a coin. A NumPy array is like an egg tray: every cell holds the same kind of thing, in a fixed order. Because everything is the same, NumPy can handle the whole tray in one move instead of one egg at a time.

Precise definition

An ndarray stores elements of one dtype in a single block of memory, and its maths runs in compiled C code. Operations such as +, * and > are vectorised: they apply to every element at once, with no Python loop. The size of an array is fixed when it is created.

  1. Install NumPy once with pip.
  2. Import it with the usual alias np.
  3. Turn a list into an array with np.array().
  4. Use operators on the whole array: arr * 2, arr + 10.
  5. Check arr.dtype to see which type NumPy chose.

List vs array: same symbol, different job

lesson_3.py
import numpy as np

as_list = [1, 2, 3]
as_array = np.array([1, 2, 3])

print(as_list * 2)
print(as_array * 2)
print(as_array + 10)
print(as_array * as_array)
OUTPUT
[1, 2, 3, 1, 2, 3]
[2 4 6]
[11 12 13]
[1 4 9]
LineWhat it means
as_list * 2For a list, means repeat the list*, so you get six items.
as_array * 2For an array, means multiply every number*.
as_array + 10Adds 10 to each element, with no loop.
as_array * as_arrayTwo arrays of the same size are combined position by position: 11, 22, 3*3.

OUTPUT

LineWhat it means
a = np.array([1, 2, 3])All whole numbers, so the array holds integers.
b = np.array([1, 2.5, 3])One decimal number is enough to turn the entire array into decimals. The 1 becomes 1.0.
c = np.array([1, 2, 'x'])Adding a piece of text turns everything into text, which stops you doing maths on it. The dtype <U21 means text of up to 21 characters.

5Common mistakes

  • Expecting a list's behaviour: arr * 2 multiplies the numbers, it does not repeat the array.
  • Mixing text into a numeric array. NumPy quietly converts every value to text and your maths stops working.
  • Trying to add an item with append like on a list. Arrays have a fixed size; you build a new array instead.
  • Writing import numpy and then using np.array. If you drop as np, the name np does not exist.

6When should I use it?

Use NumPy whenever you have many numbers to process together: marks, sensor readings, prices, pixels of an image, or the input to a data-science model.

7Interview questions

What is NumPy?

A Python library for fast numerical work. Its core object is ndarray, a fixed-size grid of values that all share one dtype.

Why is NumPy faster than a list?

The values sit together in one block of memory and the maths runs in compiled C code over the whole array, so there is no slow Python loop.

What does arr 2 do compared with my_list 2?

On an array it doubles every number. On a list it repeats the list twice.

What happens if you mix integers and decimals in one array?

NumPy upcasts everything to one common type, so the integers become floats.
