Read and save CSV and JSON files

Load data from files into a DataFrame, pick only the columns you need and save your results back to disk.

1What is it?

Pandas can load a file into a DataFrame with a single function call: read_csv() for comma-separated text files and read_json() for JSON. to_csv() goes the other way and saves a DataFrame to a file.

2Why do we need it?

Your data almost always lives in a file or an export, not in your code. Loading and saving is the first and last step of nearly every data task.

3In plain words

Everyday example

A CSV file is a notebook where each line is one row and commas separate the columns. read_csv() is a helper that reads the whole notebook and hands you a neat table.

Precise definition

read_csv(path) parses delimited text into a DataFrame, inferring dtypes from the values. read_json(path) expects JSON that looks like a list of records or a dictionary of columns. to_csv(path, index=False) writes the table out without the row labels.

  1. Have the file in the folder you run your script from (or give the full path).
  2. Call pd.read_csv("file.csv") or pd.read_json("file.json").
  3. Check the result with print(df) or df.head().
  4. Clean or add columns as needed.
  5. Save with df.to_csv("out.csv", index=False).

4Code, step by step

Create a small CSV to practise with

lesson_1.py
csv_text = """item,price,qty
pen,10,5
notebook,45,3
bag,450,1
marker,30,4
"""

with open("shop.csv", "w") as f:
    f.write(csv_text)

print("shop.csv created")
OUTPUT
shop.csv created
LineWhat it means
csv_text = """..."""A multi-line string. The first line holds the column names; every other line is one row.
with open("shop.csv", "w") as f:Opens (and creates) the file for writing, then closes it automatically.
f.write(csv_text)Saves the text into the file. The next blocks read this file.

Choose columns and an index

lesson_3.py
import pandas as pd

small = pd.read_csv("shop.csv", usecols=["item", "price"])
print(small)

by_item = pd.read_csv("shop.csv", index_col="item")
print(by_item.loc["bag"])
OUTPUT
       item  price
0       pen     10
1  notebook     45
2       bag    450
3    marker     30
price    450
qty        1

LineWhat it means
usecols=["item", "price"]Loads only the listed columns, which is quicker and tidier for wide files.
index_col="item"Uses that column as the row labels instead of 0, 1, 2.
by_item.loc["bag"]Because item is the index, we can find a row by its item name.

Read a JSON file

lesson_4.py
import pandas as pd

json_text = '[{"item": "pen", "price": 10}, {"item": "bag", "price": 450}]'
with open("shop.json", "w") as f:
    f.write(json_text)

df = pd.read_json("shop.json")
print(df)
OUTPUT
  item  price
0  pen     10
1  bag    450
LineWhat it means
json_text = '[{...}, {...}]'JSON as a list of objects. Each object becomes one row, and its keys become the column names.
pd.read_json("shop.json")Loads that file into a DataFrame. Because JSON objects look like Python dictionaries, this feels like pd.DataFrame(list_of_dicts).

Save a result with to_csv

lesson_5.py
import pandas as pd

df = pd.read_csv("shop.csv")
df["total"] = df["price"] * df["qty"]
df.to_csv("shop_totals.csv", index=False)

print(open("shop_totals.csv").read())
OUTPUT
item,price,qty,total
pen,10,5,50
notebook,45,3,135
bag,450,1,450
marker,30,4,120
LineWhat it means
df["total"] = df["price"] * df["qty"]Calculates a new column for every row.
df.to_csv("shop_totals.csv", index=False)Writes the table to a new file. index=False leaves out the 0, 1, 2 row labels.
print(open(...).read())Reads the saved file back as plain text so you can see exactly what was written.

5Common mistakes

  • Getting FileNotFoundError. Python looks in the folder you run the script from, not the folder where you saved it. Check the path.
  • Forgetting index=False in to_csv(). The saved file then gets an extra unnamed column of row numbers.
  • Assuming a printed big DataFrame shows everything. Pandas hides the middle rows with ...; use df.to_string() to print them all.

6When should I use it?

Use read_csv() for spreadsheets exported as CSV and read_json() for data from web APIs. Use to_csv() to share cleaned data or feed it into another tool.

7Interview questions

What does read_csv() return?

A DataFrame built from the file. The first row is used as the column names by default.

How do you read only some columns?

Pass usecols=["col1", "col2"] to read_csv().

Why use index=False when saving?

Otherwise Pandas writes the row labels as an extra first column, and reading the file back creates an unwanted Unnamed: 0 column.

What if the file uses semicolons instead of commas?

Tell Pandas with sep=";", for example pd.read_csv("file.csv", sep=";").

8Try it yourself

Write a CSV with the text name,marks, then Asha,78, Ravi,90, Meena,66 (one per line) into a file called marks.csv. Read it with Pandas and print the average of the marks column.

import pandas as pd

with open("marks.csv", "w") as f:
