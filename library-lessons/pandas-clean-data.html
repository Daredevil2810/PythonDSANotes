Fix wrong formats, wrong values and duplicates

Convert messy dates, spot and repair impossible values, and remove duplicate rows.

1What is it?

Besides empty cells, bad data comes in three more forms: values in the wrong format (like dates written three different ways), wrong values (like a typo that makes a price 4500 instead of 450) and duplicate rows (the same record entered twice).

2Why do we need it?

Mixed formats stop you from sorting or calculating with dates. A single impossible value can wreck an average. Duplicates make totals too big. Fixing these makes every later result trustworthy.

3In plain words

Everyday example

Think of tidying a shop's order book: rewrite every date the same way, correct the price someone wrote with an extra zero, and cross out the order that was written down twice.

Precise definition

pd.to_datetime(col, format="mixed", errors="coerce") parses dates written in different styles and turns unreadable ones into NaT. You fix values with a rule such as df.loc[condition, col] = new_value or by filtering rows out. duplicated() marks repeats and drop_duplicates() removes them.

  1. Convert date columns with to_datetime().
  2. Drop or fill any NaT that conversion creates.
  3. Decide what values are possible, then correct or remove the ones outside that range.
  4. Check for repeats with duplicated().
  5. Remove repeats with drop_duplicates().

4Code, step by step

Wrong format: dates

lesson_1.py
import pandas as pd

df = pd.DataFrame({
    "day": ["2025-01-05", "2025/01/06", "07 Jan 2025", "not a date"],
    "sales": [120, 90, 150, 60],
})
df["day"] = pd.to_datetime(df["day"], format="mixed", errors="coerce")
print(df)

df = df.dropna(subset=["day"])
print(df)

Wrong values: fix or remove

lesson_2.py
import pandas as pd

# 4500 is a typo for 450
df = pd.DataFrame({"item": ["pen", "book", "bag", "ruler"], "price": [10, 120, 4500, 15]})

fixed = df.copy()
fixed.loc[fixed["price"] > 1000, "price"] = 450
print(fixed)

removed = df[df["price"] <= 1000]
print(removed)
OUTPUT

Duplicates

lesson_3.py
import pandas as pd

df = pd.DataFrame({
    "order": [101, 102, 102, 103, 103],
    "item": ["pen", "book", "book", "bag", "bag"],
    "qty": [2, 1, 1, 1, 3],
})
print(df.duplicated())
print(df.drop_duplicates())
print(df.drop_duplicates(subset="order").reset_index(drop=True))
OUTPUT
0    False
1    False
2     True
3    False
4    False
dtype: bool

0    101   pen    2
1    102  book    1

LineWhat it means
df.duplicated()True for a row that exactly repeats an earlier row. The first copy is False.
df.drop_duplicates()Removes rows that are identical in every column. Order 103 stays twice because its quantities differ (1 and 3).
subset="order"Compares only the order column, so each order number is kept once.
reset_index(drop=True)Renumbers the rows 0, 1, 2 after rows were removed, and drops the old numbers.

5Common mistakes

  • Treating a large value as wrong just because it looks big. First ask whether it is genuinely possible.
  • Forgetting errors="coerce", so one bad date makes the whole conversion crash.
  • Removing duplicates across every column when the real key is just one column (like an order number), or the opposite.

6When should I use it?

Run these checks right after loading a new dataset and before any analysis. Fix values you are sure about; remove rows when you can't be sure.

7Interview questions

How do you find duplicate rows?

df.duplicated() returns True for each repeat. df.duplicated().sum() counts them.

What is NaT?

"Not a Time": the missing-value marker for dates, like NaN for numbers.

How do you handle wrong values in a big dataset?

Define a rule for valid values (a range, for example) and either replace or remove everything outside it, rather than editing rows one by one.

What does the subset argument do in drop_duplicates()?

It limits the comparison to the listed columns, so rows count as duplicates when those columns match.
