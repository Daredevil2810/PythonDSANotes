Random numbers and simulations

Generate random numbers the modern way, make them repeatable with a seed, and run a small dice simulation.

1What is it?

NumPy can generate random numbers in bulk. You create a random generator with np.random.default_rng(), then ask it for integers, decimals, or random picks from a list.

2Why do we need it?

Random numbers are used to test ideas without real data, to shuffle data, to split data into training and test sets, and to simulate things like dice or coin tosses to see what usually happens.

3In plain words

Everyday example

Think of a dice-rolling machine. You tell it how many dice to roll and it hands you all the results at once. A seed is like setting the machine to the same starting position every time, so it rolls the same sequence and your experiment can be repeated.

Precise definition

rng = np.random.default_rng(seed) creates a generator. rng.integers(low, high, size) gives integers from low up to but not including high. rng.random(size) gives decimals from 0 up to 1. rng.choice(items, size) picks from a list. The same seed gives the same numbers, but the exact values can differ between NumPy versions, so rely on shapes and ranges, not specific numbers.

  1. Create a generator: rng = np.random.default_rng(42).
  2. Ask for numbers with rng.integers, rng.random or rng.choice.
  3. Pass size to get many values at once.
  4. Use the same seed whenever you need a repeatable result.
  5. Check the shape, min and max of the result to confirm it looks right.

4Code, step by step

A generator with a seed

lesson_1.py
import numpy as np

rng = np.random.default_rng(42)
print(rng.integers(1, 7, size=5))
print(rng.random(3))

rng2 = np.random.default_rng(42)
print(rng2.integers(1, 7, size=5))

Random picks and shuffling

lesson_2.py
import numpy as np

rng = np.random.default_rng(7)
names = np.array(['Asha', 'Ravi', 'Meena', 'Kabir', 'Isha'])

print(len(rng.choice(names, size=2, replace=False)))
shuffled = rng.permutation(names)
print(len(shuffled), sorted(shuffled) == sorted(names))
OUTPUT
2
5 True
LineWhat it means
rng.choice(names, size=2, replace=False)Picks 2 different names. replace=False means a name cannot be picked twice.
rng.permutation(names)Returns a shuffled copy and leaves the original alone.
sorted(shuffled) == sorted(names)Shuffling only reorders: the same names are still there, so this prints True.

Simulate 1,000 dice rolls

lesson_3.py
import numpy as np

rng = np.random.default_rng(1)
rolls = rng.integers(1, 7, size=1000)

print(rolls.shape)
print(rolls.min(), rolls.max())
print(3.3 < rolls.mean() < 3.7)
print(np.bincount(rolls)[1:].sum())
OUTPUT

5Common mistakes

  • Writing rng.integers(1, 6) and expecting a 6 to appear. The upper limit is excluded; use 7 for a six-sided die.
  • Expecting a different answer on each run while using a fixed seed. A seed makes results repeat on purpose.
  • Leaving out the seed in tests or tutorials, so nobody can reproduce your numbers.
  • Printing results and comparing exact numbers across machines. Check shapes, ranges and averages instead.

6When should I use it?

Use random numbers to create practice data, shuffle or sample a list, split data into train and test parts, and simulate games or experiments.

7Interview questions

What is a random seed?

A starting value for the generator. The same seed always produces the same sequence, which makes experiments repeatable.

What range does rng.integers(1, 7) return?

Whole numbers from 1 to 6. The upper limit is exclusive.

How do you pick items without repeats?

rng.choice(items, size=n, replace=False).

Why is default_rng preferred over np.random.seed?

default_rng gives each generator its own state, which is cleaner, safer and the approach NumPy recommends for new code.

8Try it yourself

Using np.random.default_rng(5), simulate 100 coin tosses where 0 is tails and 1 is heads. Print the shape of the result and whether every value is either 0 or 1.
