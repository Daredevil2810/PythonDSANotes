Pandas Series: labelled 1-D data

Meet Pandas and its simplest building block, the Series: one column of data with a label on every value.

1What is it?

Pandas is a Python library for working with tables of data: loading them, cleaning them and answering questions about them. Its simplest object is the Series: one column of values where every value also carries a label (called the index).

2Why do we need it?

Real data rarely arrives as a tidy Python list. It arrives as marks registers, sales sheets and sensor logs. Pandas lets you ask what is the average? or which entry is the highest? in one line, with no loop. A Series is the piece every bigger Pandas object is built from, so understanding it makes everything else easier.

3In plain words

Everyday example

Think of one column in your class marks register. Each mark sits next to a student's name. The marks are the values, the names are the labels, and the whole column is a Series.

Precise definition

A Series is a one-dimensional array (backed by NumPy) with an index and a single dtype. Operations such as +, > and .mean() work on the whole Series at once (this is called vectorised) and line up values by their index labels.

  1. Install Pandas once with pip.
  2. Import it with the usual alias pd.
  3. Build a Series from a list or a dictionary.
  4. Read values by label (s["Ravi"]) or by position (s.iloc[0]).
  5. Use methods like mean() and comparisons to analyse the whole Series.

Create a Series from a list

lesson_2.py
import pandas as pd

marks = pd.Series([78, 90, 66])
print(marks)
print(marks.dtype)
OUTPUT
0    78
1    90
2    66
dtype: int64
int64
LineWhat it means
marks = pd.Series([78, 90, 66])Builds a Series from a list. With no labels given, Pandas numbers the values 0, 1, 2.
print(marks)Shows the labels on the left, the values on the right and the dtype at the bottom.
print(marks.dtype)Shows the data type of the values. All values in a Series share one dtype.

Give it your own labels

lesson_3.py
import pandas as pd

marks = pd.Series([78, 90, 66], index=["Asha", "Ravi", "Meena"])
print(marks)
print("Ravi:", marks["Ravi"])
print("First by position:", marks.iloc[0])
print("Average:", marks.mean())
OUTPUT
Asha     78
Ravi     90
Meena    66
dtype: int64
Ravi: 90
First by position: 78
Average: 78.0
LineWhat it means
index=["Asha", "Ravi", "Meena"]Replaces the default 0, 1, 2 with names. You need one label per value.
marks["Ravi"]Reads a value by its label.
marks.iloc[0]Reads a value by its position. iloc always counts from 0, whatever the labels are.
marks.mean()Averages the whole Series in one call, with no loop.

Build one from a dictionary and filter it

lesson_4.py
import pandas as pd

steps = {"Mon": 4200, "Tue": 8100, "Wed": 6500, "Thu": 9300}
s = pd.Series(steps)
print(s[s > 6000])
print(pd.Series(steps, index=["Mon", "Thu"]))
OUTPUT
Tue    8100
Wed    6500
Thu    9300
dtype: int64
Mon    4200
Thu    9300
dtype: int64
LineWhat it means
s = pd.Series(steps)Dictionary keys become the labels and the dictionary values become the data.
s[s > 6000]s > 6000 gives a True/False value for every item. Using that inside [] keeps only the True ones.
pd.Series(steps, index=["Mon", "Thu"])Passing index picks only those keys from the dictionary.

5Common mistakes

  • Writing pd.series(...) with a small s. The class is pd.Series.
  • Treating the index as positions. marks[0] asks for a label called 0 (newer Pandas raises a KeyError). Use marks.iloc[0] for the first item.
  • Assuming labels are unique. They don't have to be, which can give surprising results when you select by label.

6When should I use it?

Use a Series when you have one list of related values that deserve labels, or when you pull a single column out of a bigger table.

7Interview questions

What is a Pandas Series?

A one-dimensional labelled array: a sequence of values of one dtype plus an index of labels.

How is a Series different from a Python list?

A Series has labels, holds a single dtype and supports whole-column operations like s * 2 or s.mean() without a loop. A list can mix types and needs a loop for the same work.

How do you select by label and by position?

By label: s["Ravi"] or s.loc["Ravi"]. By position: s.iloc[0].

What happens when you create a Series from a dictionary?

The keys become the index labels and the values become the data.
