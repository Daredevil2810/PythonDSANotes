Histograms: see how values are spread

Group numbers into ranges called bins and draw how many fall in each, to see the shape of your data.

1What is it?

A histogram counts how many values fall into each range (called a bin) and draws one bar per range. It shows how your data is spread out: where most values sit, and whether there are unusual ones.

2Why do we need it?

Averages hide the shape of data. A class average of 60 could mean everyone scored near 60, or half scored 30 and half scored 90. A histogram shows which one it is.

3In plain words

Everyday example

Imagine sorting exam papers into piles: 0 to 40, 40 to 60, 60 to 80 and 80 to 100. You then look at how tall each pile is. A histogram is a picture of those piles.

Precise definition

plt.hist(data, bins=...) splits the range of the data into bins and draws a bar for the count in each. bins can be a number (how many equal-width bins) or a list of edges. Unlike a bar chart, the x axis is a continuous number line and the bars touch. np.histogram returns the same counts as numbers.

  1. Collect your numbers in one list.
  2. Call plt.hist(data).
  3. Choose bins as a number or as a list of edges.
  4. Add edgecolor so neighbouring bars are separated.
  5. Compare counts with np.histogram if you need exact numbers.

4Code, step by step

A basic histogram

lesson_1.py
import matplotlib.pyplot as plt

marks = [35, 42, 48, 50, 52, 55, 56, 58, 60, 61,
         62, 63, 64, 65, 66, 67, 68, 70, 71, 72,
         74, 75, 78, 80, 82, 85, 88, 90, 93, 97]

plt.hist(marks, bins=5, edgecolor='white')
plt.title('Exam marks')
plt.xlabel('Marks')
plt.ylabel('Number of students')
plt.show()

Choose the bins yourself

Get the counts as numbers

lesson_3.py
import numpy as np

marks = [35, 42, 48, 50, 52, 55, 56, 58, 60, 61,
         62, 63, 64, 65, 66, 67, 68, 70, 71, 72,
         74, 75, 78, 80, 82, 85, 88, 90, 93, 97]

counts, edges = np.histogram(marks, bins=[0, 40, 60, 80, 100])
print(counts)
print(edges)
print(counts.sum() == len(marks))
OUTPUT
[ 1  7 15  7]
[  0  40  60  80 100]
True
LineWhat it means
np.histogram(marks, bins=[...])Does the same counting as plt.hist but returns numbers instead of drawing.
countsHow many marks fall in each bin.
edgesThe bin edges you passed in.
counts.sum() == len(marks)Every mark lands in exactly one bin, so the counts add back up to 30.

5Common mistakes

  • Using a bar chart when you have raw numbers. A histogram does the counting for you.
  • Choosing too few or too many bins. Too few hides the shape; too many makes a jagged mess. Try a few values.
  • Forgetting that a value on a bin edge goes into the upper bin, except for the very last bin which includes its right edge.
  • Not labelling the y axis. Readers must know whether bars show counts or percentages.

6When should I use it?

Use a histogram to see the distribution of one numeric column: marks, ages, delivery times, prices. It is a standard first step in data cleaning, because outliers show up as lonely bars.

7Interview questions

What is the difference between a bar chart and a histogram?

A bar chart compares separate categories. A histogram groups continuous numbers into ranges and counts how many fall in each.

What are bins?

The ranges the data is divided into. Each bar of a histogram represents one bin.

How do you set custom bin edges?

Pass a list to bins, for example bins=[0, 40, 60, 80, 100].

How do you get the bin counts without drawing?

Use np.histogram(data, bins=...), which returns the counts and the edges.
