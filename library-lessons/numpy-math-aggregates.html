Array maths and summaries: sum, mean, max, axis

Do maths on a whole array at once, then summarise it by overall, by column and by row.

1What is it?

NumPy lets you do arithmetic on entire arrays (vectorised maths) and summarise them with functions like sum(), mean(), max() and std(). A summary can cover the whole array or run along one axis.

2Why do we need it?

Questions like what is the class average? or which test was hardest? are everyday data work. NumPy answers them without a single loop, and the axis idea carries straight over to Pandas.

3In plain words

Everyday example

You have a marks sheet: one row per student, one column per test. The average of a column tells you how hard that test was. The average of a row tells you how one student did overall. The axis just says down the columns or across the rows.

Precise definition

Operators work element by element. Aggregation methods collapse an array: with no axis they return one number; axis=0 collapses the rows (one result per column); axis=1 collapses the columns (one result per row). argmax and argmin return the position of the largest and smallest values.

  1. Use operators and functions like +, **2 and np.sqrt on whole arrays.
  2. Call sum, mean, min, max, std for a quick summary.
  3. Add axis=0 for results per column.
  4. Add axis=1 for results per row.
  5. Use argmax to find where the biggest value sits.

4Code, step by step

Maths on whole arrays

lesson_1.py
import numpy as np

prices = np.array([100, 250, 80])
qty = np.array([2, 1, 5])

print(prices * qty)
print(prices * 1.18)
print(prices ** 2)
print(np.sqrt(np.array([4, 9, 16])))

Summaries of one array

lesson_2.py
import numpy as np

marks = np.array([72, 85, 90, 64, 78])

print(marks.sum())
print(marks.mean())
print(marks.max(), marks.min())
print(round(marks.std(), 2))
print(np.median(marks))
print(marks.argmax())

Rows, columns and axis

lesson_3.py
import numpy as np

# rows = students, columns = tests
scores = np.array([[70, 80, 90],
                   [60, 75, 65],
                   [88, 92, 79]])

print(scores.mean())
print(scores.mean(axis=0))
print(scores.mean(axis=1))
print(scores.max(axis=0))
print(scores.cumsum(axis=1))
OUTPUT

scores.mean(axis=0)axis=0 runs down the rows, giving one average per column (per test).
scores.mean(axis=1)axis=1 runs across the columns, giving one average per row (per student).
scores.max(axis=0)The best score in each test.
scores.cumsum(axis=1)Running total along each row, so you see each student's marks adding up.

5Common mistakes

  • Mixing up the axes. Remember: axis=0 gives one answer per column, axis=1 gives one answer per row.
  • Reading argmax() as the biggest value. It returns the index of the biggest value.
  • Using Python's built-in sum() on a 2-D array. It adds the rows together and returns an array of column totals, not one number. Use arr.sum() or np.sum(arr) instead.
  • Combining arrays of different lengths, for example 3 prices with 4 quantities, which raises a ValueError.

6When should I use it?

Use array maths and aggregates for totals, averages, spread and best/worst values on any numeric data, and axis whenever your data is a table.

7Interview questions

What does axis=0 mean in arr.sum(axis=0)?

The sum runs down the rows, so you get one result for each column.

What is the difference between max() and argmax()?

max() returns the largest value. argmax() returns the position of that value.

What does vectorised mean?

An operation is applied to every element of the array at once, without writing a Python loop.

How do you get the average of each row in a 2-D array?

arr.mean(axis=1).
