Markers, colours and line styles

Change how a line looks: add markers, pick colours, switch to dashed lines and set the thickness.

1What is it?

You can control the look of every line: the marker drawn at each point, the colour, the line style (solid, dashed, dotted) and the thickness.

2Why do we need it?

Styling is not decoration. When two lines are printed in black and white, or seen by colour-blind readers, different markers and dashes keep them apart. A few well-chosen styles also make important data stand out.

3In plain words

Everyday example

Think of highlighting pens. You can choose a pen colour, a thick or thin tip and even draw dashes. Matplotlib has the same choices, only you name them in code.

Precise definition

Style options can be given as keyword arguments (marker, color, linestyle, linewidth, markersize) or packed into a format string such as 'o--r' (circle markers, dashed line, red) as the third argument of plot. Colours can be names ('green'), short codes ('g') or hex codes ('#ff7f0e').

4Code, step by step

Markers and line style with keywords

lesson_1.py
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [3, 5, 4, 8, 7]

plt.plot(x, y, marker='s', linestyle='--', color='green')
plt.show()
LineWhat it means
marker='s'Draws a square at each data point.
linestyle='--'Makes the connecting line dashed.
color='green'Sets the colour by name.

Thickness, size and hex colours

lesson_2.py
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [3, 5, 4, 8, 7]

plt.plot(x, y, marker='o', markersize=10,
         linewidth=4, color='#ff7f0e')
plt.show()
LineWhat it means
markersize=10Makes each marker larger.
linewidth=4Makes the line thicker.
color='#ff7f0e'A hex colour code. Any hex colour from a design tool works here.

Shortcut format strings

lesson_3.py
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]

plt.plot(x, [1, 2, 3, 4], 'o--r', label='Red dashed')
plt.plot(x, [2, 3, 4, 5], 's:g', label='Green dotted')
plt.plot(x, [3, 4, 5, 6], '^-b', label='Blue solid')
plt.legend()
plt.show()
LineWhat it means
'o--r'Reads as marker o, line style --, colour r. The order is marker, line, colour.
's:g'Square markers, dotted line, green.
'^-b'Triangle markers, solid line, blue.
plt.legend()The label on each line is used to build the legend.

5Common mistakes

  • Putting a colour code in the wrong place in a format string, for example 'ro--' works but 'o--rx' does not make sense.
  • Using plt.plot(x, y, 'o', linestyle='-') and being surprised by the clash. Keyword arguments override the format string.
  • Choosing colours that look alike. Combine colour with marker or line style so lines stay distinct in print.
  • Misspelling a name such as colour='red'. Matplotlib uses the American spelling color.

6When should I use it?

Use markers when there are only a few points and each one matters. Use different line styles when charts will be printed in black and white. Keep decoration modest so the data stays the star.

7Interview questions

What does the format string 'o--r' mean?

Circle markers, a dashed line and red colour.

How do you make a line thicker?

Use the linewidth argument, for example linewidth=3.

How can you give a colour in Matplotlib?

By name ('green'), by a one-letter code ('g') or by a hex code ('#2ca02c').

Why use different line styles as well as different colours?

So the lines can still be told apart in black-and-white print or by readers who cannot distinguish the colours.
