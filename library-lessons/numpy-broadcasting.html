Broadcasting: maths between different shapes

See how NumPy combines arrays of different shapes, such as a table plus a single row, without copying data.

1What is it?

Broadcasting is NumPy's rule for doing maths between arrays of different shapes. A smaller array is stretched, in effect, to match the bigger one.

2Why do we need it?

You constantly need things like add 5 bonus marks to every student or subtract each column's average. Broadcasting lets you write that directly instead of building big repeated arrays or looping. It is also behind many mysterious shape errors, so it is worth understanding.

3In plain words

Everyday example

You have a table of marks and one extra row of bonus marks, one bonus per subject. Broadcasting is like photocopying that single bonus row down the page so each student's row gets the same bonus added, but without really making the copies.

Precise definition

NumPy compares the two shapes from the last dimension backwards. Two dimensions are compatible when they are equal or one of them is 1. A dimension of size 1 is stretched to match the other. If any pair is incompatible, NumPy raises a ValueError.

  1. Write out both shapes, lined up from the right.
  2. For each pair, check: are they equal, or is one of them 1?
  3. If every pair passes, the smaller array is stretched to fit.
  4. If one pair fails, you get a shape error.
  5. Fix it with reshape, or by adding a dimension with [:, np.newaxis].

4Code, step by step

A single number against an array

lesson_1.py
import numpy as np

marks = np.array([[60, 70],
                  [80, 90]])
print(marks + 5)
print(marks * 2)
OUTPUT
[[65 75]
 [85 95]]
[[120 140]
 [160 180]]
LineWhat it means
marks + 5A single number has no dimensions, so it is stretched to every cell.
marks * 2The same idea works for any operator.

A table plus one row

lesson_2.py
import numpy as np

marks = np.array([[60, 70, 80],
                  [50, 65, 75]])   # shape (2, 3)
bonus = np.array([5, 0, 10])      # shape (3,)

print(marks.shape, bonus.shape)
print(marks + bonus)
OUTPUT
(2, 3) (3,)
[[65 70 90]
 [55 65 85]]
LineWhat it means
marks ... shape (2, 3)Two students, three subjects.
bonus ... shape (3,)One bonus per subject.
marks + bonusLining the shapes up from the right: 3 and 3 match, and the missing first dimension of bonus is stretched across both rows. Every student gets the same per-subject bonus.

A column against a row

lesson_3.py
import numpy as np

rows = np.array([[1], [2], [3]])    # shape (3, 1)
cols = np.array([10, 20, 30, 40])   # shape (4,)

print(rows + cols)
print((rows + cols).shape)
OUTPUT
[[11 21 31 41]
 [12 22 32 42]
 [13 23 33 43]]
(3, 4)
LineWhat it means
rows ... shape (3, 1)A column with three rows.
cols ... shape (4,)A single row of four values.
rows + colsThe 1 in the first shape stretches to 4 and the missing dimension in the second stretches to 3. The result is a 3 by 4 table of every row value added to every column value.

When broadcasting fails

lesson_4.py
import numpy as np

a = np.ones((2, 3))
b = np.ones((2,))

try:
    print(a + b)
except ValueError as e:
    print("Error:", e)

print(a + b[:, np.newaxis])
OUTPUT
Error: operands could not be broadcast together with shapes (2,3) (2,) 
[[2. 2. 2.]
 [2. 2. 2.]]
LineWhat it means
a + bShapes (2, 3) and (2,): comparing from the right, 3 and 2 are neither equal nor 1, so NumPy refuses.
except ValueError as eCatches the error so we can print its message.
b[:, np.newaxis]Turns b into a column of shape (2, 1). Now the pairs are 3 vs 1 and 2 vs 2, which is allowed, and the sum works.

5Common mistakes

  • Not checking .shape when you get a broadcasting error. Print both shapes first.
  • Assuming (3,) is a column. It is a flat row; a column is (3, 1).
  • Relying on broadcasting silently when you meant two arrays to be the same shape; you can get a result with the wrong meaning and no error.
  • Trying to broadcast shapes like (2, 3) and (2,). Add a dimension with np.newaxis or reshape(2, 1).

6When should I use it?

Use broadcasting to apply one value or one row/column of values to a whole table, for example scaling, adding bonuses, or subtracting each column's average.

7Interview questions

What is broadcasting in NumPy?

The rule that lets NumPy do arithmetic on arrays of different shapes by stretching the smaller one to match the larger, without actually copying the data.

When are two shapes compatible for broadcasting?

Compared from the last dimension backwards, each pair of sizes must be equal or one of them must be 1.

What does np.newaxis do?

It adds a new dimension of size 1, for example turning a shape (3,) into (3, 1).

Why does adding shapes (2, 3) and (2,) fail?

Comparing from the right, 3 and 2 are different and neither is 1.
