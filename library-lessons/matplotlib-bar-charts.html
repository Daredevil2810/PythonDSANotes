Bar charts: compare categories

Draw vertical and horizontal bar charts, colour the bars and print the value on top of each one.

1What is it?

A bar chart shows one bar per category, and the bar's length shows the value. It is the standard way to compare things such as sales per city or marks per subject.

2Why do we need it?

A line chart suggests that points are connected in order, which makes no sense for cities or subjects. Bars treat each category as a separate item and make the biggest and smallest obvious at a glance.

3In plain words

Everyday example

Think of a row of glass tubes filled with water. Each tube is one category, and the water level is its value. You can compare them without reading a single number.

Precise definition

plt.bar(categories, values) draws vertical bars and plt.barh(categories, values) draws horizontal ones. The color argument accepts one colour or a list with one colour per bar. plt.bar_label(bars) prints each bar's value on the chart.

  1. Prepare a list of category names and a list of values.
  2. Call plt.bar(names, values).
  3. Use color=[...] for a colour per bar.
  4. Use plt.barh when names are long.
  5. Add plt.bar_label(bars) to show the numbers.

4Code, step by step

A basic bar chart

lesson_1.py
import matplotlib.pyplot as plt

cities = ['Pune', 'Delhi', 'Mumbai']
sales = [1350, 850, 300]

plt.bar(cities, sales)
plt.title('Sales by city')
plt.ylabel('Sales')
plt.show()
LineWhat it means
plt.bar(cities, sales)One bar per city. The first list gives the labels and the second gives the heights.
plt.title('Sales by city')A title that says what is compared.
plt.ylabel('Sales')Labels the vertical axis. The categories along the bottom speak for themselves.

Horizontal bars with your own colours

lesson_2.py
import matplotlib.pyplot as plt

subjects = ['Maths', 'Science', 'English', 'History']
marks = [88, 76, 69, 54]
colours = ['#2563eb', '#0d9488', '#f59e0b', '#ef4444']

plt.barh(subjects, marks, color=colours)
plt.xlabel('Marks')
plt.show()
LineWhat it means
plt.barh(subjects, marks, color=colours)barh draws horizontal bars. Handy when category names are long and would collide along the bottom.
color=coloursA list with one colour for each bar, in the same order.
plt.xlabel('Marks')On a horizontal chart the values run along x, so the label goes on the x axis.

Show the value on each bar

lesson_3.py
import matplotlib.pyplot as plt

cities = ['Pune', 'Delhi', 'Mumbai']
sales = [1350, 850, 300]

bars = plt.bar(cities, sales, color='#0d9488', width=0.5)
plt.bar_label(bars)
plt.ylim(0, 1600)
plt.show()
LineWhat it means
bars = plt.bar(...)bar returns the bars it drew. We keep them so we can label them.
width=0.5Makes each bar narrower. The default width is 0.8.
plt.bar_label(bars)Prints the value above every bar.
plt.ylim(0, 1600)Sets the y range so the biggest label has room above its bar.

5Common mistakes

  • Using a line chart for categories. Lines imply a connection between neighbours.
  • Starting the y axis above zero. Bars are compared by length, so cutting the axis exaggerates differences.
  • Mixing up bar and barh. On a horizontal chart the value axis is x, not y.
  • Giving color a list of the wrong length. It needs one colour for each bar.

6When should I use it?

Use bar charts to compare separate categories: sales by city, marks by subject, votes by option. Sort the bars from largest to smallest when the order is not important.

7Interview questions

When do you use a bar chart instead of a line chart?

When the x values are separate categories, not an ordered sequence such as time.

How do you draw horizontal bars?

Use plt.barh(names, values).

How do you show each bar's value on the chart?

Keep the result of plt.bar and pass it to plt.bar_label.

Why should bar charts start at zero?

Bars encode value by length, so a cut axis makes small differences look huge.

8Try it yourself

Draw a bar chart of fruit sold: apples 40, bananas 25, mangoes 60. Give it the title Fruit sold and show the value on each bar.

Show hint
Hint: Keep the result of plt.bar(...) in a variable and pass it to plt.bar_label.
Show solution
solution.py
import matplotlib.pyplot as plt

fruit = ['Apples', 'Bananas', 'Mangoes']
sold = [40, 25, 60]
bars = plt.bar(fruit, sold)
plt.bar_label(bars)
plt.title('Fruit sold')
plt.show()
