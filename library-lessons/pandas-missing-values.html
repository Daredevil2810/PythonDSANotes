Handle missing values

Find empty cells, then either drop those rows or fill the gaps with a sensible value.

1What is it?

A missing value is a cell with no data. Pandas shows it as NaN ("not a number"), or NaT for dates. Cleaning means finding these gaps and deciding what to do with them.

2Why do we need it?

Empty cells quietly give wrong answers. An average calculated over half-empty data may not describe reality, and some operations fail outright. Handling missing data is one of the most common data-cleaning jobs.

3In plain words

Everyday example

Imagine a marks register where two students were absent and nothing was written. You can cross those rows out (drop), write 0 (fill with a value), or write the class average (fill with the mean). Each choice tells a different story, so you pick on purpose.

Precise definition

isna() returns True for missing cells. dropna() returns a copy without rows that have gaps (use subset= to look only at some columns). fillna(value) returns a copy with the gaps replaced. A column with a missing number is stored as float, because NaN is a float.

  1. Count the gaps with df.isna().sum().
  2. Decide: remove the rows or fill them.
  3. To remove: dropna() (optionally with subset).
  4. To fill: fillna() with a value, mean, median or mode.
  5. Assign the result back, because both methods return a new DataFrame.

Fill gaps with a value

lesson_3.py
import pandas as pd

df = pd.DataFrame({
    "name": ["Asha", "Ravi", "Meena", "Kabir", "Isha"],
    "marks": [78, None, 66, None, 91],
    "city": ["Pune", "Delhi", None, "Pune", "Pune"],
})
filled = df.fillna({"marks": 0, "city": "Unknown"})
print(filled)
OUTPUT

Fill with mean, median or mode

lesson_4.py
import pandas as pd

df = pd.DataFrame({
    "marks": [78, None, 66, None, 91],
    "city": ["Pune", "Delhi", None, "Pune", "Pune"],
})
mean = df["marks"].mean()
median = df["marks"].median()
common_city = df["city"].mode()[0]
print("mean:", mean, "median:", median, "mode:", common_city)

df["marks"] = df["marks"].fillna(mean)
df["city"] = df["city"].fillna(common_city)
print(df)
OUTPUT

df["city"].mode()[0]mode() returns the most common value(s) as a Series, so [0] takes the first one.
df["marks"] = df["marks"].fillna(mean)Fills the gaps and assigns the result back into the column. This is the safe pattern for one column.

5Common mistakes

  • Using inplace=True on a single column, as in df["marks"].fillna(0, inplace=True). In current Pandas this does not change df. Assign the result back instead.
  • Filling with 0 when 0 is a real value. A student who was absent did not necessarily score zero.
  • Dropping rows blindly. If a third of your rows have a gap somewhere, dropna() throws away a third of your data.

6When should I use it?

Drop rows when only a few are affected and they aren't important. Fill when you want to keep every row: use the mean or median for numbers and the mode or a label such as "Unknown" for categories.

7Interview questions

How do you count missing values in each column?

df.isna().sum().

What is the difference between dropna() and fillna()?

dropna() removes rows (or columns) that contain gaps. fillna() keeps them and replaces the gaps with a value.

When would you use the median instead of the mean?

When a few extreme values would pull the mean away from a typical value, such as incomes or house prices.

Why does an integer column become float when it has a missing value?

Because NaN is a floating-point value, so the whole column is stored as floats like 78.0.
