Filter arrays with conditions and np.where

Pick values that match a rule, count them, change them, and label them with np.where.

1What is it?

A boolean mask is an array of True/False values made by a comparison such as marks > 50. Using it inside [] keeps only the matching values. np.where() is a one-line if-else for a whole array.

2Why do we need it?

Real questions have conditions: who passed?, which readings are too high?, give grace marks to anyone below 40. Masks answer all of these without loops.

3In plain words

Everyday example

Imagine holding a sieve over a bowl of marks. The condition > 50 is the sieve. Everything that passes through is kept, everything else stays behind. The True/False list is just a record of which marks passed the sieve.

Precise definition

A comparison on an array returns a boolean array of the same shape. arr[mask] returns only the elements where the mask is True (as a new 1-D array). Combine conditions with & (and), | (or) and ~ (not), each condition in its own brackets. np.where(cond, a, b) picks from a where the condition is True and from b otherwise.

  1. Write a comparison: marks >= 40.
  2. Use it as a mask: marks[marks >= 40].
  3. Combine rules with &, |, ~ and brackets.
  4. Count matches with mask.sum(), since True counts as 1.
  5. Use np.where to choose between two values for every element.

4Code, step by step

Masks and filtering

lesson_1.py
import numpy as np

marks = np.array([35, 82, 47, 91, 28, 66])

mask = marks >= 40
print(mask)
print(marks[mask])
print(marks[marks > 80])
print(mask.sum())
OUTPUT
[False  True  True  True False  True]
[82 47 91 66]
[82 91]

Combining conditions

lesson_2.py
import numpy as np

marks = np.array([35, 82, 47, 91, 28, 66])

print(marks[(marks >= 40) & (marks < 80)])
print(marks[(marks < 30) | (marks > 90)])
print(marks[~(marks >= 40)])
OUTPUT
[47 66]
[91 28]
[35 28]
LineWhat it means
(marks >= 40) & (marks < 80)Both rules must be true. Use &, not the word and, and keep each rule in brackets.
(marks < 30) | (marks > 90)Either rule may be true. | means or.
~(marks >= 40)~ flips True and False, so this keeps the marks that failed.

np.where: label every value

lesson_3.py
import numpy as np

marks = np.array([35, 82, 47, 91, 28, 66])

print(np.where(marks >= 40, 'Pass', 'Fail'))
print(np.where(marks >= 40, marks, 0))
print(np.where(marks < 40))
OUTPUT
['Fail' 'Pass' 'Pass' 'Pass' 'Fail' 'Pass']
[ 0 82 47 91  0 66]
(array([0, 4]),)
LineWhat it means
np.where(marks >= 40, 'Pass', 'Fail')For each mark, give 'Pass' where the condition is True and 'Fail' where it is False.
np.where(marks >= 40, marks, 0)Keep the mark if it passed, otherwise use 0. The result has the same length as the input.
np.where(marks < 40)With only a condition, it returns the positions where the condition is True, wrapped in a tuple. Here, positions 0 and 4.

Changing values with a mask

lesson_4.py
import numpy as np

marks = np.array([35, 82, 47, 91, 28, 66])
marks[marks < 40] = 40
print(marks)

ids = np.array([10, 20, 30, 40, 50])
print(ids[[0, 2, 4]])
OUTPUT
[40 82 47 91 40 66]
[10 30 50]
LineWhat it means
marks[marks < 40] = 40Assigns 40 to every position the mask selects. A quick way to give minimum or grace marks.
ids[[0, 2, 4]]Passing a list of positions picks exactly those items, in that order. This is called fancy indexing.

5Common mistakes

  • Using and / or instead of & / |. Python's keywords fail on arrays with an ambiguous truth value error.
  • Forgetting the brackets: marks > 40 & marks < 80 is evaluated in the wrong order. Write (marks > 40) & (marks < 80).
  • Expecting arr[mask] to change arr. It returns a new array; assign to arr[mask] = ... to change the original.
  • Forgetting that np.where(condition) with one argument gives positions, not values.

6When should I use it?

Use masks to filter, count or fix values that meet a rule, and np.where when every element needs one of two outcomes, such as a Pass/Fail label or a cleaned value.

7Interview questions

How do you select all values greater than 50 from an array a?

a[a > 50].

Why do you need brackets around each condition when combining with &?

& has higher priority than comparison operators, so without brackets Python evaluates the wrong parts first.

What does np.where(cond, x, y) do?

It returns an array that takes values from x where cond is True and from y where it is False.

How can you count how many values match a condition?

Sum the mask: (a > 50).sum(), because True counts as 1.

8Try it yourself

For temps = np.array([22, 35, 18, 41, 30]), print how many readings are above 30, and print the array with every reading above 30 replaced by 30.

Show hint

import numpy as np

temps = np.array([22, 35, 18, 41, 30])
