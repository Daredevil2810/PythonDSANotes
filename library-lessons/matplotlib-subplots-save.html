Subplots and saving charts

Put several charts in one figure, meet the figure/axes way of working, and save your chart as an image file.

1What is it?

A subplot is one small chart inside a bigger picture. plt.subplots() creates the whole picture (the figure) and the chart areas inside it (the axes), so you can place several charts side by side. savefig writes the result to an image file.

2Why do we need it?

Dashboards, reports and LinkedIn posts rarely use one chart alone. Putting related charts next to each other lets people compare them. Saving as a file lets you drop the chart into a document, a website or a post.

3In plain words

Everyday example

Think of a photo frame with four windows. The frame is the figure and each window is an axes where you put one picture. You decorate each window separately, then hang the whole frame on the wall.

Precise definition

fig, axs = plt.subplots(rows, cols, figsize=(w, h)) returns a figure and an array of axes. You draw with methods on an axes (ax.plot, ax.bar) and style it with ax.set_title, ax.set_xlabel, ax.set_ylabel. fig.tight_layout() prevents overlaps. plt.savefig('name.png', dpi=200) writes the figure to a file; call it before plt.show().

  1. Create the grid with fig, axs = plt.subplots(1, 2, figsize=(9, 3.5)).
  2. Draw on each axes, for example axs[0].plot(...).
  3. Style each axes with set_title and the label methods.
  4. Call fig.tight_layout() so nothing overlaps.
  5. Save with plt.savefig(...) and then show.

4Code, step by step

Two charts side by side

lesson_1.py
import matplotlib.pyplot as plt

fig, axs = plt.subplots(1, 2, figsize=(9, 3.5))

axs[0].plot([1, 2, 3, 4, 5], [4, 6, 5, 8, 7])
axs[0].set_title('Steps')

axs[1].bar(['Pune', 'Delhi', 'Mumbai'], [1350, 850, 300])
axs[1].set_title('Sales')

fig.tight_layout()
plt.show()
LineWhat it means
plt.subplots(1, 2, figsize=(9, 3.5))Creates one figure with 1 row and 2 columns of charts. figsize is the width and height in inches.
axs[0].plot(...)Draws on the left chart. With a single row, axs is a simple list of two axes.
axs[0].set_title('Steps')On an axes object the method is set_title, not title.
axs[1].bar(...)A completely different type of chart on the right.
fig.tight_layout()Adjusts the spacing so titles and labels do not overlap.

A 2 by 2 grid

lesson_2.py
import matplotlib.pyplot as plt

fig, axs = plt.subplots(2, 2, figsize=(8, 6))
fig.suptitle('Four ways to look at data')

axs[0, 0].plot([1, 2, 3, 4], [2, 4, 3, 6])
axs[0, 0].set_title('Line')

axs[0, 1].bar(['A', 'B', 'C'], [5, 9, 3])
axs[0, 1].set_title('Bar')

axs[1, 0].scatter([1, 2, 3, 4, 5], [2, 3, 5, 4, 6])
axs[1, 0].set_title('Scatter')

axs[1, 1].hist([1, 2, 2, 3, 3, 3, 4, 4, 5], bins=5)
axs[1, 1].set_title('Histogram')

fig.tight_layout()
plt.show()
LineWhat it means
plt.subplots(2, 2, ...)A grid with 2 rows and 2 columns. Now axs is two-dimensional, so you pick a chart with axs[row, col].
fig.suptitle(...)A title for the whole figure, above all the charts.
axs[0, 0] ... axs[1, 1]The four windows: top left, top right, bottom left and bottom right.
fig.tight_layout()Keeps the four titles and labels from running into each other.

Save the chart to a file

lesson_3.py
import os
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [2, 4, 3])
plt.title('Saved chart')
plt.savefig('chart.png', dpi=150, bbox_inches='tight')

print(os.path.exists('chart.png'))
print(os.path.getsize('chart.png') > 0)
OUTPUT
True
True
LineWhat it means
matplotlib.use('Agg')Switches to a backend that draws to files and opens no window. This is useful on servers and for scripts that only save images. On your own computer you can leave it out.
plt.savefig('chart.png', dpi=150, bbox_inches='tight')Writes the chart to chart.png. dpi sets the sharpness and bbox_inches='tight' trims extra white space.
os.path.exists('chart.png')Confirms the file now exists.
os.path.getsize('chart.png') > 0And that it is not empty.

5Common mistakes

  • Calling plt.savefig after plt.show(). Once the window is closed the figure is cleared and you save a blank image.
  • Using axs[0] on a 2-D grid, or axs[0, 0] on a single row. Check the shape you asked for.
  • Mixing plt.title with axes objects. On an axes it is ax.set_title, ax.set_xlabel and ax.set_ylabel.
  • Forgetting tight_layout() and ending up with overlapping labels.

6When should I use it?

Use subplots to compare related charts in one picture, and savefig whenever the chart has to leave your script: a report, a slide, a website or a post.

7Interview questions

What is the difference between a figure and an axes?

The figure is the whole canvas. An axes is one chart area on it, with its own x and y axis.

How do you create a 2 by 3 grid of charts?

fig, axs = plt.subplots(2, 3).

How do you save a chart as an image?

plt.savefig('name.png'), called before plt.show().

What does tight_layout do?

It adjusts the spacing between subplots so labels and titles do not overlap.
