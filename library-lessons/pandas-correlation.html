Correlation: do two columns move together?

Measure how strongly two numeric columns are related with corr(), and learn how to read the result honestly.

1What is it?

Correlation is a number between -1 and 1 that says how closely two columns move together. Pandas calculates it with corr().

2Why do we need it?

Before building a model or drawing conclusions, you want to know which columns are related. Do students who study more score higher? Does more screen time go with lower marks? Correlation gives a quick, numeric first answer.

3In plain words

Everyday example

If every extra hour of study comes with a few more marks, the two numbers rise together. That is a correlation near +1. If more phone time comes with fewer marks, they move in opposite directions: near -1. If shoe size and marks have nothing to do with each other, it is near 0.

Precise definition

corr() calculates the Pearson correlation coefficient, which measures linear relationships. +1 is a perfect positive line, -1 a perfect negative line and 0 means no linear relationship. Correlation does not prove one thing causes the other.

ValueMeaning
close to +1Both rise together
close to -1One rises while the other falls
close to 0No straight-line relationship
above about 0.6 or below -0.6A fairly strong relationship (a common rule of thumb, not a law)
  1. Make sure the columns you compare are numeric.
  2. Use a.corr(b) for one pair, or df.corr(numeric_only=True) for every pair.
  3. Read the numbers: sign tells the direction, size tells the strength.
  4. Remember: a strong correlation is a clue, not proof of cause.

4Code, step by step

Correlation of two columns

lesson_1.py
import pandas as pd

df = pd.DataFrame({
    "hours": [1, 2, 3, 4, 5, 6, 7, 8],
    "marks": [35, 42, 50, 55, 63, 70, 78, 84],
})
print(round(df["hours"].corr(df["marks"]), 3))
OUTPUT
0.999
LineWhat it means
df["hours"].corr(df["marks"])Correlation between two columns. A value close to 1 means that students who study more tend to score more.
round(..., 3)Rounds to 3 decimal places so the number is easy to read.

The whole correlation table

lesson_2.py
import pandas as pd

df = pd.DataFrame({
    "name": list("abcdefgh"),
    "hours": [1, 2, 3, 4, 5, 6, 7, 8],
    "marks": [35, 42, 50, 55, 63, 70, 78, 84],
    "phone_minutes": [200, 180, 170, 150, 140, 100, 90, 60],
    "shoe_size": [8, 6, 9, 7, 8, 6, 9, 7],
})
print(df.corr(numeric_only=True).round(2))
OUTPUT

df.corr(numeric_only=True)Calculates every pair of columns. numeric_only=True skips the text column name; without it, Pandas raises an error.
.round(2)Two decimals keep the table readable. The diagonal is always 1, since every column matches itself perfectly.

Find what relates most to marks

lesson_3.py
import pandas as pd

df = pd.DataFrame({
    "hours": [1, 2, 3, 4, 5, 6, 7, 8],
    "marks": [35, 42, 50, 55, 63, 70, 78, 84],
    "phone_minutes": [200, 180, 170, 150, 140, 100, 90, 60],
    "shoe_size": [8, 6, 9, 7, 8, 6, 9, 7],
})
with_marks = df.corr()["marks"].drop("marks")
print(with_marks.round(2).sort_values())
print("Strongest link:", with_marks.abs().idxmax())
OUTPUT
phone_minutes   -0.99
shoe_size        0.02
hours            1.00
Name: marks, dtype: float64
Strongest link: hours
LineWhat it means
df.corr()["marks"]From the full table, takes only the column that shows how everything relates to marks.
.drop("marks")Removes marks compared with itself (always 1).
.abs().idxmax()abs() ignores the sign so strong negative links count too; idxmax() returns the name of the strongest one.

5Common mistakes

  • Concluding that one thing causes the other. Ice-cream sales and sunburn are correlated because of the weather, not because one causes the other.
  • Running df.corr() on a table with text columns. Use numeric_only=True (or select numeric columns first).
  • Trusting a correlation from a handful of rows, or one that comes from a single extreme value. Always look at the data too.

6When should I use it?

Use correlation for a quick first look at which numeric columns are related, for example when choosing features for a model or deciding what to chart next.

7Interview questions

What does corr() calculate?

The Pearson correlation coefficient between numeric columns, from -1 to 1.

What does a correlation of -0.9 mean?

A strong negative relationship: when one column goes up, the other tends to go down.

Does a high correlation mean one column causes the other?

No. Correlation only says the two move together. Another factor, or chance, might explain it.

Why does df.corr() fail on a table with text columns?

Correlation needs numbers. Pass numeric_only=True or select the numeric columns first.
